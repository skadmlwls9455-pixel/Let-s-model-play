# 부엌 소리 (녹음 foley)

뽈뽈 문어 부엌 미니게임에 쓰는 녹음 효과음 27개다(거의 모두 진짜 녹음). 지금 게임의 해초전(톡톡 -> 뒤집기 -> 썰기 -> 접시)과 나중 요리(미역국 젓기, 톳 주먹밥 올리기)에 쓴다. 냄새는 못 내니 소리로라도 "맛있겠다" 가 들리게: 가까이서 들리는 깨끗한 지글, 바삭, 톡.

- 원본: OpenGameArt.org 의 **CC0 와 CC BY** 녹음만. 출처와 바꾼 것은 [CREDITS.md](CREDITS.md). CC BY 두 곳(DavidW 도마 소리, Vinrax 물소리)은 크레딧을 꼭 넣어야 한다.
- 칩튠 한 벌(`audio/`, 합성기로 만든 오리지널) 옆에 놓는 층이다. 그 한 벌의 규칙(48 kHz 모노, Opus + AAC, BGM 대비 크기, 루프 여유)을 그대로 따른다. 접시 공개(done)에 칩튠 팡파르는 없다: 이 층의 접시 소리와 김뿐이다.
- 표: [manifest.json](manifest.json) (파일, 길이, 루프 지점, 크기, act, 출처 키). 들어 보기: [listen.html](listen.html) (이 폴더에서 `python3 -m http.server` 로 열면 루프를 게임처럼 돌려 들을 수 있다. 파일로 바로 열면 한 번씩만 재생).
- id 는 모두 `cook_` 으로 시작한다. 본 한 벌에 이미 `step`(걸음, step_1~4)과 `place_*`(장소 테마)가 있어서 겹치지 않게 했다. files 경로(`cook/<id>.ogg`)는 이 폴더(`foley/`) 기준이다. 게임에서는 js/audio.js 가 `foley/manifest.json` 을 부엌 소리가 처음 필요할 때 받고, act 를 이 표의 `map.cook` 대로 튼다.
- 크레딧: CC BY 두 줄과 CC0 원본은 게임의 `credits.html` (설정 맨 아래 '만든 것들', 부엌 조리대 아래 같은 링크)에 그대로 있다.
- 소리는 꺼진 채 시작하는 게임이라 이 층은 덤이다. 켰을 때만 들린다.
- 한 판 미리 듣기 `cook_demo_haechojeon.m4a|.ogg` (19.4 s)는 굽기의 `--work` 폴더 preview/ 에 생긴다. 해초전 한 판을 게임처럼 이어 붙인 **흉내**라 게임 파일이 아니고 저장소에 넣지 않는다. 불 켜면 지글 0 이 1 s 페이드인, 3 s 마다 다음 굽기로 0.5 s 크로스페이드, 뒤집은 뒤 0.25 s 페이드아웃.

## 다시 만들기

```sh
# 저장소 뿌리에서. 원본 28개는 저장소에 없다: tools/foley-build.py 머리글의 표대로 CREDITS.md 의 페이지에서 받아
# --raw 폴더에 둔다 (받은 파일이 그때와 같은지 스크립트가 sha256 으로 본다). 해독은 ffmpeg 로만
python3 -I tools/foley-build.py --raw ~/.cache/ppolppol-foley/raw              # 굽기 + 이 폴더의 문서 + 검사
python3 -I tools/foley-build.py --raw ~/.cache/ppolppol-foley/raw --no-check   # 검사 없이
```

numpy 와 ffmpeg(libopus, aac)만 쓴다. 난수가 없고 ffmpeg 를 `-bitexact` 로 돌려서 몇 번을 돌려도 같은 파일이 나온다. 할 일: 원본 구간 자르기 -> 모노(L/R 평균) 48 kHz -> DC 제거 -> 고역/저역 통과(버터워스, 인과 IIR 과 같은 결과라 앞울림 없음) -> 페이드 -> 여러 녹음 겹치기(뒤집기, 썰기, 불 켜기, 접시) -> 크기 맞추기 -> Opus, AAC 인코딩.

## 크기

- 기준은 BGM 통합 -20 LUFS 다. 파일마다 `level.rel_db`(BGM 대비 dB)만큼 **구워져 있다**. 게임은 gain 1.0 으로 틀고 효과음 슬라이더만 곱한다.
- 파일마다 1.5 s 이상이면 통합 LUFS, 짧으면 소리 나는 구간 RMS 로 잰다(`audio/src/export.py` level() 의 코드와 `audio/manifest.json` 이 쓰는 경계. 그 파일 설명 글에는 1초라고 적혀 있지만 코드는 1.5 s 다). 지금 LUFS 로 잰 것: `cook_sizzle_0`, `cook_sizzle_1`, `cook_sizzle_2`, `cook_flip_1`, `cook_flip_2`, `cook_simmer`.
- 1~1.5 s 인 소리는 불 켜기 둘뿐이다. 1초 경계로 쟀다면 LUFS: cook_heat_on_1 -38.9 LUFS (목표 -38), cook_heat_on_2 -38.7 LUFS (목표 -38). 1 dB 안이다.
- 단위가 다른 소리끼리는 `level.loudest_100ms_lufs` / `loudest_400ms_lufs`(K 가중 가장 큰 100 / 400 ms)로 들리는 크기를 견준다. 크기 맞춤에는 쓰지 않는다.
- true peak 는 -3 dBTP 아래.
- 제안 크기에서 바꾼 것: 지글 세 단계를 +3 dB(-15/-12/-10), 보글 +2 dB(-14). 비 오는 날 바탕 빗소리(amb_rain, -12)가 가장 자주 들리는데 그 아래로 지글이 묻히지 않게. 김 쉬익 -20(제안 -14): 고음 쉬익은 RMS 로 재면 작게 읽혀서 -17 에서도 가장 큰 400 ms 가 접시 둘 사이였다. 불 켜기 -18(제안 -12): 50 ms 딸깍과 0.9 s 작은 꼬리를 RMS 가 평균해 딸깍을 6 dB 작게 읽었다(-12 면 가장 큰 100 ms 가 뒤집기만큼). -18 이면 썰기 바로 아래다.

## 루프 (지글 세 단계, 보글)

- 파일 = [앞 0.5 s = 몸통 끝 복사][몸통][뒤 1.0 s = 몸통 앞 복사], `loop.start` = 0.5, `loop.end` = 0.5 + 몸통 길이.
- Web Audio `AudioBufferSourceNode` 에 `loop = true`, `loopStart`, `loopEnd`, 시작은 `start(t, loop.start)`. `<audio loop>` 는 쓰지 않는다(인코더 패딩 때문에 틈).
- 지글 몸통은 같은 녹음의 고른 구간을 잘라, 끝 0.5 s 를 몸통 바로 앞 0.5 s 로 넘기는 등전력 크로스페이드로 이었다. 보글은 원래 이음새 없는 루프(TinyWorlds)를 주기 그대로 48 kHz 로 바꿨다. 이음새는 Opus, AAC 둘 다 디코드해서 확인했다 (검사 보고서: 굽기의 --work 폴더 check/report.md).
- 굽기가 바뀌면(band 0 -> 1 -> 2) 지금 루프에서 다음 루프로 0.15 s 등전력 크로스페이드 + 치익 한 번(새 루프가 +4 dB 까지 올랐다가 0.5 s 에 제 크기로). `quiet` 이면 0.25 s 페이드아웃.
- cook_sizzle_0 -> 1 -> 2 는 같은 팬(같은 녹음 fryingpan01)이 달궈지는 세 결이다. 크기 -35/-32/-30 LUFS. 밝기(마스터 몸통의 스펙트럼 무게중심 9750/10393/10923 Hz, 8 kHz 위 에너지 몫 0.584/0.669/0.718)는 0 -> 1 -> 2 로 오른다. 도드라지는 탁탁(2 kHz 위 2 ms 창이 200 ms 이동 중앙값보다 +9 dB 솟는 곳)은 초당 2.41/0.22/5.7: 0 은 조용한 바탕에 성긴 탁탁, 1 은 이 녹음에서 가장 빽빽하고 고른 쉬익이라 탁탁이 쉬익에 묻혀 따로 솟는 것이 가장 적다(소리는 셋 중 가운데로 크다), 2 가 가장 바쁘다. 기름 튐(+15 dB 넘음)은 초당 0/0/0.2 (2 에만). 크기 흔들림(250 ms 크기의 표준편차)은 1.17/0.67/0.73 dB. 서로 상관없는 잡음이라 등전력(cos/sin) 크로스페이드가 맞다. 디코드한 파일의 같은 숫자와 이음새 검사는 굽기의 --work 폴더 check/report.md.
- 바삭(2) 루프는 느린 크기 고르기(400 ms 로 매끈하게 한 크기를 중앙값 쪽으로 60 %)로 큰 출렁임을 폈고, 같은 녹음의 다른 곳에서 뜬 기름 튐 두 개(18 ms, 30 ms)를 몸통 3.8 s, 8.0 s 에 얹었다. 루프가 10 s 라 튐도 10 s 마다 같은 자리에 온다(바삭 상태는 보통 몇 초라 한두 바퀴).
- 지글 루프는 Opus 96 kbps 다(48 kbps 에서는 Opus 가 탁탁을 원본의 31~68 % 로 뭉갰다). AAC 도 96 kbps.

## 뒤집기 때맞춤

- 게임은 뒤집는 순간 소리를 틀고, 전은 12 fps 로 arc 그림 0~2(0~250 ms) 동안 공중에 있다가 3번째 그림(250~333 ms)에 내려앉는다(js/cook.js, js/cook-art.js). 그래서 철퍽 봉우리를 그 착지에 맞췄다: `cook_flip_1` 0.256 s, `cook_flip_2` 0.256 s. 그 앞은 카드 미끄럼으로 만든 휙이다.
- 늦추지 말고 사건과 함께 튼다. 움직임 줄이기(prefers-reduced-motion: 그림이 바로 바뀜)에서는 `start(t, sync.reduced_motion_offset_s)` 로 휙을 건너뛰면 철퍽이 50 ms 뒤에 온다.

## 길이

- manifest 의 `duration` 은 마스터(= .ogg 디코드) 길이다. .m4a 를 ffmpeg 로 디코드하면 AAC 의 마지막 1024 샘플 묶음이 통째로 남아 0.7~21 ms 더 길다(덧붙은 뒤는 디지털 무음). Chrome 의 decodeAudioData 는 정확한 길이로 디코드했다(listen.html 시험). 어느 쪽이든 루프의 `loop.end` 뒤 여유(1.0 s)에는 영향이 없다.

## 정직 메모

- **만든 쪽(Claude)은 소리를 들을 수 없다.** 고른 구간과 겹치기는 숫자(크기, 피크, 스펙트럼 무게중심, 대역별 크기, 탁탁 수, 루프 이음새 오차)와 스펙트로그램·파형 그림만 보고 정했다. 원본 페이지의 제목과 설명도 근거로 썼다.
- 그래서 사람 귀로 꼭 확인할 것 (listen.html 에 견주기 단추가 있다):
  - 뒤집기: 철퍽이 "전이 기름에 떨어짐" 으로 들리는지(젖은 수건 녹음), 휙이 공기 소리로 들리는지(카드 미끄럼을 느리게 한 것).
  - 톡톡이 끈적하지 않은지. listen.html 의 "톡톡 9번" 을 그대로 / 어둡게(3.5 kHz 저역 통과) 견줘서, 어두운 쪽이 낫다면 tools/foley-build.py 의 PAT_CHAIN 을 PAT_CHAIN_DARK 로 바꿔 다시 굽는다.
  - 지글 세 단계가 한 팬이 달궈지는 것처럼 들리는지, 너무 얇은 쉬익은 아닌지. listen.html 의 "0 -> 1 -> 2 이어 듣기" 를 그대로 / 10 kHz 위 -3 dB 로 견줘서 따뜻한 쪽이 낫다면 세 루프 셸프를 3 dB 씩 내린다.
  - 10 s 바삭 루프를 여러 바퀴 돌려도 같은 튐이 거슬리게 되풀이되지 않는지("루프로 듣기").
  - 썰기: 바삭이 큰 cut_1 과 도마 톡이 앞선 cut_2, cut_3 중 어느 결이 더 맛있게 들리는지.
  - 불 켜기의 화르륵이 불처럼 들리는지(성냥 녹음을 거른 것).
- 마음에 안 들면 tools/foley-build.py 의 숫자를 고쳐 다시 굽는다.
- 진짜 녹음이지만 "그 장면을 그대로 녹음한 것" 은 아닌 대역이 많다(아래). 정직하게 적어 둔다.

## 판정 단계의 처리 글과 다르게 한 것

- 불 켜기 2: 구간 시작 0.30 -> 0.29 s. 딸깍은 0.298 s 부터 오른다(글의 0.315 보다 이르다). 0.30 에서 자르면 첫머리가 잘린다. 화르륵은 +0.090 s (딸깍 -> 화르륵 70 ms 간격은 그대로).
- 불 켜기 화르륵 크기: 글은 "딸깍보다 5 dB 아래"(10 ms dB 를 50 ms 로 평균한 잣대, 창 위치에 따라 7 dB 까지 흔들림)이고 변형 2 의 이득은 글(-11)과 원형 JSON(-16)이 서로 달랐다. 판정이 만든 H1 원형(딸깍 0, 화르륵 -16)을 기준으로, 두 변형 모두 화르륵의 가장 큰 100 ms 에너지가 딸깍보다 약 11~12 dB 아래가 되게 했다(변형 1 -11.7 그대로, 변형 2 -11.0).
- 뒤집기 지글 부풀음: 글대로 철퍽보다 5 dB 아래(가장 큰 100 ms 에너지). 원형 이득 그대로면 8 dB(1), 11 dB(2) 아래라서 +3.2 / +6.1 dB. 변형 2 는 원본 부풀음이 거의 줄지 않아 1.25 s 까지 평평했으므로 덧붙인 감쇠를 -9 dB(0.45 s 부터) -> -15 dB(0.40 s 부터)로 키웠다.
- 뒤집기 때맞춤: 철퍽(과 부풀음)을 +0.11 s -> 약 +0.24 s 로 옮겨 철퍽 봉우리가 0.255 s, 곧 게임의 착지 그림(arc 3번째, 250~333 ms)에 온다. 그 앞은 휙이 채운다. 변형 2 의 부풀음은 1.55 -> 1.50 s 로 줄여 파일이 1.8 s 안.
- 뒤집기 휙: 대나무 막대(185 Hz 웅, 2~8 kHz 거의 없음) 대신 Kenney 카드 미끄럼(같은 CC0 페이지의 다른 파일, 카드가 닿기 바로 앞까지) 0.8 배 느리게, HP 700 Hz / LP 9 kHz, 철퍽보다 가장 큰 50 ms 에너지로 8 dB 아래.
- 크기 단위: 같은 group 은 같은 단위로 재던 것을 export.py 처럼 파일마다(1.5 s 이상 LUFS)로 되돌렸다. 뒤집기 둘이 이제 1.5 s 넘어서 둘 다 LUFS(전에는 둘 다 RMS 라 flip_2 가 LUFS 로 2.3 dB 컸다).
- 썰기 2: 바삭 층 원본 이득 -1 dB 이면 도마 톡보다 4.1 dB 아래(5 ms)라 허용(6~10 dB) 밖 -> 7.0 dB 아래로. 썰기 3(-7.2)은 그대로. 썰기 1 은 바삭을 3.5 dB 아래로 올렸다(검사 메모: 바삭이 너무 묻힌다, 귀로 견줄 것).
- 접시 1 의 포크-접시 울림: 판정 미리 듣기처럼 원본 이득 -12 dB 그대로(10 ms 에너지로는 8.5 dB 아래).
- 지글 밝기: 바삭(2)에 8 kHz 하이셸프 +3 dB(글은 고르면 +1.5 dB @7 kHz), 노릇(1)에 -1.5 dB, 보들(0)에 -2.5 dB. 노릇 창이 녹음에서 가장 밝은 곳이라 셸프가 없으면 바삭과 밝기가 같았다. 바삭의 확 커지는 두 번 -3 dB, 보들의 2.1 dB 크기 기울기 펴기는 글의 "고르면" 을 적용했다.
- 바삭 루프: 느린 크기 고르기(400 ms, 60 %, +-4 dB)로 몸통 250 ms 크기 범위 8.2 -> 약 3.6 dB. 기름 튐 두 개를 같은 녹음 39.97 s, 56.88 s 에서 떠서 몸통 3.8 s, 8.0 s 에 얹음(중앙값 +16 / +16.5 dB).

## 빈 곳 (대신 쓴 것)

- **sizzle**: 지글 세 단계와 두 뒤집기 부풀음이 모두 한 녹음(bretbernhoft fryingpan01, CC0)에서 나왔다. 그래서 색이 같지만 독립된 두 번째 팬 녹음은 OGA 에 없다. BigSoundBank #0143-0145(스테이크), #1676, #2509 (CC0)는 robots/ai.txt 때문에 에이전트가 받지 않았다. 주인이 손으로 받으면 바꿀 수 있다.
- **heat_on**: 진짜 가스 불이 화르륵 붙는 녹음이 OGA 에 없다. 화르륵은 qubodup 성냥 녹음을 빠르게 한 것을 5 kHz 로 걸러 흉내 낸 것. 어색하면 딸깍만 남겨도 된다 (BigSoundBank #0057/#0058 이 진짜, 손으로만 받을 수 있음).
- **flip**: 팬에서 뒤집개로 뒤집는 진짜 녹음은 없다. 카드가 펠트를 미끄러지는 소리(Kenney, 느리게) 휙 + 젖은 수건 철퍽 + 같은 팬 지글 부풀음을 겹쳤다. 철퍽이 "수건이 바닥에" 처럼 들리면 철퍽을 3~6 dB 낮추거나 towel-06 으로 바꾼다. 대나무 막대 휙(전의 층)은 낮은 웅 소리라 폰에서 들리지 않아 뺐다.
- **pick**: 팬을 드는 녹음(OwlishMedia Kitchen_04)에 가벼운 들기는 한 번뿐이다. pick 은 한 판에 한 번이라 변형 하나로 둔다.
- **pat**: 반죽을 두드리는 진짜 녹음은 없다. EZduzziteh 의 CC0 squish 앞머리(-20 dB 까지 55~75 ms)만 잘라 쓰고, 4 kHz 하이셸프 -4 dB 로 젖은 잡음(2~6 kHz)을 조금 눌러 몸통 쪽으로 기울였다. 끈적하게 들리면 80~90 ms 로 더 짧게, 셸프를 -6 dB 까지.
- **cut**: 바삭한 껍질 + 도마 톡이 한 번에 든 녹음이 없어 두 층(탄 토스트 CC0 + DavidW 도마 CC-BY)을 겹쳤다.
- **plate**: "접시를 식탁에 놓기" 라고 이름 붙은 녹음이 OGA 에 없다. OwlishMedia 의 이름 없는 내려놓기 두 개를 소리 결(배음)로 사기라고 짐작했다. plate_1 에는 진짜 포크-접시 울림을 -12 dB 로 깔았다.
- **step**: "뒤집개를 도마에 내려놓기" 는 없다. 주사위 첫 닿음(Kenney)의 둔한 톡으로 대신했다.
- **stir**: 냄비 크기 젓기 녹음이 없다. 머그잔 물소리(Vinrax, CC BY 3.0)를 2반음 낮춰 큰 그릇처럼 했다.
- **clink**: Kitchen_02 는 이름 없는 쇠 톡(아마 숟가락과 뚜껑)이다. 냄비 가장자리라는 확인은 없다.
- **place**: 음식(주먹밥)을 놓는 녹음이 없다. 책을 살며시 놓는 소리를 3.5 kHz 로 걸러 대신했다.
- **lift**: 천 스치는 소리로 "집어 올림" 을 대신했다.
- **steam**: 진짜 부드러운 김 녹음이 없다. bart 의 쉬익(가공된 잡음으로 보임)을 1.2~8 kHz 로 거르고 앞을 70 ms 로 눌렀다.
