# 게임 컨텍스트 (모든 리서치 에이전트 공통)

게임: "뽈뽈 문어" — 비 오는 다락방에 사는 작고 동글한 빨간 문어. 사람은 힌트 한 줄 + 버튼 하나("뽈뽈 다녀와")만 누르고,
문어가 스스로 산책(위키 문서 기웃거리기)을 다녀와 포스터를 벽에 건다. 여행 개구리 / 네코아츠메 / 다마고치 계열의 아늑한 방치형 동반자 게임.
화면: 픽셀아트 3D 다락방(따뜻한 나무 갈색, 등불 호박색, 밤 남색), Galmuri 픽셀 폰트, 모바일 세로 360px. 패널티·타이머 압박 없음.
톤: 조용하고 다정함, 반말 1인칭("처음 가 본 데가 있었어. 다리가 아직 들썩거려"). 실패도 부정적으로 그리지 않는다(빨간색·흔들림·부저 금지).

게임 상태 (사운드가 반응해야 할 축):
- 날씨: rain(비) / drizzle(가는 비) / clear(맑음, 밤엔 별) / snow(눈, 1~2월). (천둥은 위키 노드로만 존재)
- 시간대(실제 시계): 새벽 6~9 / 낮 9~17 / 노을 17~19 / 밤 19~6
- 계절(실제 월): 봄 / 여름(밤 반딧불) / 가을(낙엽) / 겨울(눈)
- 장소(산책 코너 9개 + 특수 방): hands 손과 물건, sea 바다와 생물, sky 하늘과 날씨, signs 기호와 언어, numbers 수와 모양,
  sounds 소리와 리듬, home 집과 사람, mind 생각하는 것(꿈·기억), wild 들판(위키 링크로 간 미지의 곳),
  slow_room 느린 글의 방, letter_room 편지의 방(항상 비어 있음), door_out 밖의 문(URL)
- 기분/반응: 폴짝(신남), 우쭐(뿌듯), 덤덤(담담), 졸림 + 표정 idle/happy/pet(쓰다듬기)/curious/sleep
- 진행: 등불 8칸(한 칸씩 켜짐, 8칸이면 방 완성)
- 이벤트: depart(출발) → peek×N(기웃, 결과 read 읽음/builtin 책장메모/simulated 모의방문/failed 못읽음/none 앉아만 있음)
  → return(귀가) → remember(기억) → hang_poster(포스터 걸기) → wrap_up(반응) → 잠듦.
  집에 있는 날: stay_home(창가에서 빗방울 세기 등) / empty_turn(빈 차례 "…")
  상호작용: 쓰다듬기, 창문 두드리기, 바라보기. UI: 버튼, 시트 열기/닫기, 토스트, 로그 한 줄 추가.

요청자가 원하는 사운드: 8비트/칩튠 픽셀 게임에 어울리는 BGM + 효과음. 날씨·장소·기분별 다양한 테마와 효과음, 전체 톤이 어우러질 것.
기본 테마곡: "머니코드"(I–V–vi–IV, 캐논 진행 같은 익숙한 진행) 류로 익숙하고, 돌림노래(라운드/캐논)식으로 계속 들어도 안 질리게.
제작 방식: Python/numpy로 직접 합성(NES 2A03/게임보이풍 채널을 흉내 낸 신시사이저)해서 OGG/M4A 등으로 렌더. 기존 곡 멜로디 복제 금지(오리지널 작곡).
