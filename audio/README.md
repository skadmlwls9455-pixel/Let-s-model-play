# 뽈뽈 문어 사운드

비 오는 다락방 문어를 위한 8비트(칩튠) 소리 한 벌이다. BGM, 장소 테마, 징글, 효과음, 환경음까지 168개가 들어 있다.
모두 이 폴더의 파이썬 합성기로 **직접 만든 오리지널**이고, 기존 곡의 선율을 가져오지 않았다(코드 진행만 관용구를 쓴다. 진행은 저작권 대상이 아니다).

- 전체 목록: [CATALOG.md](CATALOG.md) (자동 생성)
- 게임이 읽을 표: [manifest.json](manifest.json) (파일 경로, 루프 지점, 음량, 상태→소리 매핑, 재생 규칙)
- 들어 보기: [soundboard.html](soundboard.html) (`audio/` 에서 `python3 -m http.server` 후 열기. 게임 화면처럼 날씨·시간·등불을 고르면 섞여서 나온다). 게시본: https://claude.ai/artifact/MCtLYb8vZqpKDxTS72JyGu (비공개, 공유 메뉴로 열어 줘야 다른 사람이 볼 수 있음)
- 근거 리서치 4편: [docs/research/](docs/research/)

| 폴더 | 무엇 | 개수 |
|---|---|---|
| `bgm/` | 집 테마 「뽈뽈 돌림노래」 시간대 4 × 날씨 3 + 눈 2, 자장가, 창가 비 | 16 |
| `place/` | 산책 코너별 장소 테마 | 11 |
| `jingle/` | 출발·귀가·기억·포스터·등불·방 완성·기분 반응·잠·시간대 종 | 47 |
| `sfx/` | UI, 말풍선 목소리, 기웃 결과 5종, 쓰다듬기, 창문, 발소리, 집에 있는 날 | 80 |
| `amb/` | 날씨 환경음, 계절 밤, 등불 온기, 덧층 | 14 |

형식은 48 kHz 모노, **Ogg Opus(.ogg) + AAC(.m4a) 두 벌**이다. Opus 를 먼저 쓰고, 못 읽으면(iOS Safari 18.4 미만) AAC 로 넘어간다.

## 1. 톤을 하나로 묶는 다섯 가지

소리가 100개가 넘어도 한 게임처럼 들리게 하려고 처음부터 다섯 가지를 고정했다.

1. **동기 하나.** 메인 동기 M = `도 도 라 도 미 도`(C5 C5 A4 C5 / E5 C5). "뽈 뽈 다녀 와"의 말 리듬이다. 첫 두 음의 같은 음 반복이 "뽈뽈"이다.
   모든 장소 테마, 징글, 기억 동기가 이 동기를 줄이거나 늘이거나 조를 옮겨 만든 것이다.
2. **진행 하나.** 캐논 진행(머니코드 계열) `| F C/E | Dm Am/C | B♭ F/A | B♭ C |` = I–V–vi–iii–IV–I–IV–V. 베이스가 F–E–D–C–B♭–A–B♭–C 로 한 칸씩 걸어 내려간다.
   장소 테마는 이 네 화음을 돌리거나(vi–IV–I–V, I–V–vi–IV) 옆 조로 옮겨 쓴다.
3. **조 가족 하나.** 집은 F장조. 모든 곡은 F에서 5도권 한 칸 안에 머문다.
   - 따뜻한 쪽 B♭(E♭ 한 음 차이): 집과 사람, 느린 글의 방
   - 밝은 쪽 C(B♮ 한 음 차이): 하늘, 소리, 밖의 문
   - 효과음과 징글 선율은 **F 펜타토닉(F G A C D)** 만 쓴다. 이 다섯 음은 세 집합 어디에나 들어 있어서 어떤 곡 위에서 울려도 부딪히지 않는다. 기분 징글은 언제나 F로 끝난다("문어의 목소리 = F").
4. **악기 상자 하나.** `src/instruments.py` 의 같은 악기를 모든 곡이 나눠 쓴다. NES 펄스 25%·50%, 삼각파 베이스, 노이즈, 게임보이 웨이브(피리·오르골·종).
   아늑하게: 12.5% 펄스는 반짝임에만, 어택은 살짝 둥글게, 비브라토는 0.3초 늦게 ±15센트, 마스터 저역 통과 5~8 kHz.
5. **음량 기준 하나.** BGM = 통합 −20 LUFS. 다른 소리는 "BGM 대비 몇 dB"(`level.rel_db`)로 **파일에 구워져 있다.** 게임은 모두 gain 1.0 으로 틀고 슬라이더만 곱하면 된다.

## 2. 메인 테마 「뽈뽈 돌림노래」

4마디짜리 선율 조각 넷(A·B·C·D)을 이은 16마디 선율을 세 성부가 4마디씩 늦게 따라 부르는 **돌림노래**다. 진입 간격이 화성 주기(4마디)와 같아서 어느 조각끼리 겹쳐도 같은 화음 위에 놓인다(화성 검사기로 전 구간 확인).

| 조각 | 리듬 | 성격 |
|---|---|---|
| A 부르기 | 8분 넷 + 4분 둘 | "뽈뽈 다녀와" 동기. 같은 꼴을 한 칸씩 올리며 세 번 |
| B 대답 | 4분 위주 | 내려오는 노래, 당김음 한 번 |
| C 종종걸음 | 8분 분산화음 | 문어 다리가 종종거리는 낮은 음역 |
| D 숨 고르기 | 긴 음 | 쉼표 같은 구간. 끝에 "뽈뽈" 두 음으로 다음 바퀴를 부름 |

한 사이클은 68마디(80 BPM 기준 3분 24초)다. 성부가 하나씩 늘었다가 줄어든다.

| 마디 | 구간 | V1 (펄스) | V2 (펄스 25%) | V3 (게임보이 웨이브, 한 옥타브 아래) |
|---|---|---|---|---|
| 1–16 | 혼자 | A B C D | V1 을 점8분 늦게 작게 따라 하는 메아리 | – |
| 17–32 | 둘이 | A B C D | 21마디부터 A B C | – |
| 33–48 | 셋이 | A B C D | D A B C | 41마디부터 A B |
| 49–56 | 빠짐 | – | D | C D |
| 57–64 | 브리지 | 로열로드 진행(IV–V–iii–vi) 위 새 선율 + 메아리 | | |
| 65–68 | 꼬리 | 동기 두 마디 → B♭–B♭m(그리움 한 방울) → C | | |

**계속 들어도 덜 질리게 한 장치** (리서치 01·02 근거)
- 정확히 같은 소리가 돌아오는 주기가 3분 반~4분 반이다. 선율은 같아도 질감이 계속 바뀐다.
- 베이스는 바퀴마다 모양만 바꾼다(슬래시 하행 2분 → 근음·5도 → 통통 8분).
- 타악은 "셋이" 구간에만 아주 작게 나온다. 곡의 대부분은 쉼이 많다.
- 템포는 64~80 BPM 으로 차분하다. 화음 하나가 최소 2박이고, 선율은 거의 순차 진행이다.
- **사이클이 끝나면 20~90초 쉰다**(매니페스트 `rest_after_sec`). 그동안 환경음만 둔다. 마인크래프트·스타듀처럼 멈춤이 오히려 다음 재생을 반갑게 한다.

## 3. 상태 → 소리

### 집 화면: 시간대 × 날씨 (같은 곡, 다른 옷)

동물의 숲 시간대 음악이 비 오는 날 "같은 곡, 다른 편곡"으로 바뀌는 방식이다. 선율과 화성은 그대로 두고 악기·템포·필터·반주만 바꾼다.

| | 맑음 `clear` | 가는 비 `drizzle` | 비 `rain` | 눈 `snow` |
|---|---|---|---|---|
| 새벽 6–9 (72) | 부드러운 펄스·오카리나·오르골 반주 | + 처마 물방울 반주 | 64 BPM, 얇은 리드, 듬성 빗방울 반주, 먹먹하게 | `theme_snow_day` |
| 낮 9–17 (80) | **기본형** | + 물방울, 타악 절반 | 75 BPM, 북 없음, 빗소리가 주인공 | `theme_snow_day` 오르골 + 종 |
| 노을 17–19 (75) | 피리 리드, 현 같은 웨이브, 살짝 스윙 | + 물방울 | 72 BPM | `theme_snow_day` |
| 밤 19–6 (64) | 자장가 옷: 오르골·오카리나·종 | + 물방울 | 60 BPM | `theme_snow_night` |

파일 이름은 `theme_{시간대}_{날씨}` 이다. 게임 코드의 `weatherFor()` 는 **등불 0~5칸이면 항상 비**라서 비 버전이 가장 많이 들린다. 등불이 차면서 비 → 가는 비 → 맑음으로 바뀌므로, 방이 밝아질수록 음악도 개는 흐름이 된다.

### 기웃 결과 (거짓 성공 금지 규칙을 소리에도)

다섯 결과 모두 **같은 길이(300ms)·같은 리듬(60+140ms)** 이다. 실패도 벌하지 않는다. 음정과 음색만 다르다.

| 결과 | 소리 |
|---|---|
| ✅ read | C→F 위로, 작은 반짝임 |
| 📚 builtin | 나무 소리 + 책장 넘김 |
| 🧪 simulated | C→D 로 매달린 채, 문 너머 메아리 |
| ❌ failed | 똑똑 노크 + D→C 로 내려앉음(부저·단2도·하강 다이브 없음) |
| ◌ none | 음 하나, 숨결 |

### 이벤트·효과음·환경음

- 출발 `depart_windup`(움츠림) → `depart_leave`. 집에 있기로 하면 같은 움츠림 뒤 `stay_settle`(같은 준비 동작, 다른 결말).
- 귀가 `return_home`, 기억 `remember_{장소}`(장소마다 짧은 동기), 포스터 `hang_poster`.
- 등불 `lantern_1`~`lantern_7` 은 F장조 음계를 한 칸씩 올라간다. 귀로 진행이 들린다. 8칸은 `room_complete` 팡파르(BGM 을 잠깐 멈춤).
- 희귀 티어 `rare_sparkle`, 시간대가 바뀔 때 `chime_{dawn,day,dusk,night}`.
- 말풍선 목소리 `voice_{a|u}_{음}`: 글자 하나에 소리 하나. 둥근 모음(ㅗㅜㅡ…)은 u, 나머지는 a. 기분별로 쓰는 음이 다르다(아래 표).
- 환경음: 날씨 바탕(`amb_rain` 등, 항상 하나) + 밤·계절 덧층(`amb_summer_night` 귀뚜라미, `amb_autumn`. 바탕 없이 소리만 있어서 바탕 위에 겹쳐 튼다) + 등불 온기(`amb_lantern_low/mid/high`, 칸이 찰수록 탁탁 소리가 촘촘해짐) + 덧층(`layer_drips` 처마 물방울, `layer_snowbells`, `layer_sparkle`, `layer_winter_chime`). 길이가 서로 소수라서(37·41·47·53·61·73초…) 겹쳐도 반복이 잘 들리지 않는다.

| 기분 | 말풍선 음 집합 | 글자 간격 |
|---|---|---|
| 보통 | A4 C5 D5 | 60ms |
| 폴짝 | C5 D5 F5 G5 (끝 글자는 가장 높게) | 50ms |
| 우쭐 | C5 F5 A5 | 65ms |
| 덤덤 | A4 C5 | 70ms |
| 졸림 | F4 G4 A4, 두 글자에 하나만 | 90ms |

## 4. 게임에 넣을 때 (연동하는 쪽 메모)

매니페스트에 규칙이 다 적혀 있다(`rules`, `map`). 요점만 적는다.

- **루프는 Web Audio 로 튼다.** `AudioBufferSourceNode` 의 `loop=true`, `loopStart=loop.start`, `loopEnd=loop.end`, 시작은 `start(t, loop.start)`.
  `<audio loop>` 는 쓰지 않는다. 인코더 패딩 때문에 틈이 생긴다. 파일 앞 0.5초와 뒤 1초는 이음새용 여유분이다(디코드 후 지연 0샘플을 Opus·AAC 모두 확인했다: `python3 src/check_loops.py bgm place amb`).
- **버스 다섯 개**: bgm / amb / sfx_event / sfx_ui / voice. 징글·이벤트의 `duck_db` 만큼 bgm 버스(그리고 amb 를 그 절반)를 내린다. 어택 60~80ms, 릴리스 0.5~0.9초. 멈추지 않고 내리기만 한다. `pause_bgm: true` 는 방 완성 하나뿐이다.
- **전환**: 장소는 다음 마디선(`bar_sec`)에서 1마디 크로스페이드, 최소 8마디 머문다. 시간대는 4마디 프레이즈 끝에서 페이드한 뒤 종(`chime_*`)을 울리고 새 곡을 처음부터 튼다. 날씨는 환경음 8~12초 크로스페이드 + `weather_shift`. 징글 중 `quantize: "beat"` 는 다음 박에 맞춰 시작한다.
- **변형 고르기**: `group` 이 같은 효과음은 직전과 다른 것을 고른다. 랜덤은 게임의 시드 PRNG 로 한다(`Math.random` 금지는 게임 규칙 그대로). 음높이를 흔들려면 ±15센트까지만 흔든다. 그 이상은 음 밖으로 나간다.
- **소리는 꺼진 채로 시작**하고, 처음 켤 때 `audio_on` 을 한 번 낸다(브라우저 자동재생 정책 + 조용한 게임). 밤에는 마스터를 −3 dB 내린다.
- `soundboard.html` 이 위 규칙을 그대로 구현한 작은 참고 구현이다(장면 믹서, 산책 재생, 덕킹, 마디선 전환, 말풍선 목소리).

## 6. 합성기에서 손본 것

- 볼륨은 칩처럼 60Hz·4비트 계단으로 움직이지만, 계단 모서리를 1.5ms 에 걸쳐 넘긴다. 오르골 같은 느린 감쇠에서 나던 지글거림이 사인 기준 −46dB 에서 −74dB 로 줄었다.
- 종 음색(`WAVES['bell']`)은 협화 배음(1·2·3·4·6)만 남겼다. 예전 표는 5배음(장3도)이 −2.3dB 로 커서 D 종에 F# 이 섞였다. 지금은 −39.5dB 다.
- 펄스파는 4배 오버샘플 + PolyBLEP 로 그려서 높은 음의 에일리어싱을 줄였다.
- 환경음은 노이즈가 많아 Opus 를 `-application lowdelay`, AAC 를 `-aac_coder fast` 로 따로 인코딩한다(`ambience.py`). 저비트레이트 기본 설정에서 노이즈가 1~2dB 작아지는 문제를 피하려고 그렇게 했다. BGM 은 디코드 후에도 −20.0 LUFS 를 확인했다.

## 7. 정직 메모

- **만든 쪽(Claude)은 소리를 들을 수 없다.** 그래서 귀 대신 숫자로 확인했다. 화성 검사기, 음 높이 FFT 확인(A4 = 440.0 Hz), 라우드니스 측정, 디코드 후 루프 이음새 검사, 스펙트로그램 눈검사를 거쳤다.
  그래도 "듣기 좋은가"는 사람 귀로만 판단할 수 있다. `soundboard.html` 로 들어 보고 마음에 안 드는 곡·소리를 알려 주면 악보나 악기 숫자를 고쳐 다시 굽는다.
- 진행(캐논 진행, 로열로드)은 관용구라 저작권 대상이 아니다. 파헬벨 캐논의 1바이올린 선율(라–솔–파–미–레–도–레–미)은 일부러 피했다.
- 리서치 문서의 일부 수치는 검색 요약에 기대고 있다. 각 문서에 확인 수준을 표시해 두었다.
