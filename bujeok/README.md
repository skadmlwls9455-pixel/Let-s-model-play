# 일주 부적 공방

사주 상담 신청자에게 나눠 줄 **일주 캐릭터 부적**을 조립하는 작은 사이트. 게임(저장소 맨 위)과는 상관없는 따로 된 정적 사이트라, 이 폴더만 있으면 돌아간다.

- 앞면: 노랑 바탕에 빨간 선, 살짝 오돌토돌한 손그림 선. 맨 윗줄에 해(예: `2027 丁未年`), 윗줄 · 아랫줄 글자를 따로, 가운데에 일주 캐릭터.
- 일주 캐릭터 120개: 60 일주 × 여 · 남. 직접 그린 그림으로 일주마다 바꿔 끼울 수 있다.
- 장식: 자리(왼쪽 위 · 머리 옆 · 발 옆 …)마다 소품을 고르거나, 소품 서랍에서 꺼내 끌어 놓는다.
- 뒷면: 빈 장. 고민이 풀린 장면을 직접 그려서 올린다.
- 고민 → 그림 아이디어: **유료 API 없이** 내 컴퓨터의 LLM(Ollama 등)이나 브라우저 안 모델로, 그릴 장면과 레퍼런스용 영어 이미지 프롬프트를 만든다.
- 내보내기: PNG(앞 · 뒤 · 나란히), 10 × 15 cm 인쇄. 만든 부적은 이 브라우저에 저절로 저장되고, 백업 파일로 옮길 수 있다.

## 여는 법

가장 쉬운 길 — 이 폴더에서 작은 서버를 띄우고 `http://localhost:8080` 을 연다. 이렇게 열면 Ollama 도 따로 설정 없이 붙는다.

```bash
cd bujeok
```

```bash
python3 -m http.server 8080
```

`index.html` 을 그냥 더블클릭해도 열리지만, 그때는 Ollama 쪽에 허락 설정(아래 `OLLAMA_ORIGINS`)이 필요하다.

인터넷 주소로 쓰고 싶으면 Vercel 등에 **이 폴더만** 올린다 (Vercel 이면 새 프로젝트의 Root Directory 를 `bujeok` 으로). 그때도 Ollama 에 그 주소를 허락해 줘야 한다.

## 만드는 순서

1. **일주** — 성별을 고르고, 양력 생일로 찾거나 60칸 표에서 고른다. 자시(밤 11시 반 이후) 출생을 다음 날로 넘길지는 보는 분 방식대로 체크.
2. **글자** — 배치(위아래 나눔 / 아래 두 줄), 해 표기, 윗줄 · 아랫줄, 글꼴, 가로 넓이 · 굵기 · 크기.
3. **장식** — 테마(건강 · 재물 · 합격 · 연애 · 일 · 마음)로 한 번에 채우고, 자리마다 바꾸거나 서랍에서 꺼내 끌어 놓는다. 고른 것은 ＋ － ↺ ↻ ⇋ 로 크기 · 각도 · 뒤집기, ⟲ 로 제자리.
4. **틀 · 색** — 도장틀 / 구름틀 / 한 줄 / 없음, 빛살 · 줄무늬 · 장식줄, 색 조합, 선 질감(0 매끈 ~ 2 거칠게), 낙관(내 서명 도장 — 기본 자리는 틀 오른쪽 띠 아래, 끌어서 옮길 수 있다).
5. **뒷면** — 빈 뒷면 PNG(1800 × 2700)를 받아 그림 앱에서 그 위에 그리고, 다 그리면 올린다. 흰 종이에 그린 선화는 ‘흰 바탕 지우기’나 ‘빨간 선으로’.
6. **그림 프롬프트** — 고민을 붙여 넣고 아이디어를 만든다 (아래 ‘로컬 LLM’).
7. **내보내기** — PNG 또는 인쇄. 카드 비율 2:3 이라 4×6(10 × 15 cm) 사진 인화에 그대로 맞는다.

카드 위 것들은 키보드로도 다룬다: <kbd>Tab</kbd> 으로 글자 · 캐릭터 · 장식을 차례로 고르고, 화살표로 옮기고(<kbd>Shift</kbd> 를 누르면 크게), <kbd>+</kbd> <kbd>−</kbd> 로 크기, <kbd>Delete</kbd> 로 장식 지우기, <kbd>Esc</kbd> 로 고르기 풀기. 끌어도 카드 밖으로는 나가지 않는다.

## 일주 캐릭터 규칙

| 천간 | 색 | 캐릭터가 지니는 것 | 자세 · 표정 |
|---|---|---|---|
| 갑 | 푸른 | 머리 위 작은 나무 | 만세 |
| 을 | 푸른 | 머리에 꽂은 꽃 | 두 손 모으기 |
| 병 | 붉은 | 등 뒤의 해 | 두 팔 활짝 |
| 정 | 붉은 | 손에 든 등불 | 등불 들기 |
| 무 | 황금 | 산 모양 고깔 | 허리에 손 |
| 기 | 황금 | 밀짚모자 · 새싹 화분 | 화분 안기 |
| 경 | 흰 | 투구 · 쇠 아령 | 아령 들기 |
| 신 | 흰 | 보석 머리띠 | 볼에 손 |
| 임 | 검은 | 파도 모자 | 손 흔들기 |
| 계 | 검은 | 우산 · 빗방울 | 우산 쓰기 |

- 지지는 동물(자 쥐 · 축 소 · 인 호랑이 · 묘 토끼 · 진 용 · 사 뱀 · 오 말 · 미 양 · 신 원숭이 · 유 닭 · 술 개 · 해 돼지).
- 같은 일주는 여 · 남이 동물 · 색 · 소품을 같이 쓰고, **여**는 리본 · 속눈썹 · 볼터치, **남**은 눈썹 · 목수건(모자가 없으면 앞머리 한 가닥)으로만 갈린다.
- 일주 색은 천간을 따른다 — 붉은 · 검은 몸은 얼굴 선을 크림색으로 뒤집어 잘 보이게 했다. ‘빨간 선만’을 고르면 색 없이 부적 선으로만 그린다.
- 발밑 물상(물결 · 풀 · 구름 …)은 기본으로 꺼 두었다. ① 일주 → 캐릭터 모양에서 켠다.

## 로컬 LLM (그림 아이디어)

고민 글은 고른 엔진의 주소로만 간다. 유료 API 는 쓰지 않는다. 엔진은 ⑥ → ‘엔진 설정’에서 고른다.

### Ollama (추천)

1. https://ollama.com 에서 설치.
2. 한국어가 되는 모델을 하나 받는다. 램 16GB 이상이면 `gemma3:12b`, 가볍게는 `gemma3:4b`, 한국어 특화로는 `exaone3.5:7.8b`.

```bash
ollama pull gemma3:12b
```

3. 사이트를 `http://localhost:…` 로 열었다면 끝. ‘모델 불러오기’를 누르면 받은 모델이 뜬다.

사이트를 **다른 주소**(Vercel 같은 인터넷 주소, 또는 파일 더블클릭)로 열었다면, Ollama 가 그 주소의 요청을 받도록 `OLLAMA_ORIGINS` 를 정해 주고 Ollama 를 다시 켠다. 아래 `https://내-사이트.vercel.app` 은 실제 주소로 바꾼다 (파일로 열었다면 `*`).

macOS:

```bash
launchctl setenv OLLAMA_ORIGINS "https://내-사이트.vercel.app"
```

Windows: 시스템 환경 변수에 `OLLAMA_ORIGINS` 를 같은 값으로 추가하고 Ollama 를 껐다 켠다.

Linux(systemd): `sudo systemctl edit ollama` 로 `Environment="OLLAMA_ORIGINS=https://내-사이트.vercel.app"` 를 넣고 다시 시작.

- 크롬이 “로컬 네트워크의 기기에 접근하도록 허용할까요?” 라고 물으면 허용.
- 사파리는 https 사이트에서 `http://localhost` 를 막을 수 있다. 그럴 땐 크롬 · 엣지를 쓰거나 사이트를 localhost 로 연다.

### LM Studio · llama.cpp · Jan (OpenAI 호환)

LM Studio 의 Developer 탭에서 서버를 켜고 **Enable CORS** 를 켠다. 주소는 보통 `http://localhost:1234/v1`.

### 브라우저 안에서 (WebLLM, 실험)

설치 없이 이 브라우저에서 돈다. 크롬 · 엣지 최신판(WebGPU)이 필요하고, 처음 한 번 모델(2~3GB)을 받는다. 작은 모델이라 아이디어가 단순할 수 있다.

### LLM 없이

고민 속 낱말(건강 · 시험 · 돈 · 연애 · 가족 …)로 준비된 장면을 고른다. 언제나 되지만 고민에 꼭 맞춘 장면은 아니다.

### 나오는 것

아이디어마다 장면 · 자세 · 소품 · ‘무엇이 무엇으로 바뀌었는지’ · 뒷면 한 마디, 그리고 **레퍼런스 이미지용 영어 프롬프트**(+ 네거티브). 영어 프롬프트는 ComfyUI · Stable Diffusion WebUI · Draw Things 같은 로컬 이미지 생성기에 붙여 넣어 구도 참고용 그림을 뽑는 데 쓴다. 끝에 붙는 화풍 문구는 ‘이미지 프롬프트 꼬리’에서 바꾼다. ‘LLM 에 보내는 글 전체 복사’로 다른 곳에 붙여 써도 된다.

## 저장 · 백업

- 만든 부적은 이 브라우저(IndexedDB)에 저절로 저장되고 ‘보관함’에 모인다. 서버로는 아무것도 보내지 않는다.
- 브라우저 데이터를 지우면 사라지니, 가끔 보관함 → ‘백업 파일 받기’. 다른 컴퓨터에서는 ‘백업 불러오기’.
- 백업 불러오기는 지우지 않고 합친다: 부적은 더 새 판만 들이고, 내 그림 · 글꼴은 지금 것이 있으면 그대로 둔다 (백업 쪽이 확실히 더 새것일 때만 바꾼다). 깨진 항목은 빼고 몇 개를 들였는지 알려 준다. 백업에 엔진 설정(LLM 주소)이 있으면 바꿀지 먼저 묻는다 — 고민 글이 가는 주소라서.
- 같은 부적을 두 창에서 열어도 서로 덮어쓰지 않는다. 다른 창이 먼저 저장했으면 이 창에서 고친 것은 ‘(이 창에서 고친 판)’으로 따로 저장된다.
- 사생활 보호 창처럼 저장이 안 되는 곳에서는 위쪽에 ‘임시 저장’이라고 계속 보여 준다. 저장이 실패하면(공간 부족 등) ‘저장 실패’와 함께 알림이 떠 있으니 백업 파일을 받아 둔다.

## 글꼴 · 그림

- 글꼴은 Google Fonts 의 한글 글꼴(푸어스토리 · 흑백사진 · 구기 · 싱글데이 · 감자꽃 · 하이멜로디 · 개구 · 주아 · 도현 · 해바라기 · 연성 · 나눔손글씨 펜 · 고운돋움, 한자는 Noto Serif KR). 모두 SIL Open Font License 라 나눠 주는 부적에 써도 된다. 내 글꼴(ttf · otf · woff · woff2)도 올릴 수 있다.
- PNG 로 내보낼 때는 쓰인 글자만 Google Fonts 에서 받아 그림 안에 넣는다 (인터넷이 필요).
- 캐릭터 · 소품 · 틀은 이 사이트에서 새로 그린 것.
