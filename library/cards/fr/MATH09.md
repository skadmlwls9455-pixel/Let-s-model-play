Comparer à l'œil des photographies de fil entortillé et comparer les caractéristiques mathématiques d'un nœud sont des tâches différentes. La description officielle des données de KnotInfo indique qu'il conserve, pour chaque invariant, une valeur et, lorsqu'il existe, un lien de référence bibliographique, associés par paire. Sur l'écran de recherche réel, un nœud peut être sélectionné par son nombre de croisements, et plusieurs invariants polynomiaux comme les polynômes d'Alexander et de Jones peuvent être choisis avec d'autres propriétés. Le nombre de courbures remarquables, les croisements qui apparaissent dans un dessin, la valeur d'un invariant choisi et le nom dans la base de données sont des informations de niveaux différents. Cependant, le fait que la base de données ait été consultée ne signifie pas que chaque entrée a été calculée de manière indépendante.

Les fonctions et la structure des sources de la base de données ont été confirmées, et les valeurs d'invariants de nœuds particuliers n'ont pas été calculées directement ici. L'égalité d'un seul invariant ne suffit pas pour affirmer l'équivalence de nœuds.
