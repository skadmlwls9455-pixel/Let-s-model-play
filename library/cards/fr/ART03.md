Flow-Lenia est présenté comme une extension de Lenia dans laquelle la masse est conservée. L’équipe de recherche rapporte qu’en incluant dans la dynamique les paramètres qui déterminent les propriétés d’un motif, elle a rendu possible la simulation conjointe de plusieurs sortes de motifs. Dans certains modèles, changer une règle globale modifie le monde entier, tandis que, dans d’autres conceptions, différents paramètres locaux sont placés dans le même espace. La simulation multi-espèces du texte original n’est pas une garantie qu’une complexité toujours nouvelle apparaisse sans fin.

La source consultée est le résumé de l’article publié par l’institution de recherche. La présentation de la conservation de la masse et des modèles multi-espèces a été confirmée, mais le code des expériences et les résultats d’évolution à long terme n’ont pas été reproduits de manière indépendante.
