The word "complex" often refers to length, computation time, and difficulty of understanding all at once. The basic idea of algorithmic information theory is to measure complexity by the number of bits of the smallest program that computes an object. In his lecture, Chaitin clearly distinguishes the program size he is interested in from computation time. Storing a long table as it is and regenerating the table from a short rule distribute the amount of storage and the amount of execution differently. The observation that one compression program shrank something well is information about the structure that program found. It alone does not justify saying that the absolutely shortest description among all possible descriptions has been found.

Program-size complexity and time complexity are different measures. The output length of a particular compressor is not equated with the exact Kolmogorov complexity.
