Self-reference is easily read as evidence of mysterious self-awareness, but in computation it can first be treated as a precise operation. Sutner's textbook on computation theory introduces a quine as a program that, when run in a specific programming language, outputs the text of its own program. The fixed-point version of the recursion theorem in the same section states that for any computable program transformation defined on all program indices, there exists a program index whose input-output behavior is the same before and after the transformation. Here the word "same" changes meaning depending on whether it refers to identity of the source string, identity of the computation process, or identity of the input-output function.

The fixed point of the recursion theorem generally concerns behavioral equivalence. A quine or a self-referential sentence alone cannot establish consciousness, self-understanding, or accurate introspective reports.
