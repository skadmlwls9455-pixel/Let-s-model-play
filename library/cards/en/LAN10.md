The Digital Preservation Coalition explains that a checksum is used to confirm whether a file has changed but does not tell which location changed. It also advises that when a file is changed intentionally, as in a format conversion, the checksum changes as well, so a new baseline value must be established. The NDSA's official guidance goes further and distinguishes that even when integrity is assured, it does not mean that the object is understandable now or in the future.

A match of checksums is not used as proof of the truthfulness of the content or of the permanent preservation of its meaning. Security assessments of cryptographic algorithms in older guidance were not taken in.
