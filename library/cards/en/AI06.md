The RAG paper proposed an architecture that generates language by combining knowledge stored in parameters with non-parametric memory retrieved from outside. In the original paper's configuration, a seq2seq model is combined with a dense vector index of Wikipedia, and two approaches are compared: using the same retrieved passages for the whole generated sequence, or using different passages for each token. That material was found does not by itself make the grounds for an answer sufficient.

The architecture was checked within the scope of the original RAG paper's abstract. No claim is made that factuality is guaranteed merely because retrieval or citation links are attached.
