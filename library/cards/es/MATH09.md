Comparar a simple vista fotografías de hilo enredado y comparar las características matemáticas de un nudo son tareas distintas. La descripción oficial de los datos de KnotInfo afirma que almacena, para cada invariante, un valor y, cuando existe, un enlace de referencia, emparejados. En la pantalla de consulta real, un nudo puede seleccionarse por su número de cruces, y pueden elegirse varios invariantes polinómicos, como los polinomios de Alexander y de Jones, junto con otras propiedades. El número de curvas llamativas, los cruces que aparecen en un dibujo, el valor de un invariante elegido y el nombre en la base de datos son información de niveles distintos. Sin embargo, el hecho de que se haya consultado la base de datos no significa que cada entrada se haya calculado de forma independiente.

Se confirmaron las funciones y la estructura de fuentes de la base de datos, y aquí no se calcularon directamente los valores de los invariantes de nudos concretos. La igualdad de un solo invariante no basta para afirmar la equivalencia de nudos.
