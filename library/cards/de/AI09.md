World Models ist eine Forschungsarbeit, die eine Policy lernt, indem sie ein Modell nutzt, das Beobachtungen einer Umgebung komprimiert und vorhersagt, wie sie sich im Zeitverlauf verändern. Die Autoren berichteten von einem Experiment, in dem eine in einer erzeugten inneren Umgebung trainierte Policy in die ursprüngliche Umgebung des bestärkenden Lernens übertragen wurde. Der Ausdruck Traum bezieht sich hier auf die erzeugte Simulation und ist kein Ausdruck, der ein subjektives Traumerleben belegt. Die innere Umgebung kann Lücken haben. Nutzt der Agent diese Lücken aus, kann er drinnen gut abschneiden, in der ursprünglichen Umgebung aber scheitern. Die Autoren beschrieben auch einen Ansatz, der solche Ausnutzung verringert, indem die Unsicherheit der erzeugten Umgebung angepasst wird.

Die tatsächliche Umgebung der Arbeit meint die ursprüngliche Spielumgebung. Der Erfolg dieser Übertragung wird nicht auf eine Verallgemeinerung auf die reale physische Welt insgesamt ausgeweitet.
