Die Vorstellung von Nichts, das Zeichen, das in einer Ziffernschreibung eine leere Stelle markiert, und die Zahl 0, die an Rechnungen teilnimmt, sind verschieden. In 105 zeigt die 0 an, dass die Zehnerstelle leer ist. Wird dieses Zeichen entfernt, wird daraus 15, und der Wert ändert sich. Dagegen wird in der Rechnung, bei der 0 zu 5 addiert wird, die 0 selbst als Zahl behandelt.

Auch die babylonische Stellenwertschreibung verwendete ein Zeichen, um eine leere Stelle anzuzeigen. Eine Schreibweise zu haben, die eine leere Stelle kenntlich macht, und allgemeine Rechenregeln für das Addieren und Subtrahieren von 0 zu haben, sind jedoch verschiedene Stufen.

Der indische Mathematiker Brahmagupta behandelte in einem Werk von 628 Rechenregeln, die 0 und negative Zahlen einschließen. Er schrieb auch die Regeln nieder, dass das Addieren oder Subtrahieren von 0 eine Zahl unverändert lässt und dass die Multiplikation mit 0 den Wert 0 ergibt. Seine Erklärung des Problems der Division durch 0 stimmte jedoch nicht mit der heutigen Arithmetik überein.

Die Geschichte der 0 lässt sich schwer als ein einzelner Augenblick zusammenfassen, in dem das Nichts zum ersten Mal gedacht wurde. Es ist eine Geschichte, in der die Arten, eine leere Stelle zu schreiben, und die Regeln für das Rechnen mit der Zahl über viele Zeiträume hinweg verfeinert wurden.
