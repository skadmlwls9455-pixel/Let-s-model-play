L'idée de rien, le symbole qui marque une place vide dans un nombre écrit, et le nombre 0 qui prend part au calcul sont distincts. Dans 105, le 0 indique que la place des dizaines est vide. Si ce signe est retiré, on obtient 15, et la valeur change. En revanche, dans le calcul qui ajoute 0 à 5, le 0 lui-même est traité comme un nombre.

La notation de position babylonienne employait elle aussi un symbole pour indiquer une place vide. Cependant, disposer d'une notation qui distingue une place vide et disposer de règles générales de calcul pour ajouter et soustraire 0 sont des étapes différentes.

Le mathématicien indien Brahmagupta a traité, dans une œuvre de 628, des règles de calcul qui incluent 0 et les nombres négatifs. Il a aussi écrit les règles selon lesquelles ajouter 0 à un nombre ou le soustraire de ce nombre le laisse inchangé, et multiplier par 0 donne 0. Cependant, son explication du problème de la division par 0 ne concordait pas avec l'arithmétique d'aujourd'hui.

L'histoire du 0 se résume difficilement à un seul moment où le néant aurait été conçu pour la première fois. C'est une histoire dans laquelle les manières d'écrire une place vide et les règles du calcul avec ce nombre ont été affinées au cours de nombreuses périodes.
