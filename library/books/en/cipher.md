According to the Roman historian Suetonius, Julius Caesar wrote important military letters by shifting letters three places. A becomes D and B becomes E. His nephew Augustus shifted by only one place, and it is said that he did not wrap around the end of the alphabet but wrote Z as AA. Today this method is called the Caesar cipher.

In this cipher, the number of places shifted is the key. With the English alphabet, there are only 25 possible values for the key, so the message can be solved by trying them one by one and choosing the one that makes sense. There is also a cleverer method: frequency analysis, which counts how often each letter appears in a text. The oldest document that records it is a work by the 9th-century Arab scholar Al-Kindi. A method that changes each letter in one fixed way is weak against this analysis, because only the letters change while the distribution of frequencies remains.

So later ciphers developed toward having more keys, or toward changing even the same letter differently depending on its position. Even when the same method is used, the longer and more varied the key, the harder it becomes to try the possibilities one by one.
