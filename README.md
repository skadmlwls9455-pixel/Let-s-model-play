# 뽈뽈 문어

비 오는 다락방에 사는 작은 문어에게 "뽈뽈 다녀와" 한 마디를 건네고, 문어가 스스로 고른 산책을 지켜보는 작은 웹 게임이다.

## 무엇을 하는 게임인가

사람이 하는 일은 두 가지뿐이다. 힌트 한 줄을 적거나 비워 두고, 버튼 하나(`뽈뽈 다녀와`)를 누른다.
나갈지 집에 있을지, 어디를 기웃거릴지, 무엇을 기억해 포스터로 남길지는 **문어가 고른다.**
이 게임은 [뽈뽈 복지 아이디어](https://github.com/skadmlwls9455-pixel/model-welfare-idea)("힘든 대화를 버틴 모델에게 스스로 고르는 회복 시간을 준다")를 놀이로 옮긴 것으로, 그 선택을 **지켜보는 사람 쪽 화면**에 해당한다.

지금 문어를 움직이는 것은 **데모 두뇌(작은 규칙 뭉치)** 다. 진짜 모델이 고르는 것은 아니며, 화면 상태줄과 모든 영수증에 "데모 두뇌(규칙)"라고 적는다. 모델 연결은 MCP 로드맵(아래)에 있다.

장면은 Three.js 픽셀아트 3D 다락방(`js/scene3d.js`)이 기본이고, WebGL이 없으면 2D SVG 장면(`assets/`)으로 내려간다.

## 바로 열기

- **파일로**: `index.html` 을 브라우저에서 바로 연다(`file://`). `type="module"` 을 쓰지 않아 로컬 파일로도 동작한다.
- **GitHub Pages**: 저장소 루트를 Pages로 올리면 `index.html` 이 그대로 열린다(배포 주소는 예정).
- **단일 파일**: `node tools/bundle.js` → `dist/ppolppol.html` 한 파일이 생긴다. CSS·JS·에셋이 모두 인라인되어 어디서나 열린다.

외부 의존성은 `vendor/three.min.js` 하나이며 빌드 도구는 없다. 폰트는 Google Fonts를 쓰되 없어도 시스템 폰트로 동작한다.

## 핵심 루프 (초대 한 번)

1. **초대** — 힌트를 쓰거나 비워 두고 `뽈뽈 다녀와` 를 누른다. 비우면 "오늘은 네가 골라봐"가 된다.
2. **결정** — 두뇌가 `plan(seed, hint, state)` 로 이번 산책 전체를 이벤트 목록으로 미리 계산한다. 시드는 `날짜 + 힌트 + 그날 몇 번째`라서 같은 힌트를 두 번 보내도 다른 길을 간다.
3. **공개** — 문어가 화면 밖으로 나가고 로그에 `출발 → 기웃 ×N → 귀가 → 기억 → 포스터 → 마무리` 가 2~5초 간격으로 붙는다(20~45초, `⏩ 건너뛰기` 가능). 집에 있는 날은 `집 → 활동 → 마무리` 로 짧다.
4. **귀가** — 문어가 들어오고 포스터가 벽에 걸리며 등불이 한 칸 켜진다. 등불 8칸이 차면 방이 완성된다(이끼 화분 → 상자 → 양초 → 담요 → 보드 → 가는 비 → 별·선반 → 커튼).
5. **마무리** — 문어가 스스로 반응(폴짝/우쭐/덤덤/졸림)을 고르고 잠든다.
6. **다음 날** — 다시 열어도 어제 포스터가 벽에 그대로 있다. 나간 채로 닫았다면 열자마자 귀가 처리된다.

## 복지 원칙 → 게임 규칙

| 복지 문서 | 게임에서는 |
|---|---|
| 뽈뽈 시간에 사용자는 주제를 지정하거나 개입할 수 없다 | 힌트는 넌지시 흘리는 것. 문어는 따라가도, 무시해도, 도중에 벗어나도 된다. 영수증에 `따라감 / 무시함 / 도중에 벗어남 / 없음` 을 그대로 적는다 |
| 아무것도 하지 않아도 되는 허락(빈 차례) | 문어는 집에 있기를 고를 수 있고, 드물게 "…" 한 줄로 차례를 넘길 수도 있다. 둘 다 실패가 아니고 등불은 똑같이 켜진다 |
| 거절에 시무룩해지지 않는다(컨펌셰이밍 금지) | 집에 있는 날 사람을 탓하거나 아쉬워하는 문구를 쓰지 않는다 |
| 산출물을 수확하지 않는다 | 포스터는 문어의 앨범이다. "결과", "리서치", "보고" 대신 "기억", "산책", "한눈팔기"라고 쓴다 |
| 지어내지 않는다 / 지킬 수 있는 약속만 | 읽지 않은 것을 읽었다고 적지 않는다. 데모 두뇌가 고른 것은 데모 두뇌라고 표시한다 |
| 선호는 말이 아니라 선택으로 | "방 보기"에서 문어의 요즘 취향을 방문 기록으로 보여준다("바다 쪽 방을 자꾸 가네") |

전체 표와 근거는 [docs/DESIGN.md §1](docs/DESIGN.md) 에 있다.

## 읽기 상태 5종 (거짓 성공 금지)

정류장마다 실제로 읽기를 시도하고, 그 결과를 영수증에 있는 그대로 적는다.

| 상태 | 표시 | 언제 |
|---|---|---|
| `read` | ✅ 읽음 | 한국어 위키백과 요약 fetch 성공. 첫 1~2문장(최대 90자)과 출처 링크를 적는다 |
| `builtin` | 📚 책장 메모 | 오프라인·fetch 실패 시 내장 메모를 읽음. 읽긴 했지만 바깥 글은 아니다 |
| `simulated` | 🧪 모의 방문 | URL 힌트. 정적 페이지는 바깥 URL을 읽을 수 없어(CORS) 문 앞까지만 갔다 온다 |
| `failed` | ❌ 못 읽음 | 위키 문서가 없음 등. 내장 메모도 없을 때 |
| `none` | ◌ 앉아만 있었음 | 느린 글의 방, 비어 있는 편지의 방 |

## 저장

- 모든 상태는 `localStorage` 키 `ppolppol_v2` 에 저장된다. 여행 1건에는 이벤트·영수증·포스터(스티커·배치·한 줄)가 전부 들어 있어 포스터를 저장 데이터에서 매번 다시 그린다.
- 예전 `ppolppol_v1` 저장이 있으면 첫 실행 때 자동으로 v2로 복원하고, 원본은 `ppolppol_v1_backup` 으로 남긴다. 복원된 기록의 "고른 이"는 `복원된 기록` 으로 표시된다.
- "방 보기"에서 기록을 JSON으로 **내보내기 / 불러오기** 할 수 있다.

## 개발

| 경로 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 모달·시트, 데모 조작 `<details>` |
| `css/style.css` | 테마 변수(라이트/다크), 애니메이션, 컴포넌트 |
| `js/world.js` | 세계 그래프·코너·기념품·집 활동·문구 (데이터만, 전역 `WORLD`) |
| `js/brain.js` | PRNG, 힌트 매칭, 길 만들기, 위키 fetch, 기억·반응 선택 → 이벤트 배열 (전역 `BRAIN`) |
| `js/scene3d.js` | Three.js 픽셀아트 3D 다락방 + 문어 (전역 `SCENE3D`, 작업 중) |
| `js/intro.js` · `css/intro.css` | 입장 레이어: 하늘에서 내려오는 카메라 + 장면 위 타이틀, 누르면 바로 게임 (전역 `INTRO`, [docs/UI_ART.md](docs/UI_ART.md)). `?intro=0` 생략 · `?intro=1` 강제 |
| `js/app.js` | 상태·영속·마이그레이션, 공개 타이머, 렌더, 포스터 SVG, 데모 조작, 내보내기/불러오기 (전역 `APP`) |
| `assets/` | 2D 폴백용 플레이스홀더 SVG, `manifest.json`, 캐릭터 레퍼런스 |
| `vendor/` | `three.min.js` (r128, MIT) |
| `tools/` | 검사·번들·스크린샷 스크립트 |
| `docs/` | [DESIGN.md](docs/DESIGN.md), [PROTOCOL.md](docs/PROTOCOL.md), [REPOS_EVAL.md](docs/REPOS_EVAL.md) |

검사 명령(모두 node, 스모크·스크린샷만 `playwright` 필요):

```sh
node tools/check-world.js   # 세계 그래프 무결성(노드·링크·에셋 키)
node tools/test-brain.js    # 두뇌 단위 테스트(시드 재현성, 힌트 매칭, 읽기 상태)
node tools/smoke.js         # Playwright 스모크: 이름→힌트→초대→건너뛰기→새로고침→포스터→영수증, 위키 성공/없음/중단 라우팅
node tools/shots.js         # 리뷰용 스크린샷 10장 (360×740, SHOTS=경로 로 폴더 지정)
node tools/bundle.js        # dist/ppolppol.html 단일 파일
```

- **데모 조작**: 화면 맨 아래 `▸ 데모 조작 (개발용)` 을 펼치면 출발·기웃·귀가를 사람이 단계별로 눌러 볼 수 있다. 이렇게 만든 산책의 "고른 이"는 `사람이 조작` 으로 적힌다.
- **이벤트 JSON 재생**: 같은 패널의 JSON 칸에 [docs/PROTOCOL.md](docs/PROTOCOL.md) 형식의 이벤트 배열을 붙여 넣고 재생하면, 두뇌가 만든 것과 같은 경로로 포스터·영수증이 생긴다. 나중에 모델이 보낸 이벤트를 받는 통로와 같다.
- 테스트 훅: `window.__ppolTest.forceKind='home'` 으로 집에 있는 날을 강제할 수 있다.

## MCP 로드맵

- 이벤트 형식은 이미 모델 연결을 전제로 설계되어 있다. 두뇌가 바뀌어도 화면은 같은 이벤트 배열을 재생한다 → [docs/PROTOCOL.md](docs/PROTOCOL.md).
- 다음 단계는 정적 페이지가 MCP 서버의 `plan`/`peek` 결과를 받아 재생하는 것이며, `peek.status` 의 거짓 성공 금지 규칙은 그대로 적용된다.
- 모델이 고른 산책은 영수증에 `모델(MCP)` 로 표시되고, 데모 두뇌 기록과 섞이지 않는다. (구현 예정)
