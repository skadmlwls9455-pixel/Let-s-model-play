# 6차 공통 지시문 — 먼저 이것을 읽고, 그다음 네 갈래 지시문을 읽는다

너는 "뽈뽈 문어" 의 새 기능 한 갈래를 맡은 세션이다. 주인은 지금 답할 수 없다. **묻지 말고 끝까지 한다.**
작은 선택이 남으면 주인 말에 가장 가까운 단순한 쪽으로 하고 보고서 '정한 것' 에 적는다.

## 1. 게임 한 줄

작은 힐링 폰 웹 게임 (세로 화면). AI 모델이 문어로 다락방에 살고, 사람은 산책에 초대만 한다 — 갈지 · 어디 갈지는 문어가 정한다.
사람에게는 내 캐릭터 · 놀이방 (달리기 오락기 · 부엌) · 위층 옷방 · 마당 텃밭이 있다.
바닐라 HTML/CSS/JS, 빌드 없음, `type="module"` 없음, three.js r128 픽셀 장면. 플레이어 글은 한국어 반말.

이번 6차의 목표 (주인 11-18): 게임이 "작고 답답하다". 생활 시뮬처럼 넓힌다 —
마당 → 길 → **문어 마을** → **해변 · 바다**, 매일 조금 바뀌는 줍기, 도감, 놓아둔 것을 보고 오는 손님, 자유로운 꾸미기,
문어와 사진, 계절 축제, 친구 집 방문.

## 2. 누가 무엇을 하나 (겹치지 않게)

**가장 중요한 규칙: 기존 파일은 한 글자도 고치지 않는다.** (읽는 것은 얼마든지.)
`index.html` · `js/app.js` · `js/scene3d.js` · `css/*.css` · `package.json` · `tools/smoke.js` · `tools/export-site.js` · `vercel.json` ·
`.github/` · `assets/manifest.json` 을 포함해 지금 있는 파일 전부가 대상이다. 본 게임에 잇는 일은 리드가 한다.
네 모듈을 이으려면 기존 파일의 어디에 무엇이 필요한지는 보고서의 **'리드가 이을 것'** 에 줄 단위로 적는다.

## 3. 파일 자리 (이미 배포 목록에 등록돼 있다 — `npm test` 가 그대로 통과한다)

| 무엇 | 자리 |
|---|---|
| 실행 코드 | `js/next/<이름>.js` (IIFE · 전역 하나 · ES5 문법: `var` · `function`) |
| 화면 모양 | `css/next/<이름>.css` — 선택자 · id · CSS 변수 · `@keyframes` 이름은 **모듈 머리글자로 시작** 한다: swim `sw-` · book `bk-` · forage `fg-` · guests `gs-` · photo `ph-` · visit `vs-` · decor `dc-` (창의 id 는 `<머리글자>-dlg`). `body` · `button` · `dialog` · `:root` 같은 맨 선택자에 규칙을 걸지 않는다 (시험용 쪽만의 바탕은 그 html 안 `<style>` 에). 본 게임의 클래스 (`.btn` · `.sheet` …) 를 빌려 쓰지 않고 `css/style.css` 를 싣지 않는다 — 나중에 같은 쪽에 같이 실린다 |
| 시험용 쪽 | `next/<이름>.html` — `file://` 로 바로 열린다. `<head>` 에 `<base href="../">` 를 넣어 본 게임과 같은 **저장소 뿌리 기준 경로** 를 쓴다 (`js/next/…` · `assets/next/…` · `vendor/…`). 기존 파일은 **읽기만** 한다 |
| 그림 | `assets/next/<이름>/<id>.png` (32×32 한 벌 — 목록은 1배, 도감은 2배로 쓴다. 16px 를 따로 그리지 않는다) + `assets/next/<이름>/manifest.json` (`{ "id": "파일.png" }` — 리드와 도구가 보는 목록이다. 모듈은 실행 중에 읽지 않는다: `file://` 에서는 fetch 가 막힌다) |
| 그림 만드는 도구 | `tools/next/make-<이름>-art.js` (코드로 픽셀을 찍어 PNG 로. 외부 그림 내려받기 금지). 본보기 `tools/make-souvenirs32.js` · `tools/ui-art/` 는 **읽기만 하고 돌리지 않는다** (돌리면 `assets/manifest.json` 을 다시 쓴다). 네 도구는 `tools/ui-art/pixel-out.js` 의 `encodePNG` 를 require 해서 `assets/next/<이름>/` 에만 쓴다 |
| 빠른 시험 (node) | `tools/next/test-<이름>.js` — DOM 없이, 5초 안 |
| 화면 시험 (Playwright) | `tools/next/test-<이름>-live.js` — 네 시험용 쪽만 연다 |
| 문서 | `docs/next/<이름>.md` — 규칙 · API · 저장 칸 · '리드가 이을 것' |
| 메모 · 보고 · 스크린샷 | `wip/round6-world/notes/<갈래>.md` · `wip/round6-world/reports/<갈래>.md` · `wip/round6-world/shots/<갈래>/` |

- 공용 시드 난수: `js/next/prng.js` (전역 `NEXT_PRNG`, node 에서는 `require`). 고치지 말고 쓴다.
- 새 최상위 폴더 · 새 `api/*.js` 함수 파일 · 새 npm 의존성을 만들지 않는다 (Vercel 무료 요금제의 함수 수 한도가 있다).

## 4. 지킬 선 (하나라도 어기면 'must' 결함)

5차의 **지킬 선 11개** 를 그대로 지킨다 — 이 절 끝에 옮겨 적었다. (`wip/round5/briefs/COMMON.md` 의 다른 절 — Setup · How to work · lanes — 은 5차 것이라
따르지 않는다. 그 파일을 열 필요가 없다.) 이번 갈래에 특히 걸리는 것과 더한 것:

1. **문어 (모델) 에 대해 지어내지 않는다.** 문어가 무엇을 좋아한다 · 느낀다 · 먹는다 · 말했다는 글과 연출을 코드가 만들지 않는다.
   네 모듈에는 지시문이 따로 말하지 않는 한 **문어가 나오지 않는다** (헤엄치는 것 · 줍는 것 · 찍는 것은 내 캐릭터다).
2. **문어는 일꾼이 아니다.** 조개 (돈) · 재료 · 설계도가 문어 산책이나 문어의 선택에서 나오게 하지 않는다. 전부 사람의 놀이에서 나온다.
3. **압박 없음.** 연속 출석 · 남은 시간 표시 · 줄어드는 막대 · '오늘만' · 놓친 것 표시 · 뽑기 (확률 상자) · 재촉 알림 · 실패 화면 없음.
   쉬어도 잃는 것이 없다. 드문 것은 시드가 정하되 갈아서 얻는 길이나 '곧 떠나' 가 없다.
4. **결정은 시드로.** 결정 · 결과 코드에 `Math.random` 금지 (`grep -n "Math.random" 네 파일` 0건). 날짜는 `NEXT_PRNG.dateKey()` (로컬 날짜).
5. **코드는 사실만 적는다.** 도감 · 기록 문구는 "11월 18일에 처음 봤어 · 3번" 같은 사실. 취향 · 감정 말 ("참새가 너를 좋아해") 금지.
6. **플레이어 글에 이모지 · 꾸밈 기호 없음.** 한글 · 숫자 · 기본 문장부호 · 가운뎃점만. 그림은 직접 찍은 픽셀 그림.
7. **소리는 넣지 않는다** (본 게임 소리는 기본 꺼짐이고 소리 파일은 리드 몫). 진동도 부르지 않는다.
8. **남의 게임을 베끼지 않는다.** 상업 게임의 이름 · 캐릭터 · 그림 · UI 를 코드 · 문서 · 커밋 · 화면 글 어디에도 쓰지 않는다. 원리만.
9. **저장을 건드리지 않는다.** `ppolppol_v2` · `ppolppol_cook_v0` · `ppolppol_runner` 를 쓰지도 지우지도 않는다.
   시험용 쪽의 저장은 `ppolppol_next_<이름>` 키만 (모두 `try/catch`).
10. **이름을 넣지 않는다.** 주인의 이름 · 닉네임 · 메일, 모델 · 에이전트 이름을 코드 · 주석 · 문서 · 커밋 글에 쓰지 않는다
    (도구가 스스로 붙이는 귀속 줄은 그대로 둔다 — 지우려고 설정이나 커밋을 고치지 않는다).
    **절대 경로도 적지 않는다** — 이 세션은 주인 컴퓨터에서 돈다. 홈 폴더 이름이 곧 주인 이름일 수 있다. 코드 · 시험 · 문서 · 메모 · 보고 · 커밋 글의 경로는
    저장소 뿌리 기준으로 쓰고, 시험은 `path.join(__dirname, …)` 로 연다. 명령 출력을 메모에 붙일 때도 경로를 지운다.
    커밋 전마다 `git diff --cached | grep -n "/Users/\|/home/\|C:\\\\"` 가 0건인지 본다 (저장소는 공개이고 강제 push 가 금지라 새면 못 지운다).
11. **돈 이름은 '조개'.** 줍는 물건 · 기념품 이름에 '조개' 를 쓰지 않는다 ('소라 껍데기' 처럼 다른 이름으로).
    문어가 산책에서 가져오는 기념품 16종 (`js/world.js` 의 souvenirs) 과 같은 이름 · 같은 그림의 물건을 만들지 않는다.
12. **다른 세션의 것을 만들지 않는다.** 요리 · 먹기 · 놀이방 식탁과 소파 · 달리기 · 로딩 화면은 다른 세션이 만드는 중이다.
    네 모듈이 음식을 다루면 (도감) 넘겨받은 줄을 읽기만 하고, 요리 수가 하나에서 셋으로 늘어도 그대로 돌게 수를 박아 두지 않는다.
13. **글자는 흔한 것으로.** 화면 글에 드문 한글 음절 · 새 기호 (화살표 · 수학 기호 · 상자 그림 문자) 를 쓰지 않는다 — 작은 글꼴 파일에는 흔한 2,350자와
    지금 쓰는 글자만 들어 있어, 그 밖의 글자 하나가 큰 글꼴 파일을 통째로 내려받게 한다.

**5차의 지킬 선 11개 (옮겨 적음):**
(1) 모델에 대해 속이지 않는다 — 문어가 무엇을 느낀다 · 좋아한다 · 원한다, 읽지 · 고르지 · 말하지 않은 것을 했다고 말하거나 비치지 않는다. 코드가 쓴 글이 모델의 말로 보이면 안 된다.
(2) 모델이 쓴 말은 고치지도, 몰래 자르지도, '바로잡지' 도 않는다. (3) 문어를 조종하지 않는다 — '안 가' 와 집에 있기는 늘 되고 값이 없다.
(4) 거절은 담담하게 — 시무룩한 얼굴 · 효과음 · 재촉 없음. (5) 연속 출석 · 놓칠까 봐 불안 · 뽑기 · 카운트다운 압박 · 밀어붙이는 알림 없음.
(6) 플레이어 글에 이모지 · 유니코드 기호 없음 (한글 · 숫자 · 기본 문장부호 · 가운뎃점). 아이콘은 픽셀 그림. (7) 소리는 기본 꺼짐 — 손짓 없이는 아무것도 틀지 않는다.
(8) 부엌에 실패 · 점수 · 시간 제한 · 메달 없음. (9) 상업 게임의 이름 · 그림 · UI 를 쓰지도 베끼지도 않는다 (원리는 된다).
(10) 저장은 잃지도 망가뜨리지도 않는다 (`ppolppol_v2` · `ppolppol_cook_v0` · `ppolppol_runner`). (11) 주인의 이름 · 닉네임 · 메일을 어디에도, 모델 · 에이전트 이름을 코드 · 주석 · 문서 · 커밋 글에 쓰지 않는다 (도구가 붙이는 귀속 줄은 괜찮다).

## 5. 모듈끼리의 약속 (갈래들이 서로를 기다리지 않게)

- **사람 쪽 상태는 넘겨받은 `user` 객체에만 쓴다.** 네 규칙 함수는 `fn(user, …, dateKey)` 꼴의 순수 함수다 (DOM · 저장 없이 node 에서 돈다).
  본 게임에서는 리드가 저장 속 `S.user` 를 넘긴다. 칸 이름은 아래로 고정한다 — 없으면 네 함수가 `{}` 로 만든다, 모르는 id 는 지우지 않는다.

  | 칸 | 모양 | 주인 갈래 |
  |---|---|---|
  | `user.shells` | 수 (조개) — **읽기만.** 값을 치르는 함수는 `{ ok, cost }` 를 돌려주고 빼기는 리드 훅이 한다 | (기존) |
  | `user.mats` | `{ 물건 id: 개수 }` 가방 | F |
  | `user.finds` | `{ 물건 id: 처음 주운 날 }` | F |
  | `user.pick` | `{ day, got: { 자리 id: 1 }, list: { 구역: [{ spot, item }] } }` 오늘 주운 자리와 그날 놓였던 목록 | F |
  | `user.pickPrev` | 어제의 `pick` (하루 이월 계산용 — 날이 바뀔 때 `pick` 을 여기로 옮긴다) | F |
  | `user.plans` | `{ 물건 id: { at, from: 'season' \| 'friend' \| 'box' } }` 아는 설계도 | F |
  | `user.made` | `{ 물건 id: 처음 만든 날 }` | F |
  | `user.furn` | `{ 가구 id: 가진 개수 }` | F (만들기) · D (목록) |
  | `user.sea` | `{ 바다 것 id: { first, n } }` 헤엄에서 본 것 | S |
  | `user.guests` | `{ 손님 id: { first, n, last } }` | G |
  | `user.guestWait` | `{ 손님 id: { since, came } }` 드문 손님의 달력 날 세기 | G |
  | `user.foods` | `{ 음식 키: 처음 만든 날 }` | B |
  | `user.poses` | `{ 모션 id: 가진 날 }` | P |
  | `user.shown` | `{ 물건 id: 전시한 날 }` 도감 진열장에 올려 둔 것 | B |
  | `user.visitDay` | `{ day, n }` 오늘 친구 집에서 받은 설계도 수 | H |
  | `user.bookSeen` | `{ 탭: 마지막으로 열었을 때 찾은 수 }` 도감의 '새로 생긴 것' 점 | B |
  | `user.placed` | `[{ id, zone, x, z, r }]` 놓은 가구 — zone 은 `in` · `yard` · `beach`, x · z 는 m (소수 둘째 자리), r 은 도, 60개까지 | 리드 (G 는 그 구역에 놓인 것을 `{ id: 개수 }` 로 세어 받고, H 는 그대로 스냅샷 `furn` 에 담는다) |
  | `user.skin` | `{ wall: 프리셋 id, floor: 프리셋 id }` | 리드 (id 는 D 의 SKINS) |

  이미 있는 칸 (읽기만 — 리드와 본 게임 것): `user.dyes` `{ 색 id: 개수 }` 텃밭 염료 · `user.dyed` 물건별 물들인 색 · `user.look` 지금 모습.
  **이미 쓰는 이름 — 새 칸으로 쓰지 않는다:** `shells` · `seeds` · `dyes` · `days` · `giftDay` · `giftTell` · `garden` · `plotTold` · `dye` · `dyed` · `earned` · `week` · `sets` (`week` 는 주간 할 일이다 — '주마다 한 번' 을 여기에 적지 않는다), 그리고 다른 세션의 먹기가 새로 쓰는 `table` · `meals`.
  위 표에 없는 칸이 필요하면 `user.<네 전역 이름 소문자>_…` 로 시작하는 이름으로 만들고 보고서 '저장 칸' 에 적는다 (다른 갈래 · 다른 세션과 겹치지 않게).

- **목록은 `CATALOG` 로 내놓는다.** 물건 · 바다 것 · 손님 · 가구 · 모션을 가진 모듈은 `X.CATALOG = [{ id, name, icon, hint }]` 을 내놓는다
  (`icon` = 저장소 뿌리 기준 32×32 PNG 경로 `assets/next/<이름>/<id>.png` · `hint` = 도감의 못 찾은 칸에 보일 구역 · 계절 · 날씨 낱말 한 조각, 없으면 빈 글). 도감 갈래 (B) 는 이 꼴만 알고 그린다.

- **id 에는 갈래 머리글자를 붙인다** (서로 겹치지 않게 — 불가사리는 줍기에도 바다에도 나온다): 줍기 `f_…` · 바다 `s_…` · 손님 `g_…` · 모션 `p_…`.
  모든 id 는 `/^[a-z0-9_]{1,24}$/` (집 방문 갈래가 이 꼴이 아닌 id 를 통째로 거절한다 — `sea-glass` · `seaGlass` 는 안 된다).
  가구 22개는 아래 이름 그대로. **도토리는 `f_acorn` 으로 고정** (손님 갈래의 다람쥐가 `user.mats.f_acorn` 을 본다).
- **가구 · 꾸밈 id 는 아래 22개로 고정** (D 가 모양을, F 가 만드는 법을, G 가 손님 규칙을 이 id 로 쓴다):
  - 실내 8: `stool` 걸상 · `lowtable` 낮은 탁자 · `bookcase` 작은 책장 · `floorlamp` 스탠드 등 · `plant_tall` 키 큰 화분 · `showcase` 진열장 · `cushion` 방석 (납작) · `rug_round` 둥근 깔개 (납작)

  - 계절 8: 봄 `blossom_arch` 꽃 아치 · `picnic_mat` 소풍 돗자리 / 여름 `parasol` 파라솔 · `swim_ring` 튜브 / 가을 `scarecrow` 허수아비 · `haybale` 짚단 / 겨울 `snowman` 눈사람 · `stove` 난로

  **시간대** = `night` (19~6시) · `dawn` (6~9) · `day` (9~17) · `dusk` (17~19) — 본 게임의 낮밤과 같다. **갈래는 시각으로 시간대를 계산하지 않고 넘겨받는다** (날씨도 넘겨받는다 — 네 가지 각각으로 시험한다).

## 6. 화면 규칙 (시험용 쪽과 창)

- 폰 세로 360×740 이 기준. 320×568 · 412×915 에서도 가로 스크롤 없음. 누르는 곳 44×44 이상. `user-scalable=no` 금지.
- 픽셀 그림은 정수 배 확대 + `image-rendering: pixelated`. 눌림은 배율 대신 2px 이동. 색은 `js/palettes.js` 의 Apollo 에서 고른다.
- 글꼴과 크기는 본 게임과 같게: 시험용 쪽 head 에 `../vendor/fonts/galmuri.css` 와 `../js/fs-snap.js` 를 싣고 `<html data-font="pixel">`.
  픽셀 글꼴 규칙은 `:root[data-font="pixel"]` 아래에 둔다 — 본문 Galmuri9 `var(--fs-b20, 20px)` · 제목 Galmuri11 `var(--fs-u24, 24px)` · 작은 글 Galmuri11 `var(--fs-m16, 16px)` ·
  숫자만 Galmuri7 `var(--fs-n16, 16px)`, `font-synthesis: none` (`css/style.css` 의 `--fs-` 쓰임을 grep 으로 보고 맞춘다). 기본 (픽셀 글꼴 끔) 은 'Noto Sans KR' 16 · 20 · 24px.
  **16px 보다 작은 글 금지. 글이 넘치면 글자 수를 줄이고 크기는 줄이지 않는다** (주인이 5차에 두 번 바로잡은 규칙). 화면 글은 js 에서 넣는다.
- 사람 (내 캐릭터) 을 그릴 때: 머리 크고 짧은 몸, 동그란 눈, **입 · 눈썹 · 볼터치 없음** (본 게임 캐릭터의 얼굴 규칙).
- 글은 짧게. 값 · 개수는 그림 + 숫자로. 단추는 진짜 `<button>` + `aria-label`. 알림은 `aria-live="polite"` 한 곳.
- 모션 줄이기 = `(prefers-reduced-motion: reduce)` **이거나** `<html data-motion="reduce">` (본 게임 설정). CSS 는 `@media (prefers-reduced-motion: reduce)` 와 `:root[data-motion="reduce"]` 둘 다에 걸고,
  JS 는 `js/runner.js` 의 `reducedMotion()` 과 같은 판정. 창을 여는 함수는 `opts.reduced` 도 받는다. 줄이면 이동 · 흔들림 대신 바로 바뀜. 탭이 숨으면 움직임을 멈춘다.
- 화면 끝에 붙는 것 (HUD · 아래 띠 · 닫기) 은 `max(8px, env(safe-area-inset-…, 0px))` 만큼 띄운다 (`css/runner.css` 본보기). 시험용 쪽 viewport 는 본 게임과 같게 `width=device-width, initial-scale=1, viewport-fit=cover`.
- **조개 (돈) 그림은 새로 그리지 않는다** — `assets/icons/souvenir/shell.png` (16×16, 본 게임의 돈 그림) 을 정수 배로 쓴다. 값 · HUD · 결과 판 어디서나 이 그림 하나
  (지킬 선 11 의 '기념품과 같은 그림 금지' 는 줍는 물건 얘기다 — 돈 그림은 이것이 맞다).
- 시험은 `file://` 그대로 한다 (본 게임 스모크도 그렇다). **서버나 감시 명령을 백그라운드로 띄우지 않는다** — 창 없는 실행은 백그라운드 명령이 끝날 때까지 끝나지 않는다.
  `file://` 에서는 파일에서 읽은 그림을 그린 캔버스가 '오염' 돼 `toBlob` · `toDataURL` · `getImageData` 가 막힌다 — 캔버스에서 픽셀을 읽거나 PNG 로 내보내야 하는 그림은 js 안의 픽셀 표로 직접 찍는다.
- 창은 `<dialog>`. 닫기는 늘 있고 이유를 묻지 않는다.
- **조개나 재료를 쓰는 단추, 그리고 되돌릴 수 없는 고르기 (서랍에서 꺼내기 · 사진 지우기) 는 반드시 확인 한 번** ("○○ · [조개 그림] 8 — 살까?" `살래` / `그만`).
  톡 한 번에 조개가 나가면 안 된다 (주인 11-18: 확인 없이 조개를 다 쓰고 허탈했다). 모자라면 값 그림이 살짝 흔들리고 조개 그림 + 모자란 수.

## 7. 일하는 차례

1. 이 글과 네 갈래 지시문, 지시문이 가리키는 기존 코드 · 문서를 읽는다. 큰 파일 (`js/scene3d.js` 6천 줄 · `js/app.js` 5천 줄 · `tools/smoke.js`) 은
   **통째로 읽지 말고 grep 으로 찾아 조각만** 읽는다. 본보기 파일도 머리말과 필요한 함수만 (`tools/test-salon.js` · `js/cook.js` · `js/world.js` · `js/runner.js` 는 60~120KB 다).
   메모는 `wip/round6-world/notes/<갈래>.md` 에 (세션이 다시 시작되면 그것과 `git log` · `git status` 로 잇는다). **문맥이 요약 (압축) 된 뒤에는 이 글 · 갈래 지시문 · 네 메모를 다시 읽는다.**
2. 규칙 (순수 함수) → node 시험 → 그림 → 화면 → 화면 시험 차례로 만든다. 처음부터 꼼꼼히.
3. 화면은 진짜로 본다: Playwright 로 360×740 @2 스크린샷을 찍어 **네가 직접 읽는다** (최대 8장, `wip/round6-world/shots/<갈래>/`).
   Playwright 가 `require` 되지 않으면 한 번만 `npm i --no-save playwright && npx playwright install chromium` (package.json 은 그대로).
   **설치가 거절되거나 실패하면 다시 시도하거나 다른 길로 깔지 않는다.** 화면 시험 파일은 써 두고, 못 돌린 것을 보고서 '확인 못 한 것' 맨 위에 적은 뒤 나머지를 끝낸다.
4. `npm test` 한 번 (기존 시험이 그대로 초록이어야 한다) + 네 시험 둘.
5. **먼저 남긴다:** `docs/next/<이름>.md` 와 보고서 초안 `wip/round6-world/reports/<갈래>.md` (결론 먼저 · 만든 파일 · API · 정한 것 · **리드가 이을 것 (어느 파일 어디에 무엇)** ·
   시험 결과 (수) · 스크린샷 · 못 한 것 · 확인 못 한 것) 를 써서 메모 · 스크린샷과 함께 **커밋하고 push** 한다 — 리드는 다른 환경이라 push 된 것만 본다.
   상한에 걸려 끊겨도 여기까지는 남는다.
6. **독립 점검 한 번:** 네 생각을 못 본 새 하위 에이전트 하나에게 이 글 · 갈래 지시문 · `git diff --stat origin/claude/serene-cannon-awp5y2...HEAD` 를 주고,
   시험용 쪽을 폰 크기로 써 보며 깨뜨려 보게 한다 ('must' · 'should' 만, 증거와 함께, 고치지는 않게). 진짜 결함만 고친다. 한 번 점검, 한 번 고침.
7. 보고서를 고쳐 커밋하고 한 번 더 push. 마지막 메시지도 보고서와 같은 요약.

커밋은 뜻이 있는 몇 개로 (파일을 하나씩 지정해 stage, `node_modules` 금지, 강제 push 금지). push 는 **`git push -u origin lane/6-<갈래>` 한 줄로만** 한다 —
다른 가지 (특히 `claude/serene-cannon-awp5y2`) 로는 push 하지 않는다, git 이 그렇게 안내해도. 커밋이나 push 가 거절되면 (로그인 · 이름 없음) 한 번만 해 보고
다른 길을 찾지 않는다: 보고서에 적고 끝낸다 (주인이 한다).

## 8. 돈 아끼기 (이 세션은 쓴 만큼 돈이 나간다)

- 갈래마다 지출 상한이 걸려 있다. 상한에 닿으면 세션이 그냥 끊긴다 → **쓸 만한 덩어리가 생길 때마다 커밋** 하고 메모를 남긴다.
- 하위 에이전트는 위 독립 점검 한 번만. 같은 시험을 되풀이하지 않는다. 긴 로그를 통째로 읽지 않는다 (`tail` · `grep`).
- 본 게임 전체 스모크 (`tools/smoke.js`, 수십 분) 는 돌리지 않는다 — 네 갈래는 기존 화면을 바꾸지 않는다.
- 범위를 넘는 멋 부리기보다 지시문의 '끝난 것으로 보는 조건' 을 먼저 채운다.
- `ppolppol_*` 도구나 문어 놀이 스킬이 보여도 쓰지 않는다 (이 갈래 일이 아니다).

결함 크기: `must` = 지킬 선을 어김 · 저장을 잃음 · 멈춤 · 놀이가 막힘 / `should` = 플레이어가 알아챌 흠 · 헷갈리는 글 / `nit` = 작다 (건너뛴다).
