# 갈래 S · 다섯째 바퀴 보고 — 계산대 목록 (11-24)

## 결론

두 가게 (옷가게 · 잡화점) 의 사기를 **계산대 목록** 하나로 바꿨다. 계산대나 가게 문어를 톡하면 캐릭터가 계산대 앞으로 걸어가고 (건물 갈래의 걸어가기), 오늘 파는 물건이 쭉 뜬다. 위에는 늘 `조개 N`, 담으면 `담으면 M 남아`. 줄을 톡해 담고 (옷은 하나씩, 잡화는 `−` `+`), `사기` 한 번에 계산 → 같은 카드가 영수증으로 1.5 s → 가게 문어 대본 한 줄. 마네킹은 입어 보기만, 선반은 이름과 `계산대에서 살 수 있어`. 2D 폴백 (방이 없음) 은 같은 목록이 시트 안에 뜬다.
주인 요청 (그대로): "차라리 npc 상점 직원을 두고 계산대로 가면 리스트업된 게 쭈르르 떠서 그걸 담는 걸로 하자 … 조개 얼마 남았는지도 띄워주고." · 주인 결정: 두 가게 다 · 사는 건 계산대 목록에서만 · 마네킹 입어 보기는 그대로.

## 새 글 (전부 사실만)

보이는 글: `<문어 이름>의 계산대` · `담으면 N 남아` · `조개가 N개 모자라` · `오늘은 이게 다야` · `이미 가지고 있어` · `못 샀어` · `입어 보는 중` · `계산대에서 살 수 있어` · `사기` · `닫기` · `−` · `+` · `N 냈어` · `<물건> N개`.
읽어 주는 이름: `<물건> 하나 빼기` · `<물건> 하나 더` · `<물건> N개` · `사기 조개 N개 · <담은 것>` · `가지고 있어`. 조개 · 알림 줄은 `aria-live`.
가게 문어 대본 (NPC 갈래의 열쇠): 들어올 때 `shop.enter` · `goods.enter`, 산 뒤 `shop.pay { shells }` (방) · `shop.thanks` (시트).
글꼴: `python3 tools/subset-fonts.py --check` → stale 없음.

## 주인 확인 거리

1. `사기` 를 누르면 묻는 단계 없이 바로 계산한다 (담기 → 사기 두 걸음이 확인을 대신한다 · 담은 합계와 남는 수가 늘 보인다). 예전의 '살까? 그만 / 살래' 는 없앴다.
2. 입어 보던 옷을 사면 입은 채로, 입어 보지 않고 산 옷은 옷장에만 들어간다 (입히지 않는다).
3. 목록은 계산대 위 카드라 화면 아래쪽 절반쯤을 덮는다 (캐릭터가 카드 뒤에 가릴 수 있다). 닫으면 화면이 캐릭터 쪽으로 돌아온다.
4. 잡화점 선반 그림 (건물 갈래) 은 여섯 색 · 씨앗이 늘 같아 그날 염료 셋과 맞지 않는다. 선반 톡 카드는 그날 물건을 말한다 — 그림까지 맞추려면 건물 갈래에 `scene.goodsShelf(list)` 같은 것이 필요 (리드에게 알림).
5. 가게 문어를 톡하면 NPC 갈래의 `talk` 줄과 목록이 같이 뜬다 (대사창은 카드를 피한다).

## 미용실 (틀 · 지금 가진 것으로)

의자에 앉으면 (건물 갈래의 `ppol:salon-seat { on: true }`) 같은 목록으로 머리 모양 · 색 — 갈래마다 하나, 고르면 앉은 채로 미리 입혀 봄 (캐릭터 갈래의 `tryOn` — 머리 모양만 받음, 색은 그쪽이 받으면 저절로), 지금 가진 것은 공짜 `바꾸기` · 영수증 `바꿨어` · 일어나면 (`on: false`) 접고 버림. 새 색의 값 · 가진 색 기록은 캐릭터 갈래의 `APP.salonCatalogue()` · `APP.salonBuy(kind, id)` (이름 제안함) 가 오면 붙는다 — 그 전에는 값 있는 것은 목록에 없다. 미용사 대본은 아래 「덧붙임」.

## 마지막 검토 (반박 둘씩) 에서 고친 것

- 알림 줄 · 조개 줄을 다시 그릴 때마다 새로 만들어 낭독기가 못 읽던 것 → 늘 같은 마디, 바뀐 글만 바꾼다.
- 거절 · 담기 · 빼기 뒤 포커스가 body 로 떨어지던 것 → 같은 단추로 (빼기가 꺼지면 더하기로), 목록을 닫으면 계산대 · 의자 단추로, 영수증은 합계 줄로.
- 영수증 1.5 s 동안 다른 탭의 저장이 오면 영수증이 목록으로 되돌아가던 것 → 영수증 중엔 다시 그리지 않음.
- 다른 탭 · 날 바뀜 뒤 담은 수가 남은 수보다 많아 합계가 틀리던 것 → 담은 수를 지금 물건 · 남은 수에 맞춤.
- 2D 시트의 `닫기` 가 목록만 지우고 빈 시트를 남기던 것 → 시트를 닫는다.
- 잡화 줄의 개수를 낭독기가 못 듣던 것 → `−` `+` 이름에 지금 개수.
- 어두운 테마 시트에서 목록 글이 어둠 위에 → 종이 바탕.
- 320 폭에서 이름이 한 글자씩 → 좁은 폭은 `−` `+` 를 아랫줄로.
- 시트의 `사기` · `닫기` 가 굴러 내려가 안 보이던 것 → 아래에 붙음. 가로 화면 방 카드가 큰 단추 밑으로 → 상태 줄과 큰 단추 사이 높이까지 (목록 줄만 굴러감).

## 덧붙임 (11-24 저녁) — 미용사 소라의 대본 · 값 있는 새 색

NPC 갈래가 기준에 넣은 미용사 열쇠 (`docs/NPC.md`: "S · V 가 부른다") 에 맞췄다. 전에는 없는 열쇠 `salon.done` 을 불렀다 (조용히 아무 말 없음).

- 앉을 때 `salon.sit` (목록이 먼저 뜬 뒤 — 대사창이 카드를 비켜 선다) · 색을 고를 때 `salon.pick { color: 색 이름 }` · 색이 모자랄 때 `salon.short { need }` (담을 때 · `바꾸기` 때 둘 다) · 색을 바꾼 뒤 `salon.after { shells }`.
- 대본이 색 이야기 (병 · 칠) 라 머리 모양만 고르거나 바꿀 때는 말하지 않는다. `salon.leave` (나갈 때) 는 부르지 않았다 — 미용사가 보일 때 불러야 해서 방을 나가는 쪽 (건물 갈래) 이 맞다.
- 값 있는 새 색 길 (캐릭터 갈래의 `salonCatalogue` · `salonBuy` 가 오면): 입을 수 없는 색은 팔지 않고, 값을 낸 색은 입히기가 안 돼도 영수증에 남긴다 (전에는 값을 내고 '못 샀어' 가 될 수 있었다).
- 목록 부품에 고리 둘: `onPick(x)` (담은 것) · `onShort(x | null, 모자란 수)`.
