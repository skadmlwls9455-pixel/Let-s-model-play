# 갈래 V 보고 — 마을에 서 있는 것 (`lane/7-v`, 11-21)

## 결론

마을 길과 광장에 **옷가게 · 잡화점 · 카페 덱 · 빈 집 · 광장 (우물 · 게시판 · 무대)** 과 길 소품이 서 있고, 단추 열 개와 NPC 문어 API · 카페 자리가 계약 C6 대로 들어갔다.
갈래 W 의 브랜치 (6c873fd — 길 폭 ±2.2 · 바깥 배율 m 당 18 아트 px) 와 **시험용으로만** 내 컴퓨터에서 합쳐 (푸시하지 않음) 진짜 땅 · 진짜 배관 위에서 브라우저 시험 112 개가 다 통과했다. 내 브랜치만으로는 장면의 시험 스텁 위에서 통과.
새 셰이더 프로그램 0 · 점광 0 · 마을 것만의 드로우콜 6 ~ 29 (예산 40) · 바깥 전체 41 ~ 70 (예산 150).

처음에 찾은 것: **폰 화면이 바깥에서 가로 6.7 m 뿐이라 계약의 길 (±3 m) 이 화면을 다 채워 가게가 안 보였다.** 리드가 길 폭을 ±2.2 로, 바깥 배율을 10 m 폭으로 바꿨고, 그에 맞춰 판매대는 걷는 곳 바로 밖 (|t| 2.35 부터), 건물 모서리는 |t| 3.3 에 두었다.
리드의 둘째 주문 (가게가 한눈에 읽히게 · 길 어깨 채우기 · 광장 가운데) 도 넣었다: 처마 위 큰 그림 간판 셋, 길을 가로지르는 깃발 줄 둘, 긴 화분 · 통 · 손수레, 마주 선 가로등, 빈 집의 못 박은 덧문과 잡풀, 광장 가운데 우물과 꽃 고리, 무대의 뒤 틀 · 디딤 두 칸 · 둥근 깔개.

독립 검증 한 번 (새 에이전트, 내 추론 없이): `must` 0 · `should` 3 — 셋 다 고쳤다 (① 꺾인 길에서 걷다 가장자리에 서 버림 490 갈래 중 98 → 길 찾기에 걷는 곳이 만나는 자리를 넣어 1120 갈래 모두 이어짐 ② 카페 문어가 부엌 집 지붕에 가림 → 부엌 집을 문어 뒤로 ③ 앉으려 뛰던 중 일어나면 앉기 약속이 true → false).

못 한 것 하나: 리드가 부탁한 `.github/workflows/test.yml` 한 줄 (갈래 브랜치는 CI 를 돌리지 않게) 은 내 세션의 권한에서 막혀 넣지 못했다. 합칠 때 바탕의 줄이 들어간다.

## 내보낸 API (`APP.scene`, 정확히)

- `npcSpots()` → `[{ id, x, y, z, face }]` (일곱)
- `npcSet([{ id, color, hat, pose }])` → 그린 수. 목록에 없는 문어는 지운다. 모르는 id 는 버리고, 모르는 모자 · 자세 · 색은 기본값 (`none` · `stand` · `#d9694f`). 마당을 짓기 전에 불러도 기억한다
- `npcMark(id, on)` → 켜졌나 (그려지지 않은 문어면 false)
- `cafeSit(true)` → `Promise<앉았나>` · `cafeSit(false)` → `Promise<일어났나>` · `cafeCup(on)` → 보이나 (앉아 있을 때만) · `cafeSeated()`
- `villageGo(단추 id | key)` → `Promise<가까이 섰나>` · `villageNear(단추 id | key)` → boolean
- `document` 이벤트 `ppol:cafe-seat` (`detail: { on }`)
- 시험용: `villageInfo()` · `debugVillageStub()` · `debugVillageFrame(dt)` · `debugVillageHide(on)`

## 주인이 확인할 결정

1. **건물을 길에 붙였다.** 계약의 터 (|t| 3.5 ~ 10) 안쪽이 아니라 길 쪽 모서리 |t| 3.3, 판매대와 가게 문어는 걷는 곳 바로 밖 (|t| 2.35 ~ 3.6). 리드가 길 폭 ±2.2 와 10 m 화면으로 받쳐 줬다.
2. **건물은 등각 (x · z 축).** 마당 집과 같은 꼴이다. 가게 앞면이 길 쪽 · 아래쪽을 비스듬히 본다.
3. **카페 덱에 지붕이 없다.** 기둥 넷과 가는 들보 · 전구 줄뿐이라 어느 각에서 봐도 안이 보인다. 비 · 눈은 덱에도 그대로 내린다 (가릴 지붕이 없으니 덱 안에 떠 있는 입자도 없다).
4. **카페 자리는 식탁 옆.** 식탁 뒤에 앉히면 기본 각에서 식탁이 몸을 가려, 길 쪽 걸상에 식탁을 옆에 두고 앉는다 (옆모습).
5. **NPC 문어의 밝은 몸 색은 어둡게** 그린다 (밝기에 따라 0 ~ 40 %: 한낮 햇빛에 하얗게 떠서 — 갈래 N 의 옅은 잠든 문어 색은 회색빛 도는 색으로 보인다). 재질은 건물과 같은 것이라 다락 문어와 음영이 조금 다르다.
6. **NPC 표시** (`npcMark`) 는 작은 노란 마름모 하나. 차양 밑에서도 보이게 다른 것 위에 그린다.
7. 가게 문어는 **발판 위**에 선다 (판매대가 얼굴을 가려서).
8. **광장 한가운데에 우물**이 선다 (가운데가 비어 보인다는 리드의 주문). 나무는 캐릭터를 가려서 쓰지 않았다.
9. 혼자 걷는 동안 (단추를 멀리서 누름 · 카페 앉기) 화면이 캐릭터를 가운데로 따라온다.
