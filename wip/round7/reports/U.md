# 갈래 U 보고 — 화면 고침과 빈 화면 채우기 (`lane/7-u`, 11-21)

## 결론

여섯 가지를 다 만들어 올렸다. 1~5번 (D+N · 설정 접기 · 계단 단추 없앰 · 포스터 스티커 · 장면 멈춤) 은 커밋 `7a6c986` 까지, 6번 (먼 풍경) 은 `9b002c6` 부터다.
러너 스티커는 손대지 않았다 (아래 "남긴 것"). 6번은 기본으로 켜져 있고 `?vista=0` 으로 끌 수 있다.

## 바꾼 것

1. **상태 줄 'D+N'** — `js/app.js` `renderDayN` · `dayCount` (새, `[7-U]`), `renderStatus` 가 부른다. `index.html` `#room-title` → `#day-n`. `css/style.css` `.day-n` 규칙 (`[7-U]`).

   - 탭 제목 = '<이름> · 뽈뽈 문어'. 등불 설명의 첫 줄에서 방 제목을 뺐다 (`pipsHead`). `roomTitle` · `hiddenRoomTitle` 은 지웠다. 장면 설명 (`#scene-desc`) 은 그대로 방을 말한다.

2. **설정 구역 접기** — `js/app.js` `setSecFold` · `setSecRead` · `setSecOpen` (새), `renderSettings` 가 조각을 묶어 넣는다. 구역마다 `details.set-sec[data-sec]`, 제목 (`h3` · 내 모습은 `.set-parts-h`) 이 `summary`.

   `index.html` `#btn-stair` 안의 그림 삭제, `css/style.css` 의 `#btn-stair[data-spot="edge"]` 규칙 10줄 삭제, `HINT_SPOTS` 에서 계단 손 힌트 삭제.
   - 기본 구도에서 계단이 보이는 폭: **360×740 = 0 px** (계단 상자가 화면 왼쪽 밖 −58…−1), **412×915 = 25 px** (보이는 디딤판을 누르면 올라간다). 한 손가락으로 180 px 밀면 360 폭에서 57 px 가 보이고 그림 위 단추 (over) 가 된다 → 눌러서 올라감 (L5 가 본다). 키보드: Tab → '위층으로' → Enter 로 올라간다.
4. **포스터 스티커 키움** — `js/app.js` `posterSVG` 의 스티커 블록 + `posterStickerSize` · `fitFrontSticker` (새). 앨범 카드는 `card: true` 로 부른다.

5. **전체 화면 놀이 중 장면 그리기 멈춤** — `js/scene3d.js` `setCovered` (새: 가려진 동안 렌더 패스를 건너뛰고 계산은 10 fps — 11-22 고침, 아래 '돌린 것'), `js/app.js` `sceneCoverSync` (새: `#runner-dlg` · `#cook-overlay` 의 `open` 속성을 MutationObserver 로 본다 — 여닫는 코드는 안 건드림).
   화면 밖일 때와 같은 길이라 닫아도 시계가 뛰지 않는다. 열린 동안 그린 장 0, 산책 귀가 같은 흐름은 그 사이에도 끝난다.
6. **빈 화면 채우기** — 새 `js/vista.js` (`VISTA.paint(w, h, { hour, weather, season, seed, t, horizon })`, DOM 없음), `js/scene3d.js` 후처리 셰이더에 유니폼 넷 (`tVista` · `uVista` · `uVistaRes` · `uVistaOff`) 과 두 줄, `vistaStep` (새).
   - 다락 · 위층 · 놀이방의 허공 픽셀에만 깐다 (마당 · 산책 중 바깥 · 입장 연출 · 초상은 끔). 위는 하늘 (낮 · 노을 · 밤의 별과 달 · 새벽 · 비 오는 잿빛) 과 계단 구름, 지평선 (화면 높이의 가운데 — 방 뒤) 아래로 바다 · 모래톱 · 마을 지붕 · 가까운 숲. 계절 (가을 단풍 · 봄꽃 · 눈) 이 나무에 든다.
   - 그림 = 렌더 타깃 크기 + 좌우 20 아트 px. 방을 돌리면 90° 마다 8 아트 px 씩 반대쪽으로 밀린다. 물결은 1 초에 3 칸 (바다 줄만 다시 그림: 한 번 0.9 ms), 모션 줄이기면 멈춘다.
   - 드로콜 · 셰이더 프로그램은 그대로 (텍스처 하나만 는다). 색은 전부 Apollo 46 칸이라 팔레트 스냅을 지나도 안 바뀐다. `?vista=0` 이면 예전 하늘 띠.

## 주인이 확인할 결정

1. **폰에서 'D+N' 의 자리.** 360 폭의 바는 196 px (아이콘 다섯) 인데 네 글자 이름 80 + 등불 칸 94 가 이미 꽉 찬다. 글자를 줄이지 않고는 'D+N' (48~60 px) 이 바 안에 못 든다 → 폭 ≤ 599 에서는 '데모' 꼬리표 옆에 매달았다 (늘 보인다). 바 안에 두려면 등불 칸을 더 작게 해야 한다.
2. **N 은 '연 날의 수'** (쉬어도 줄지 않는다 — 가방 · 선물 줄과 같은 수). 달력으로 센 '태어난 지 N일' 이 아니다.
3. **쪽지 카드의 스티커는 거의 그대로** (16~18 CSS px). 쪽지 카드는 폭 84 px 에 그림이 가운데 절반을 차지해 오른쪽 띠가 18 px 뿐이다. 더 키우면 그림을 덮는다.
4. **계단 손 힌트를 뺐다** (가리킬 단추가 없어졌다). 계단이 화면 밖인 360 폭에서는 화면을 밀거나 돌려야 계단이 보인다.
5. **먼 풍경의 낮 색.** 예전 허공은 낮에도 어두운 남색이었다. 이제 낮에는 파란 하늘 · 초록 땅이라 화면 전체가 밝아진다 (방은 그대로). 가을엔 숲에 단풍이 든다. 더 가라앉히려면 `js/vista.js` 의 `SKY` · `LAND` 표만 바꾸면 된다.
6. 시각대가 바뀌는 순간 풍경은 한 번에 바뀐다 (방 조명은 60 s 에 걸쳐 바뀐다).

## 남긴 것 · 못 본 것

- **러너 스티커** (`RUNNER_STICKERS.watch()`) 는 넣지 않았다: 안내문이 "다 끝나면" 이라 했고, 한 번도 실린 적 없는 그림이라 달리기 화면에서 자리 · 크기 (80 CSS px 이상) · 문어에 대한 표현 규칙을 따로 봐야 한다.
- **독립 점검 (새 에이전트 한 번) 은 끝나지 못했다**: 띄운 점검이 사용 한도에 걸려 중간에 멈췄고 결과가 없다. 대신 스모크 S 가 5번의 귀가 막힘을 잡아 고쳤다. 리드의 미리 합쳐 보기에 기대고 싶다.
- 진짜 폰에서는 못 봤다 (헤드리스 크로미움 · 소프트웨어 WebGL 만). 풍경 텍스처 올리기 (1 초 3 번, 약 0.3 MB) 가 느린 폰에서 어떤지는 재지 못했다.
- 사파리 (WebGL1) 에서 `DataTexture` 는 `Uint8Array` 로 올리게 했지만 실제 기기 확인은 못 했다.
