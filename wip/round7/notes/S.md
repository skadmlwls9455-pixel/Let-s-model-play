## 시간이 모자라면 먼저 버릴 것
입어 보기 그림 다듬기 → 잡화점 염료. (확인 줄 · 저장 안전 · 하루 선반 규칙은 안 버린다)

## 정한 것 (주인 확인 거리)
- 저장: `S.user.shop = { got: { 'cat:id': 날짜 }, day: { key, seeds } }`, `S.user.beach = { day, picked: [칸] }`. 모르는 칸은 그대로.
- 옷 선반: 하루 4개. 한 바퀴 = ceil(N/4) 일. 바퀴마다 시드로 섞고, 싼 것 둘 + 비싼 것 둘이 하루에 오게 엇갈려 놓는다. 전에 산 것은 다음 차례 것으로 바뀌고, 오늘 산 것은 도장을 찍고 남는다.
- 잡화점: 씨앗 2 조개 (하루 3개까지) · 그날의 염료 색 셋 (재봉틀 값 그대로 6, 수 제한 없음).
- 조개가 모자라도 옷은 입어 볼 수 있다. '살래' 를 누르면 값이 흔들리고 모자란 수를 알린다.
- 가진 옷 칸을 누르면 입어 보기 그림 + '입을래'.
- 가게 주인 줄 `shop.thanks` 는 시트가 닫힐 때 (창 위에서는 대화 상자가 가려져서).
- wardrobe 가 없으면 (P 전) 옷가게 시트는 열리지 않는다. 조개 줍기 +1 은 userState 로 (범용 벌이 도우미가 없어 재봉틀 사기와 같은 식).
- 기존 줄은 하나도 안 고친다: 날 바뀜 · 다른 탭은 내 타이머 · 내 storage 듣기로.
