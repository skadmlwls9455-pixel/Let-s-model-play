# 음식 그림 (`js/cook-sprites.js`) — 7차 (11-21)

부엌 · 요리책 · 식탁에 쓰는 음식 그림은 모두 `js/cook-sprites.js` 한 파일에 있다 (전역 `COOK_SPR`, DOM 없음, node 에서도 돈다).

```js
COOK_SPR.get(id, frame)  // { w, h, d: Uint8ClampedArray RGBA } | null   (frame 생략 = 0, 넘치면 마지막 장)
COOK_SPR.ids()           // string[]
COOK_SPR.info(id)        // { w, h, frames, ax, ay } | null   (ax, ay = 바닥에 닿는 자리의 가운데)
```

쓰는 쪽은 `null` 이면 제 밋밋한 그림을 그린다. 그림 1 px 은 언제나 기기 픽셀의 정수 배로 보여 준다.

## 형식: 글자로 칠하는 작은 화가

그림 하나 = `def(id, w, h, ax, ay, frames, function (F, f) { ... })`. `F` 는 그 그림의 판 (글자 층), `f` 는 장 번호.
색은 16진수가 아니라 **팔레트 글자** 로만 쓴다 (파일 맨 위 `PAL`: 부엌의 Apollo 46 + FOOD 24 + 덧색 `Q` `=` 둘).

자주 쓰는 글자:

| 재료 | 밝음 → 어두움 |
| --- | --- |
| 부침 · 달걀 · 빵 (FOOD J) | `W` 반짝 · `6` `5` `4` `3` `2` `1` `0` |
| 반죽 | `b` `B` |
| 흰 음식 (밥 · 크림 · 흰자) | `W` `Q` `e` `E` |
| 밝은 풀색 (FOOD P) | `q` `g` `G` `P` · 해초 `t` `T` |
| 빨강 (딸기 · 케첩) | `=` `c` `r` `R` `$` |
| 흰 그릇 | `w` 그림자는 `C` `z` · 옆면 `l` `m` `n` |
| 쇠 · 어두운 것 | `l` `m` `n` `N` `d` `D` `x` |
| 나무 | `e` `E` `f` `F` `u` `U` `V` · 호박색 `y` `A` `a` `k` `K` |
| 물 · 파랑 | `C` `z` `H` `h` `i` `I` |

층 (`lay(w, h)`) 에 그리는 법 — 모두 이어 쓸 수 있다 (`l.r(...).e(...)`):

| 부름 | 하는 일 |
| --- | --- |
| `p(x, y, ch)` | 점 하나 |
| `r(x, y, w, h, ch)` · `rr(x, y, w, h, c, ch)` | 네모 · 모서리 둥근 네모 |
| `e(x, y, w, h, ch)` · `ring(x, y, w, h, t, ch)` | 타원 (상자 기준) · 두께 t 의 타원 테 |
| `ln(x0, y0, x1, y1, ch, t)` | 선 (붓 두께 t) |
| `poly([[x, y], ...], ch)` | 다각형 |
| `rows(x, y, ['..44..', ...])` | 손으로 친 글자 줄 (`.` = 건드리지 않음). 줄 길이가 다르면 던진다 |
| `ball(x, y, w, h, light, base, shade, d)` | 왼쪽 위에서 빛 받은 둥근 덩어리 |
| `on(chars)` | 가위: 다음 그림은 **지금 그 글자인 점에만** 칠한다 (`'*'` 칠해진 곳 전부, `'.'` 빈 곳). `on()` 으로 푼다 |
| `map({ from: to })` · `copy()` · `flip()` | 색 바꾸기 (익힘 단계) · 복사 · 좌우 뒤집기 |
| 글자 `'-'` · `'^'` | "지금 색보다 한 칸 어둡게 / 밝게" (`RAMPS` 순서) — 면 나누기 · 익힘에 쓴다 |

판에 올리기: `F.put(layer, x, y, outline, shadow)`.
- `outline` = 글자 셋 `[빛 쪽, 보통, 바닥 쪽]` (예: `OW` = `'akK'` 따뜻한 갈색). 층 바깥으로 1 px 자라는 외곽선을 알아서 그린다.
  `''` 이면 없음. **검정은 쓰지 않는다.**
- `shadow` = 오른쪽 아래로 드리우는 닿는 그림자 길이 (px). 이미 칠해진 곳이 한 칸 어두워진다.
- 뒤에 있는 것부터 올린다.

## 그릴 때 보는 목록

- 비스듬히 내려다본 모습: 밝은 윗면과 어두운 옆면이 따로 있다. 음식은 쌓이고 겹친다.
- 요리마다 저만의 윤곽과 그릇 (바구니 쟁반 · 긴 접시 · 잎 접시 · 둥근 접시 · 네모 접시).
- 이름 댈 수 있는 속: 자른 면, 말린 결, 김 띠, 씨, 층.
- 재료마다 3 ~ 5 색, 밝은 쪽은 노랑으로 어두운 쪽은 붉은 갈색으로 (회색 · 검정으로 어둡게 하지 않는다).
- 반짝이는 것에는 `W` 한두 점 (왼쪽 위 1/4 자리, 외곽선에 붙이지 않는다).
- 외곽선은 따뜻한 어두운 갈색이나 그 물건의 어두운 색. 빛은 언제나 왼쪽 위.
- 홀로 선 점은 반짝임과 깨 · 씨뿐. 닿은 두 색은 1배에서도 갈라 보여야 한다.
- 문어 · 오징어 같은 두족류, 눈에 보이는 동물은 어떤 그림에도 없다. 다른 그림을 베끼지 않는다.
