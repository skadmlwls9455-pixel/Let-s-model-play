# 마을 문어 (11-21 · 7차 N 갈래)

마을 문어는 다락 문어와 다른 존재다. 다락 문어는 모델 (오늘은 딱지를 붙인 데모 규칙) 이 움직이고, 마을 문어는 **미리 써 둔 대본을 읽는 인물**이다. 둘이 섞여 보이지 않게 마을 문어의 이름표에는 늘 `이름 · 대본` 이 붙는다.

코드: `js/npc.js` (전역 `NPC`, DOM 없음) · 대사창과 게시판은 `js/app.js` 의 `[7-N]` 자리 · 검사 `tools/test-npc.js`, `tools/test-npc-live.js`.

## 명단

| id | 가게 | 이름 | 몸 색 | 모자 | 말투 | 버릇 |
|---|---|---|---|---|---|---|
| `clothes` | 옷가게 | 시침 | `#3f9c9c` | beret | 첫말 「흠.」 + 옛 치수 낱말 (치 · 푼 · 자) · 한다체 「-다.」 (길다 · 접는다 · 맞다) | 줄자 없이 눈으로 재고, 한 번 더 잰다 |
| `goods` | 잡화점 | 모아 | `#cdb94a` | apron | 같은 말을 두 번 + 끝자리까지 말하는 수 · 되풀이로 맺는다 (받았어 받았어 · 맞아 맞아 · 여섯 척. 여섯 척.) | 소리 내어 센다 · 연필을 찾는다 (머리 위에 있다) |
| `cafe` | 카페 | 느루 | `#a67c62` | cap | 말줄임표 「…」 (줄의 3분의 2쯤에만) · 끝을 흐린다 「-는데…」 「-고.」 + 허락하는 「-해도 되고」 | 구름에 이름을 붙인다 · 잔부터 데운다 |

이름의 뜻: 시침 = 시침질 (옷을 꿰매기 전에 듬성듬성 떠 두는 바느질) · 모아 = 모으다 · 느루 = 한꺼번에 하지 않고 오래도록 · 몽돌 = 모나지 않은 둥근 돌 (11-28: 조약 → 몽돌. 다락 문어 쪽 기념품 「조약돌」 과 섞이지 않게) · 뱃고동 = 목소리가 뱃고동만 해서 붙은 이름 (11-28: 그물 → 뱃고동. 대사 속 물건 그물과 섞이지 않게).

## 말하는 규칙

- 반말, 풍선 하나는 28자까지 (14자 두 줄), 한 줄에 풍선 1~2개.
- 마음 · 바람 · 몸 상태를 말하는 낱말을 쓰지 않는다. `tools/test-brain.js` 의 `CLAIM_RX` · `TAP_BAN` 을 글자 그대로 읽어 모든 줄에 건다 (그래서 "오늘" · "내일" 도 없다). 성격은 말투 · 눈여겨보는 것 · 하는 일로만 보인다.
- 다락 문어 이야기를 하지 않는다. 모델인 척하지 않는다 ("생각" · "느낌" 없음).
- 재촉하거나 다시 오라고 하지 않는다 ("빨리" · "놓치" · "마지막" · "꼭 와" 없음).
- 이모지 · 기호 없음 (한글 · 숫자 · 마침표 · 쉼표 · 말줄임표 · 가운뎃점).
- 자기 일은 사실로 말해도 된다 ("나는 지난봄에 깼어.").
- 갈래는 차례로 돈다 (난수 없음). `{theme}` · `{shells}` · `{dish}` 가 든 갈래는 그 값을 넘겼을 때만 나온다.
- 말투 표지는 문어마다 하나씩이고 다른 문어 줄에 쓰지 않는다 (docs/NPC_BIBLE.md 5절 · `tools/test-npc.js` 가 지킨다): 흠. · 자, · 한다체 (시침) / 되풀이 (모아) / … · -는데 · -해도 되고 (느루) / 있잖아 · -대 (토리) / 툭 · 통 · 쿵 (소금) / 색 이름 (몽돌) / 어이 · -지 · 크기 견줌 (뱃고동) / 끝. · 시킴말 · -ㄹ게 (소라). 물음표 · 느낌표도 쓰지 않는다.

## 부르는 법 (계약 C7)

`APP.npcSay(id, key, vars)` → `Promise<boolean>` (끝까지 봤으면 true · 접혔거나 보일 수 없으면 false). 2D 장면이거나 그 문어에게 없는 열쇠면 아무것도 보이지 않는다.

대사창 `#npc-box`: 장면 아래쪽 종이 상자 · 작은 초상 · 이름표 · 글. 누르면 다음, Esc 로 닫기, 읽을 시간이 지나면 저절로 넘어간다. 모달 시트가 열려 있으면 그 시트 바로 위에 뜬다. 포커스를 옮기거나 가두지 않고, 글은 `aria-live="polite"` 로 읽힌다. 말하는 동안 `scene.npcMark(id, true)`.

가게 문어 단추 (`#btn-npc-clothes` · `-goods` · `-cafe`) 를 누르면 `talk` 한 줄. 말하는 중에 다시 누르면 다음으로 넘어간다.

## 박자 열쇠 (11-21 밤 · 계약 C14)

걸어 들어가는 가게 · 카페 · 공연장의 박자마다 부르는 열쇠. 값 없이 불러도 줄이 나오고, 값을 넘기면 그 값을 말하는 갈래가 먼저 나온다.

| 열쇠 | 누구 | 언제 | 넘길 수 있는 값 |
|---|---|---|---|
| `shop.enter` | clothes | 옷가게에 들어왔을 때 (한 번) | |
| `shop.tryon` | clothes | 입어 봤을 때 | `{item}` 옷 이름 |
| `shop.mirror` | clothes | 거울 앞 | |
| `shop.pay` | clothes · goods | 값을 치른 뒤 | `{shells}` 낸 조개 수 |
| `shop.leave` | clothes · goods | 나갈 때 | |
| `goods.enter` | goods | 잡화점에 들어왔을 때 | |
| `cafe.order` | cafe | 주문을 받은 뒤 | `{dish}` 메뉴 이름 |
| `cafe.serve` | cafe | 쟁반이 나왔을 때 (전부터 있던 열쇠) | |
| `cafe.stamp` | cafe | 도장을 찍었을 때 | `{n}` 몇 번째 |

| `contest.podium` | 셋 다 | 단상 | |

어디에 서나: `NPC.list(날짜, 시)` 는 여덟 (가게 셋 · 집에 사는 넷 · 미용사) 을 넘긴다. 가게 문어는 장면이 가게 앞과 그 방 안의 `keeper` 칸에, 집에 사는 넷은 장면의 시간표 자리에 그린다 (예전 `sleep-1` 의 카페 낮잠은 11-24 에 뺐다). 방이 바뀌면 (W 의 `ppol:room`) 떠 있던 말은 접힌다.

대사창과 카드: 장면 안 카드 (꼬리표 · 영수증) 에 `data-npc-avoid` 속성을 달면 대사창이 그 카드를 가리지 않는다 (아래 자리가 겹치면 장면 위쪽에 뜬다).

## 집에 사는 문어 넷 · 미용사 (11-24)

주인 (11-24): "지금 집이 비어있는데 각 문어들이 살았으면 좋겠어." 자던 문어 넷이 깨어 집마다 산다 (id 는 예전 그대로 sleep-1 … 4, 몸 색도 그대로). 집 · 방 · 자리 · 시간표는 장면 (V 의 `VILLAGE.where`).

미용사: `stylist` · 소라 · `#c75c7a` · cap · 말투: 맺음말 「끝.」 (줄의 절반 안팎) · 짧은 시킴말 (앉아. · 가만. · 거울 봐.) + 손이 하는 일 「-ㄹ게」 · 버릇: 빗 셋을 머리에 꽂고, 꽂는 차례를 날마다 바꾼다 · 새 색은 제 다리 끝에 먼저 칠한다. 미용실 방은 V, 목록과 값은 S, 새 머리 색은 P 가 만든다.

시간 (`NPC.phase(hour)`): 낮 7~17 · 저녁 17~21 · 밤 21~7. `NPC.list(날짜, 시)` 는 넷을 room · slot 없이 넘기고 (자리는 장면의 시간표), 밤엔 자세만 `sleep`. 앱은 시간 칸이 바뀌면 다시 넘긴다.

누르면 (`#btn-npc-sleep-1` … `-4`, V 가 단추를 단다 · `NPC.residentKey`): 처음 만나면 `home.first` · 그날 처음이면 `home.again` (저녁엔 `home.in`) · 그다음엔 낮 `talk` / 저녁 `home.in` · 밤엔 문어는 말하지 않고 집 목소리 "자고 있어." 한 줄. 만난 날은 `S.user.story.met` · `metDay`.

미용사 열쇠 (S · V 가 부른다): `salon.sit` 앉을 때 · `salon.pick` 고를 때 (`{color}` 색 이름) · `salon.after` 바꾼 뒤 · `salon.short` 조개가 모자랄 때 (`{need}` 더 드는 수) · `salon.leave` 나갈 때 · `talk` (`#btn-npc-stylist`).
