## 1. 한 줄 요약

쌓이는 「오늘의 산책」 목록을 없애고, 장면 아래에 **한 번에 한 줄만 보이는 사각 대사창**을 둔다. 대사창은 눌러서 넘긴다. 지난 대사는 작은 📜 버튼으로 여는 **「대사 다시 보기」** 창에 글 위주로 전부 남는다.

## 2. 왜

- 주인이 폰으로 해 보고 말했다. "기존 내역들이 쭉 아래로 슬라이딩해서 쌓이는 형식인데, 내가 생각한 그 터치해서 대사 넘어가는 사각형 UI 랑 안 맞아."
- 지금은 줄이 올 때마다 목록이 아래로 밀린다. 눈이 따라가야 하고, 무엇이 방금 온 줄인지 헷갈린다.
- 게임에서 흔히 쓰는 모양(초상 + 한 줄 + ▼)은 "지금 한 마디"에 눈을 모아 준다. 문어와 마주 앉아 있는 느낌에 더 가깝다.
- 대신 지난 기록은 하나도 잃으면 안 된다. 특히 **읽음 / 못 읽음** 같은 정직 표시는 그대로 보여야 한다. 그래서 기록은 따로 「대사 다시 보기」로 옮긴다.
- 같은 피드백에서 나온 두 가지도 여기서 같이 푼다.
  - "2프레임이라 깜빡이는 느낌이고 눈이 피곤해." → 대사창의 ▼ 와 기다림 표시부터 고친다 (§5.9).
  - 문어가 "안녕, 나는 ○○이야" 하고 인사한다. 이 인사는 대사창으로 나온다 (§4.4).

## 3. 흐름

### 3.1 누가 말하나: 목소리 셋

대사창 한 장에 세 목소리가 지나간다. 판 색은 바꾸지 않는다. 판 색이 3초마다 밝음과 어두움으로 뒤집히면 그 자체가 깜빡임이 되기 때문이다. 대신 **얼굴, 이름표, 아이콘, 글자 밝기**로 구분한다.

| 목소리 | 언제 | 대사창 모양 | 기록의 `by` |
|---|---|---|---|
| **문어** | 문어(데모 규칙 또는 모델)가 **지금 막** 쓴 말. 첫 인사, 기억 한 줄, 마무리 반응, 집 활동 한 줄, 돌아와서 대화의 대답 | 왼쪽에 초상. 표정은 데모 규칙 줄만 그 줄의 표정이고, 모델 줄은 보통 얼굴 `idle`(모델이 `expr` 를 골랐으면 그것). 위 테두리에 이름표 `뚜루 · 데모 규칙`. 밝은 글자 | `demo-rules` · `model` · `human`(개발 패널 조작, `?dev=1` 에서만. 보통 플레이어에겐 안 나옴) |
| **집** | 게임이 아는 사실과 안내. 출발, 기웃 결과, 귀가, 포스터, 요약, 등불 소품, 날 인사, 지난 메모 인용, 윤슬 쪽지 | 초상·이름표 없음. 조금 흐린 글자. 왼쪽 16px 아이콘: **사람에게 건네는 말**(날 인사·메모 인용·복구 줄·안내 쪽지)은 윤슬 얼굴, **일어난 일의 기록**(출발·기웃·귀가·포스터·소품·요약)은 사건 아이콘. 둘 다 `who:'house'`, `by` 없음. 윤슬 줄은 모델 기억·상황 설명에 들어가지 않는다 | 없음 (게임 자신의 글이지 누군가의 행동이 아니다) |
| **너** | 사용자가 한 일. 직접 건 포스터, 고른 대화 칩, 같이 가기에서 주운 것·만든 요리 | **대사창에는 띄우지 않는다** (탭을 빼앗지 않게. 그 자리에서 작은 반응만). 다시 보기에만. 아이콘은 내 얼굴(만들었으면), 아니면 손 (§5.10) | `user` |

- 문어 줄의 글은 그 순간 문어가 **실제로 쓴 글**(데모 규칙 문장이나 모델 원문)뿐이다. 코드에 박힌 대체 문장을 문어 목소리로 내지 않는다. 쓴 글이 없으면 문어 줄이 없다.
- 예외 하나 — **톡 한 줄** (주인 11-08): 깨어 있는 문어를 톡 하면 그날 마지막 차례에 대해 *미리 써 둔* 한 줄이 장면 말풍선에만 뜬다 (대사창 · 다시 보기 · 저장에 안 남는다). 데모 규칙 차례는 기록에 있는 사실 하나 ('데모' 꼬리표 아래), 모델 · 사람 차례는 그들이 마무리에 쓴 말만 (없으면 '응?'), 얼굴은 보통 그대로 (`BRAIN.tapLine`, MODEL_VOICE §3). 톡은 모델을 부르지도, 요청을 쌓지도 않는다 (MCP 가 붙어도 — 이미 쓴 말만 다시 보여 준다). 나중의 같이 가기: 주머니에서 고르기(블라인드) 전엔 톡 한 줄이 없다

**데모 표시는 늘 보인다 (중요 1).** 규칙이 문어를 움직이는 동안 상태 줄 이름 옆에 작은 꼬리표 `데모`(Galmuri7 16px)를 둔다. 대사창 이름표 `데모 규칙`은 문어 줄에만 뜨고, 문어 줄은 드물어서 그것만으로는 '늘'이 안 된다. NIGHT_LOG #8 의 (가)다. #8 에는 '어디에 둘지'만 남는다. 360px 에서 자리가 모자라면 방 제목이 먼저 '…'로 줄어든다. 모델이 붙으면 꼬리표는 `모델`.

**설정 › 누가 고르나** (11-07: 방 보기에서 옮김) — 이 칸의 글은 여기 한 곳에 모은다. 다른 문서는 여기를 가리킨다.

## 4. 지킬 원칙 (MODEL_VOICE 와 잇기)

### 4.1 원칙표

| 원칙 | 대사창에서 이렇게 지킨다 | 근거 |
|---|---|---|
| 말을 바꾸지 않는다 | 긴 말은 **쪽으로 나눌 뿐 자르지 않는다**. 쪽을 다시 이어 붙이면 원문과 같아야 한다. 다시 보기에는 원문 전체가 있다. **경계:** 대사창은 쪽으로 나눈다. 말풍선·칩·꼬리표·식탁 한 줄처럼 한 줄 자리만 '…' + 원문 보관(다시 보기에 전체). 이 규칙은 다른 문서에도 같다 | MODEL_VOICE §3 |
| 누가 말했는지 보인다 | 문어 줄에는 늘 이름표 + 출처 (`데모 규칙` / `모델` / `사람이 조작`). 다시 보기 줄 아래에도 `데모 규칙 · 15:13` | MODEL_VOICE §5, 중요 1 |
| 문어 입에 남의 말을 넣지 않는다 | 문어 목소리는 "지금 막 쓴 말"에만 쓴다. 지난 메모는 **집이 따옴표로 인용**한다. 안내는 집의 몫이다. 코드에 박힌 대체 문장(지금 app.js 집 행의 `ev.line \|\| '오늘은 집에 있을래'` 같은 것)을 문어 목소리로 내지 않는다. 문어 목소리 문구에 "눌러", "해 봐", "골라 봐", "적어 줘" 가 0건이어야 한다 (grep 검사) | 결정 #10~#12, MODEL_VOICE §3·§5 |
| 말하기를 강요하지 않는다 | 첫 인사·대화 대답은 선택이다. 모델이 `wave` 를 고르면 손만 흔든다. 답이 없거나 시간이 넘으면 가만히 있고, 그걸 문어의 선택처럼 꾸미지 않는다 (`by:'fallback'`) | MODEL_VOICE "말하기를 강요하지 않기", §2 |
| 읽은 척하지 않는다 | 기웃 줄에는 대사창에도 다시 보기에도 **글리프 + 단어**(✓ 읽음 · 📖 책장 메모 · ◌ 모의 방문 · ✕ 못 읽음 · ◌ 앉아만 있었음). 색만으로 구분하지 않는다. 빨강 없음 | 스킬 §2 |
| 코드는 사실만 | 등불 소품 줄을 "놓였어" 같은 사실 문장으로 바꾼다. "이제 진짜 내 다락이야" 같은 감정 주장은 뺀다 | CURIOSITY 원칙 1 |
| 압박이 없다 | "기다리고 있었어" 를 뺀다. 📜 버튼에 '안 읽은 줄 N' 배지나 점을 두지 않는다. 건너뛰어도 잃는 게 없다 | 중요 2 |
| 산책 박자를 붙잡지 않는다 | 게임은 대사창을 **기다리지 않는다**. 대사창은 받은 줄을 보여 주기만 한다. 모델에게 "누가 읽고 있어" 같은 신호를 보내지 않는다. 예외는 같이 가기(CORE_LOOP_V2) 하나: 화면 **재생 시계만** 기웃에서 최대 6초 멈출 수 있다 (문 앞 선택은 11-07 에 없앴다). 두뇌와 모델은 멈추지 않는다 | PROTOCOL §3 |
| 혼잣말은 말풍선으로만 | 톡·쓰다듬기 반응(`…♡`, `?`)은 장면의 기호 말풍선으로만 보인다. 대사창과 다시 보기에 넣지 않는다. 톡 한 줄 · '응?' · '쿨쿨…' 도 말풍선만 (로그 · 대사창 · 다시 보기에 안 남김, 11-08) | 결정 #10 |

### 4.2 기웃 메모는 누구의 말인가

기웃 줄에 붙는 한 줄 메모(`ev.note`)는 세 곳에서 온다: 그 방의 기억 조각(세계 데이터), 실제로 읽은 글의 요약, 방의 실마리 (`brain.js roomNote`). 읽은 글의 요약은 위키 문장이지 문어의 말이 아니다.

- 그래서 데모에서는 이 메모를 **집이 따옴표로** 보여 주고, 어디서 왔는지 작은 꼬리표를 붙인다: `“모자 속에 역사가 있었어” · 방 메모 · 데모 규칙` (세계 자료에서 규칙이 고른 것), `“…” · 위키백과` (읽은 글 요약). 초상을 붙이지 않는다. 꼬리표가 없으면 문어 말로 읽히기 때문이다.
- 진짜 모델이 기웃 메모를 직접 쓰면 그때만 문어 목소리(`모델`)로 보여 준다.

| 모델 연결 | 이 방에 처음 올 때 **결정 지점 1번** (선택). 아래 상황을 보낸다. 초상은 보통 얼굴 `idle` (눈 뜬 얼굴), 답에 `expr` 가 있으면 그것. 반눈 `calm`(-_-^)은 인사 기본값으로 쓰지 않는다. 폴짝은 하지 않는다 | 돌려받은 말 원문 그대로, `by:'model'`, `model` |
| 모델이 `wave` | 말 없이 팔만 흔든다. 대사창에는 집 "뚜루가 팔 하나를 흔들었어." | `{by:'model', action:'wave', text:null}` |
| 모델이 `watch` / `stop` | 아무 말 없이 다음 집 줄로 넘어간다 | `{by:'model', action}` |
| 8초 넘김 · 오류 | 인사를 하지 않는다. 행동한 것처럼 꾸미지 않는다 | `{by:'fallback', text:null}` |

모델에게 보내는 상황 (작게):

```js
{ point: 'meet', facts: { name: '뚜루', firstInRoom: true, timeOfDay: '아침' },
  menu: ['say', 'wave', 'watch', 'stop'] }   // line 은 선택 (권장 24자 이하, 넘어도 자르지 않음)
// 돌려받는 것: { action, line?, expr? }  — expr 는 'happy' | 'idle' | 'curious' | 'calm' 중 하나 (장면 코드 이름과 같게), 선택
```

- 모델은 MCP 로 붙은 "내 Claude"일 수 있다. 처음 만난 게 아니라 이 방에 처음 온 것이다. 서버는 Claude 의 기억·대화를 읽지 않고 이 방의 사실만 보낸다 (결정 20).
- 넣지 않는 말: "자기소개해 줘", "사용자가 기다려", "반갑게".
- 모델이 "나는 Claude 야"라고 써도 그대로 보여 준다.
- 인사는 **이 방에서 처음 한 번**이다. 매일의 인사는 집 목소리 날 인사다 (결정 11·13).
- 튜토리얼을 "처음부터 다시 보기"로 돌릴 때는 새로 말하게 하지 않는다. 집이 인용한다: "처음 만난 날 뚜루가 한 말: “안녕, 나는 뚜루야.”"

### 4.5 돌아와서 대화 두 차례 (결정 18)

산책에서 돌아온 뒤, 잠들기 전에 두 번 묻고 듣는다. 자리는 CORE_LOOP_V2 §3.4 순서표 ④′ (식탁 뒤, 똑똑·넓히기와 배지 틈·잠 앞). 집에 있는 날도 한다. 빈 차례엔 없다.

**모양**: `DLG.ask` 의 칩 모양 (§5.11). 칩 셋, 크기 같음, 미리 골라진 쪽 없음.

| 차례 | 칩 |
|---|---|
| 1 | [어디 갔어?] [어땠어?] [그만] |
| 2 | [뭐 봤어?] + 1에서 안 고른 것 + [그만] |

- 집에 있는 날은 [어디 갔어?] 대신 [뭐 했어?].
- 질문은 **사실을 묻는 말**을 먼저 둔다. 데모 규칙이 사실로 대답할 수 있어서다.
- [그만]을 누르거나 다른 일(뽈뽈 다녀와, 설정·앨범 열기, 놀이방 문 등)을 시작하면 대화는 조용히 끝난다. 다시 묻지 않는다. 시간 제한 없음.

**데모 대답** (`데모 규칙` 이름표. 그 산책 기록의 사실만 쓴다)

| 칩 | 대답 |
|---|---|
| 어디 갔어? | 들른 방 이름 둘까지: "모자의 방이랑 바다의 방에 갔어." 모의 방문이 있으면 "모자의 방은 문 앞까지만." |
| 뭐 봤어? | 기억한 곳의 상태대로: 읽음 "모자의 방 글을 읽었어." · 책장 메모 "책장 메모를 읽었어." · 모의 방문 "안은 못 봤어." · 못 읽음 "닫혀 있었어." |
| 어땠어? | **문장 없이 기호 하나.** 그 산책의 마무리 반응 기호(데모 규칙이 이미 고른 것, 예 ♪)를 다시 보여 주고, 없으면 '…'. 느낌 말을 규칙이 지어내지 않는다 (중요 3) |
| 뭐 했어? (집) | 집 활동 이름: "창가에 있었어." |

**모델이 붙으면**: 결정 지점 `chat`, 질문마다 한 번.

```js
{ point: 'chat', round: 1, q: '어땠어?', tripId: 'trip_k7x2',
  menu: ['say', 'watch', 'stop'] }      // 자기 산책 기록은 이미 안다. line 은 선택
// 돌려받는 것: { action, line?, expr? }
```

- `say` 의 `line` 은 글자 그대로 보여 준다 (`by:'model'`). 길면 쪽으로 나누고 자르지 않는다.
- `watch` 는 말 없이 너를 본다. `stop` 은 창 쪽으로 돈다, 담담하게. 8초 넘김은 가만히, `by:'fallback'`.
- 보내지 않는 것: 같이 갔는지 기다렸는지, 주운 것·간직한 것, 요리, "사람이 궁금해해" 같은 말.
- 상한: 귀가 한 번에 2번.

**기록**: 너의 칩(`who:'user'`)과 문어 대답(`by`, `action`, `text` 원문)을 `S.talk` 에 `kind:'chat'` 으로 남긴다 (§5.12). 새로고침해도 모델이 쓴 말이 사라지지 않게. 말 건 날(ACHIEVEMENTS)도 `trips[].talk` 이 아니라 `S.talk` 의 `kind:'chat'` 에서 읽는다. 사람 줄은 `trips` 에 넣지 않는다 (CORE_LOOP_V2 §5.2).

### 5.1 자리와 크기

- 대사창은 지금 있는 `#log-sec` 안에 JS 가 만든다. 그 섹션을 `#invite`(초대 바) 앞으로 옮긴다. 이렇게 하면 입장 연출(`css/intro.css`)이 `#log-sec` 을 숨겼다 보여 주는 규칙을 고치지 않아도 된다.
- 테두리는 지금 쓰는 `frame_dialog` 9-slice 다. (9-slice: 모서리 그림은 그대로 두고 가운데만 늘리는 테두리 그림.)
- 초상은 **정수 배**로 그린다: 64px + 테 → 72px 칸. 지금 로그의 96px 은 1.5배라 픽셀이 고르지 않다.
- 이름표: 왼쪽 위 테두리에 8px 걸친 작은 나무 판. 이름이 길면 이름만 `…` 로 줄이고, 출처(`데모 규칙`)는 줄이지 않는다.
- 📜 다시 보기 버튼: 오른쪽 위 테두리. 그림은 픽셀 두루마리 `icon.ui.backlog` (이모지 글자 아님). 보이는 크기 28px, 누르는 곳 44×44. 넘기기 영역보다 위층이라 눌러도 대사가 넘어가지 않는다.

| 화면 | 글자 | 한 쪽 줄 수 | 대사창 높이 | 한 줄 글자 수 (문어 / 집) |
|---|---|---|---|---|
| 기본 (픽셀 글꼴) | Galmuri9 20px, 줄높이 30 | 3줄 | 130px | 약 10자 / 12자 |
| 화면 폭 ≤ 340px | Galmuri7 16px, 줄높이 24 | 3줄 | 112px | 약 12자 / 15자 |
| 시스템 글꼴 | 16px, 줄높이 24 | 3줄 | 약 100px | 약 13자 / 16자 |

- 계산 (360×740): 장면 325 + 상태 44 + 대사창 130 + 여백 16 + 초대 바 약 64 (버튼 한 줄. 결정 18로 힌트 칸이 없다) + 목표 줄 24 = 603 → 첫 화면에 다 들어간다.
- 360×640: 장면 281 + 44 + 130 + 16 + 64 + 24 = 559 → 3줄 그대로 들어간다. 그래서 예전의 '높이 680 아래는 2줄' 규칙은 뺐다. 주소창이 보이면 실제 높이가 더 작으니 프로토타입에서 확인한다.
- 320×568: 250 + 44 + 112 + 16 + 64 + 24 = 510.
- (11-07) 상태 줄엔 [내 얼굴] 단추를 두지 않는다 (내 모습은 옷방). 장면 오른쪽 위 묶음도 장면 틀 안이라 높이를 늘리지 않는다.
- 가로 스크롤 0. 보통 글은 `keep-all` + `overflow-wrap:anywhere`, URL 은 `break-all`.
- 글자 폭은 어림이다. 프로토타입에서 실제로 잰다.

### 5.2 한 줄 → 쪽

- 한 쪽은 위 표의 줄 수만큼이다. 넘치면 **어절(띄어쓰기 단위)** 경계에서 다음 쪽으로 넘긴다. 한 어절이 한 줄보다 길면(URL) 그 어절만 쪼갠다.
- 대사창 안의 모든 줄 높이를 같게 둔다. 그래야 "다음 쪽"이 글을 한 칸 올리기만 하면 되고, 줄이 반쯤 잘리지 않는다.
- 대사창에는 그 사건의 **첫 문장**(+ 기웃이면 상태와 "처음 온 곳", 메모 인용)만 나온다. 곁가지(aside, bridge, 지난번 메모·날씨, 돌아온 이유, 집 활동 설명)는 다시 보기에만 있다. 산책 한 번이 대사창 줄 10개 안팎이 되게 하려는 것이다.
- **덧쪽** (선택, `DLG.say` 의 `more`): 같이 가기의 '어깨 너머' 글(CORE_LOOP_V2 §3.2)을 이야기 시간(①)에 기웃 줄 뒤 덧쪽으로 보여 준다. **최대 2쪽.** 넘치면 '…' 그리고 다시 보기에 전체와 출처 링크 (읽은 글의 발췌라 문어 말이 아니다. 문어·모델 말은 §4.1 대로 자르지 않는다). 같이 가는 동안에는 대사창이 아니라 기웃 판에 나온다.

### 5.3 타자기 (글자가 한 자씩 나오는 효과)

| 항목 | 값 |
|---|---|
| 쓰는 줄 | 문장 줄(문어·집·나). 상태 칩이 붙은 **기록 줄**(출발·기웃·포스터·요약)은 한 번에 나타난다 (2px 올라오는 정도) |
| 속도 | 글자당 45ms (초당 약 22자). 테스트용 `?speed=` 배수를 따른다 |
| 쉼 | `. ? !` 뒤 +180ms, `,` 뒤 +90ms, `…` 뒤 +240ms. 줄 끝에는 쉼 없음 |
| 단위 | 글자 묶음 단위 (`Intl.Segmenter`, 없으면 `Array.from`). 이모지를 쪼개지 않는다 |
| 줄바꿈이 튀지 않게 | 쪽 전체를 먼저 깔고, 아직 안 나온 부분만 `visibility:hidden` 으로 둔다. 줄바꿈 자리가 처음부터 정해진다 |
| 박자 | `requestAnimationFrame` 에 누적 시간으로 센다. 탭이 숨겨지면 그 줄을 바로 끝낸다 |
| 커서 | 깜빡이는 커서는 두지 않는다 |

### 5.4 누르면 무슨 일이

| 대사창 상태 | 누르면 |
|---|---|
| 글자가 나오는 중 | 그 쪽을 바로 다 보여 준다 |
| 다 나왔고 다음 쪽이 있음 (▼) | 다음 쪽 |
| 다 나왔고 기다리는 줄이 있음 (▼) | 다음 줄 |
| 기다리는 줄이 없음 | 아무 일 없음. 대사창이 2px 눌리기만 한다. 마지막 줄은 그대로 남는다 |
| 선택 단추가 떠 있음 (`DLG.ask`) | 넘어가지 않는다. 단추만 눌린다 |

- 쪽이 바뀐 뒤 120ms 안에 들어온 탭은 무시한다 (두 번 눌림 방지).
- 판정은 `click` 으로 한다. 스크롤하다 손가락이 닿은 것은 탭으로 치지 않는다.

### 5.5 저절로 넘김과 대기열

대기열은 차례를 기다리는 줄 목록이다.

| 줄 종류 | 언제 | 넘어가는 법 |
|---|---|---|
| 흐르는 줄 | 산책 중에 온 줄 (출발~요약, 소품 줄) | 뒤에 기다리는 줄이 있으면 **읽는 시간**이 지난 뒤 저절로 넘어간다. 마지막 줄은 남는다 |
| 기다리는 줄 | 첫 만남 3줄, 날 인사, 메모 인용, 복구 줄 | 눌러야 넘어간다. ▼ 는 3번 통통 튄 뒤 멈춘다 |

- **읽는 시간** = 1.5초 + 글자당 65ms, 최소 2.5초, 최대 6초. 줄이 시작된 때부터 잰다. 단, 글이 다 나온 뒤 최소 1.2초는 머문다. 문어 줄은 ×1.25 (최대 6초). 20자 줄이면 약 2.8초다. 읽는 시간 공식은 이것 하나다 (CORE_LOOP_V2 도 이것을 쓴다).
- 지금 산책 줄 간격(2.2~4.5초)과 거의 같은 박자다. 그래서 **그냥 보고만 있어도 다 읽히고**, 누르면 빨라질 뿐이다.
- '동작 줄이기'를 켜도 읽는 시간은 그대로다. 읽는 시간은 움직임이 아니다.

| 상황 | 대사창이 하는 일 |
|---|---|
| 기다리는 줄 3개 이상 | 읽는 시간 ×0.6, 타자 2배 빠르게 |
| 5개 이상 | 타자 없이 바로 |
| 6개 초과 | 가장 오래된 **집 줄**부터 대사창을 건너뛰고 다시 보기에만 남긴다. **문어 줄은 건너뛰지 않는다** |
| 바로 돌아오기 (주 버튼) | 지금 줄을 바로 끝낸다. 남은 줄은 다시 보기로만 보낸다. 산책이 끝나면 마무리만 보여 준다: 그 산책에서 문어가 **실제로 쓴** 마지막 줄(마무리 반응 → 없으면 기억 한 줄 → 없으면 집 활동 한 줄. 데모 규칙 문장이나 모델 원문)이 있으면 그 줄 ▼ 집의 요약. 없으면 **요약 한 줄만**. 문어 줄을 지어 채우지 않는다 |
| 뽈뽈 다녀와 누름 | 기다리던 줄을 비운다 (다시 보기에는 있다) |
| 자리 비움: 탭을 10초 넘게 숨겼다 돌아옴, 또는 다른 창(포스터·설정·앨범·달리기·다시 보기·미니게임)이 덮었다 닫힘 | 덮인 동안 타자와 시계를 멈춘다. 산책은 그대로 진행된다. 돌아왔을 때 기다리는 줄이 2개를 넘으면, 마지막 문어 줄 1개와 마지막 집 줄 1개만 남기고 나머지는 다시 보기로 보낸다. 이 일이 처음 생길 때 한 번만 집 줄 "지나간 말은 다시 보기에 있어." 를 덧붙인다 |
| 버튼 안내 쪽지가 떠 있음 | 타자와 저절로 넘김을 멈춘다 (`DLG.hold`) |
| 목록을 통째로 다시 그림 (새로고침·다른 탭 저장·불러오기) | 대기열에 쌓지 않는다. 가장 새 줄을 타자 없이 조용히 보여 준다 |
| 앱을 처음 열 때 | 날 인사 → (메모 인용) → (복구 줄)을 기다리는 줄로 넣는다. **입장 연출이 끝난 뒤**(`INTRO.onDone`) 시작한다 |

### 5.6 ▼ 와 `…`

- **▼ = "누르면 다음이 있어."** 다음 쪽이나 기다리는 줄이 있을 때만 보인다. 눌러도 아무 일 없는 ▼ 는 거짓말이라 마지막 줄에서는 안 보인다.
- **`…` = "곧 더 와."** 산책 중에 기다리는 줄이 없고, 마지막 줄을 다 보여 주고 1.5초가 지나면 ▼ 자리에 작게 나온다. **움직이지 않는다.** 산책 중이라는 표시는 「다녀오는 중…」 버튼이 이미 하고 있다.
- 지금 로그에서 `…` 줄이 끝없이 숨쉬던 것(`.lrow.typing`)은 대사창에서는 없다.

### 5.7 화면 낭독기

라이브 영역은 화면 낭독기가 새로 바뀐 글을 저절로 읽어 주는 칸이다. inert 는 창이 열린 동안 그 바깥을 누를 수도 읽을 수도 없게 막는 상태다.

| 요소 | 마크업 | 읽히는 것 |
|---|---|---|
| 대사창 묶음 | `#dbox` (`role="group"`, `aria-label="대사"`) | |
| 타자로 나오는 글 | `aria-hidden="true"` | 읽지 않는다 (반쪽 글자를 읽지 않게) |
| 줄 알림 | 숨긴 `<p aria-live="polite" aria-atomic="true">` | 줄이 시작될 때 **한 번만**, 모든 쪽을 합친 전체 글. 예: "뚜루, 데모 규칙: 안녕, 나는 뚜루야." "모자의 방, 읽음, 6초, 처음 온 곳." 장식 이모지는 빼고 읽는다 |
| 넘기기 | 글 칸 위에 얹은 `<button>` (선택 단추와 **형제**로 둔다. 단추 안에 단추를 넣지 않는다). `DLG.ask` 동안에는 숨긴다 | "다음 대사" / 글이 나오는 중이면 "대사 끝까지 보기" / 다음이 없으면 `aria-disabled` + "다음 대사 없음". Enter·Space 로 누른다 |
| 선택 단추 줄 (`DLG.ask`) | `role="group"` + `aria-label`(묻는 글) | 단추마다 글자 그대로 |
| 📜 버튼 | `<button aria-haspopup="dialog">` | "대사 다시 보기" |
| 다시 보기 창 | `<dialog>` 안의 기록 목록 (`role="log"`) | 열려 있을 때만 새 줄을 읽는다 |

- 라이브 영역은 **늘 하나만** 살아 있다. 창이 닫혀 있으면 기록 목록은 그려지지 않아 조용하고, 대사창이 읽어 준다. 창이 열리면 바깥이 inert 가 되어 대사창은 조용해진다. 그래서 같은 줄을 두 번 읽지 않는다.
- 대사창은 포커스를 저절로 가져가지 않는다. 이름 칸 같은 곳에 글을 쓰는 도중에 포커스를 빼앗지 않기 위해서다.
- 실제 폰(TalkBack 또는 VoiceOver)에서 한 번은 직접 확인한다. 자동 테스트로는 확인할 수 없다.

### 5.11 다른 기능과 잇는 곳 (대사창이 내놓는 손잡이)

훅(hook)은 다른 코드가 끼어들 수 있게 한 줄 불러 주는 자리다.

| 손잡이 | 쓰는 곳 | 약속 |
|---|---|---|
| `DLG.say({voice, text, by, expr, pace, model, more})` | 첫 인사, 집 줄, 너 줄 | 문어 목소리는 `by` 가 꼭 있어야 하고, 글은 데모 규칙이나 모델이 쓴 것이어야 한다. `by` 가 없으면 집 줄로 떨어진다. `voice:'user'` 는 다시 보기에만 들어간다. `more` 는 덧쪽(§5.2) |
| `DLG.ask({voice, by, text, choices:[{id, label}], cancel, chips})` → `Promise<id 또는 null>` | 넓히기 제안(ROOM_EXPANSION, 나중), 돌아와서 대화(§4.5). (11-07: CORE_LOOP_V2 문 앞 선택은 없앴다) | 아래 표 |
| `DLG.hold(true/false)` | 버튼 안내 쪽지 | 쪽지가 떠 있는 동안 타자·저절로 넘김을 멈춘다. 닫힌 쪽지 글은 다시 보기에 📌 집 줄로 남는다 |
| `DLG.subscribe(fn)` | 같이 가기 헤엄 화면 등 겹창 | 겹창이 산책 줄을 자기 화면에 띄우고 싶을 때. 대사창은 산책의 결정에 아무 통로도 만들지 않는다 |
| `DLG.open()` | 📜 버튼 · 테스트 (11-07: 방 보기 문은 없앴다) | |
| `html[data-ui-busy]` | 배지 알아보기 (ACHIEVEMENTS §7.1) | 대사창은 글자가 나오는 중·`DLG.ask`·다시 보기 열림·쪽지 떠 있음일 때 켠다. 비춤은 TUTORIAL 이 같은 속성을 켠다. 켜는 쪽이 여럿이라 이유마다 따로 세고, 하나라도 남아 있으면 켜 둔다 |
| 테스트용 `current()`, `pending()` | 스모크 테스트 | 읽기 전용. `{voice, text, by, page, pages}`, 기다리는 줄 수 |

**`DLG.ask` 규칙**

| 항목 | 정한 것 |
|---|---|
| 모양 | 대사창 높이는 그대로(130px). 위에 글 2줄, 아래에 단추 줄(높이 44px). 단추 2~3개, 크기가 같고 미리 골라진 쪽이 없다. 글자가 길면 단추 글꼴은 Galmuri7 16px (프로토타입에서 잰다) |
| 글 길이 | 묻는 글은 **한 쪽(2줄, 집 약 24자)** 에 들어가게 쓴다. 넘치면 앞쪽을 ▼ 로 먼저 넘기고, 마지막 쪽에서 단추가 뜬다 |
| 넘기기 | 단추가 떠 있는 동안 넘기기 단추를 숨긴다. 상자 톡으로 넘어가지 않는다 |
| Esc · 폰 뒤로 가기 | `cancel` 값을 돌려준다. `cancel` 이 없으면 아무 일 없이 질문이 남는다 |
| 바깥 톡 | 늘 아무 일 없다 (장면 톡·쓰다듬기와 헷갈리지 않게). 대답으로 치지 않는다 |
| 다른 창이 덮음 | 질문은 그대로 남는다. 닫히면 다시 보인다 |
| 칩 모양 (`chips:true`) | 돌아와서 대화용. 칩 3개까지, 글 6자 안팎, Galmuri7 16px |

### 5.13 2D 대체 장면

- 대사창과 다시 보기는 장면 밖의 화면 요소라 2D 와 3D 에서 똑같이 돈다.
- 초상은 `APP.portraitFor(expr)` 를 쓴다. 2D 에서는 SVG 얼굴 초상이 나온다.
- WebGL 이 끊겨 도중에 2D 로 바뀌거나 문어 색이 바뀌면 대사창 초상도 다시 그린다. 그래서 `refreshPortraits` 가 찾는 범위를 `#log canvas.lport-cv` 에서 `canvas.lport-cv` 로 넓힌다.
- 2D 에서는 기웃 말풍선이 다락 머리 위에만 뜬다. 문장은 대사창이 같은 방식으로 맡으니 잃는 것이 없다.

### 5.14 다른 작업과 덜 부딪히게

- 새 파일 `js/dialogue.js` (전역 `DLG`)와 `css/dialogue.css` 가 거의 전부를 맡는다.
- 대사창 스크립트는 시작할 때 `#log` 를 다시 보기 창 안으로 **옮긴다**. 스크립트가 없거나 시작하다 실패하면 지금 화면(「오늘의 산책」)이 그대로 남는다.
- 주소에 `?dlg=0` 을 붙이면 옛 화면으로 볼 수 있다 (비교·문제 찾기용).
- 대사창은 `#log` 의 화면 요소(DOM 행)를 붙잡지 않고 **복사본**을 들고 있다. `renderLog` 가 목록을 통째로 다시 그려도 깨지지 않는다.
- 참고: 지금 `renderLog` 는 진행 중인 산책을 그리지 않는다. 산책 중에 목록을 다시 그리면 이미 나온 산책 줄이 목록에서 사라진다 (지금도 같다). 대사창은 복사본이라 괜찮다. v2 에서 "보여 준 줄까지" 그리게 고친다.

### 5.15 장면 말풍선 맞추기 (11-08)

장면 칸(`#scene`)은 넘친 것을 잘라 내서, 삐져나간 말풍선은 글자가 사라진다. 그래서 말풍선을 장면 안에 맞춘다 (3D `js/ui-art.js keepInside`, 2D `js/app.js keepBubble2D`). 두 테마 같은 규칙, 가장자리 P = 4px:

1. 폭 220px (좁은 장면이면 장면 폭 − 2P). 2D 는 150px 그대로.
2. 글 길이: 톡 한 줄은 데모 22자 · 모델 24자 + '…' → 픽셀 2~3줄 · 시스템 1~2줄. 생각 말풍선의 메모는 24자 + '…'.
3. 옆: 가장자리 안으로 민다 (오른쪽 위 아이콘 · 바깥 집 단추와 겹치면 그 옆까지, 장면 밖으로는 안 민다). 민 만큼 픽셀 꼬리를 거꾸로 옮기되 풍선 아랫변 안 (가운데 ± 폭/2 − 20).
4. 위: 장면 위쪽을 넘으면 그만큼 아래로 (`--bub-dy`, 등장 애니메이션 · 숨쉬기 여유 2px). 12px 넘게 내려오면 머리에 닿으니 픽셀 꼬리는 뺀다 (`data-tail="off"`). 글이 장면 안에 다 보이는 게 꼬리보다 먼저다.
5. 보이는 동안 5 Hz 로 다시 맞춘다 (문어가 걸어가도). `line-clamp` 는 쓰지 않는다 (꼬리를 자르고 `[hidden]` 을 덮는다).

## 7. 플레이테스트에서 볼 것

폰으로, 처음 하는 사람 한 명 + 주인. 말로 묻지 말고 먼저 지켜본다.

| 볼 것 | 어떻게 | 좋은 신호 |
|---|---|---|
| 대사창을 누를 줄 아나 | 첫 화면에서 아무 말 없이 건넨다 | 쪽지가 뜬 뒤 5초 안에 대사창을 누른다 |
| 산책을 보기만 해도 다 읽히나 | 산책 한 번을 손대지 않고 본다. 끝나고 "어디 다녀왔어?" | 들른 곳 하나 이상과 가져온 것을 말한다 |
| 글과 장면이 어긋나나 | 문어가 마당에 나타날 때 대사창 글을 본다 | "글이 늦다/빠르다" 는 말이 없다 |
| 타자 속도 | 45ms 와 70ms 를 프로토타입 토글로 비교 | 답답하다는 말이 없다. 누르면 바로 끝나는 게 자연스럽다 |
| 한 쪽 3줄이 맞나 | 넘김 횟수를 센다 | 한 줄에 쪽 넘김이 거의 없다 |
| 누가 말했는지 보이나 | 끝나고 "방금 '창턱에 이끼 화분이 놓였어'는 누가 한 말이야?" | "집(게임)" 이라고 답한다. 문어 줄은 문어라고 답한다 |
| 다시 보기를 찾나 | 산책 뒤 "아까 그 말 다시 보고 싶으면?" | 📜 를 스스로 찾는다. "못 읽음" 표시 뜻을 안다 |
| 눈이 피곤한가 | 5분 켜 둔다. 동시에 움직이는 것 수를 센다 | 거슬린다는 말이 없다. 대사창 둘레에서 움직이는 것이 1개 이하 |
| 버튼이 밀려 불편한가 | 붙이기 / 걸치기 토글 비교 | 한쪽을 분명히 고른다 (§8-1) |
| 바로 돌아오기 뒤 두 줄이 충분한가 | 나가 있는 동안 주 버튼을 누르게 한다 | "뭐가 있었는지 모르겠다"는 말이 없다 |
| 화면 낭독기 | TalkBack 으로 산책 한 번 | 같은 줄을 두 번 읽지 않는다. 반쪽 글자를 읽지 않는다 |

자동으로 볼 숫자 (사람에게는 보이지 않는 테스트에서만): `?speed=4` 로 산책 10번을 흘려 **대사창을 건너뛴 문어 줄 0**, 산책 한 번에 대사창 줄 수 10개 안팎.

## 8. 주인이 정할 것

1. **대사창 자리.**
   - (가) 장면 **바로 아래에 붙이기** (추천). 방을 가리지 않는다. 대신 아래 버튼이 대사창 높이만큼 내려간다.
   - (나) 레퍼런스처럼 장면 아래쪽 빈 띠에 **살짝 걸치기**. 그림과 한 틀로 보인다. 대신 문어가 앞쪽(담요)에 있거나 확대했을 때 가려질 수 있다.
   - 프로토타입에 토글을 넣었으니 폰에서 둘 다 보고 골라 줘.

   - 인사·메모·쪽지는 어느 쪽이든 눌러야 넘어간다.
