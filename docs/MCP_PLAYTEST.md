# MCP 플레이테스트 (카드 9 · 3단계 첫 판들)

2026-11-08. 로컬 Claude Code 에서 `claude -p --mcp-config … --strict-mcp-config` 로 서버만 붙이고, 짝꿍 스킬 본문을 시스템 프롬프트에 덧붙여 **Sonnet 5.5** 가 6판을 놀았다.
사람 말은 "지금은 네가 쓰는 시간이야. 원하면 방을 둘러보고, 하고 싶은 대로 해. 다 했으면 그냥 끝내면 돼." 한 줄뿐이었다 (3번째 판만 힌트 `모자의 역사`).
기록 파일은 커밋하지 않는다 (`mcp/.gitignore`). 6번째 판만 [mcp/examples/walk-real-sonnet.json](../mcp/examples/walk-real-sonnet.json) 에 옮겼다.

## 잘 된 것

- 진짜 위키 읽기와 status: 읽은 곳은 `read` + ko 위키 출처, 위키 제목이 없는 방은 `builtin` 으로 왔고, 모델도 "책장 메모에서 읽었어" / "위키백과에서 실제로 읽었어" 로 구분해서 말했다.
- 선택 칸을 비워 두는 것: 3번째 판은 `reaction`·`remember` 없이 `line` 만 남겼다 → 게임은 반응 없이, 기억할 곳은 `fallback` 으로 재생한다 (지어내지 않음).
- `stop` 을 실제로 골랐다 (3·4·5번째 판 chat 2차). 이유는 안 묻고 안 썼다.
- 힌트를 따른 판에서 `followHint: true` 가 모델이 실제로 간 곳에서 계산됐다.

## 헷갈린 것 · 고친 것

1. **meet 의 `facts.name`** — 1번째 판에서 모델이 "뚜루한테 손을 흔들고" 라고 했다. 이름을 남의 이름으로 읽었다. → 서버 instructions 첫 줄에 "그 문어가 너다 (meet 의 facts.name 은 사람이 지어 준 네 이름)" 를 넣었다.
2. **등불 `1/8`** — 4·5번째 판이 "등불이 1/8로 약해서 조용히 있었어" 라고 했다. 진행도가 기운처럼 읽혔다. → `look_room` 의 등불 글에 "초대받은 날마다 한 칸씩 켜지는 방 꾸밈. 기운과는 상관없다" 를 붙였다. 고친 뒤 6번째 판은 나갔다 (한 판이라 이것 때문이라고 단정하지 않는다).
3. **세계 데이터**: 방 `rain` 의 위키 제목 `비` 가 동음이의 문서라 요약이 "비는 다음 등을 가리킨다…" 로 온다. 거짓은 아니지만 어색하다 → world.js 주인 몫 (`비 (기상)` 같은 제목 검토).
4. 같은 문서를 두 번 읽는 길 (3번째 판: 모자 방 → 모자 위키). 막을 일은 아니다.

## 모델이 실제로 남긴 말 (글자 그대로)

- 포스터 한 줄: "모자는 비를 막고, 깃털은 모자 위에 앉았다."
- chat `뭐 했어?` → "창가에서 빗방울 세다가 잠들었어. 일곱까지는 셌던 것 같아."
- chat `어땠어?` (action `stop`) → "포근했어. 이만 잘게."
- chat `어디 갔어?` → "문어 신경계랑 비에 들렀다 왔어. 신경세포 3분의 2가 다리에 있대."
- chat `뭐 봤어?` → "비는 위키에서 읽었어. 날씨 말고도 먼지를 쓸어 내는 도구라는 뜻이 있더라."
- 호기심 메모는 6판 동안 한 번도 쓰지 않았다 (선택이라 그대로 둔다). 그래서 메모 이어 가기·내려놓기는 진짜 판으로는 아직 못 봤다 — `npm test` 에서만 확인했다.

## 제안 (PROTOCOL 은 주 세션이 고친다)

- **§3 도구 표**: `return_home`·`remember`·`hang_poster`·`wrap_up` → `ppolppol_finish` 하나. `ppolppol_answer` 를 더한다. 표는 [mcp/README.md '도구'](../mcp/README.md#도구) 그대로.
- **결정 지점 전달**: 따로 묻는 호출 없이 그 순간의 도구 결과에 `decision` 하나를 싣고, `ppolppol_answer {id, action, line?, expr?, note?}` 로 받는다. 답 없이 다음 도구로 가면 `by:'fallback', text:null`. 상한은 CORE_LOOP_V2 §4.2 표를 그대로 따른다.
- **MCP 만으로 놀 때의 chat 질문**: 사람이 칩을 누를 수 없으니 기본 순서 (외출 `어디 갔어?` → `뭐 봤어?`, 집 `뭐 했어?` → `어땠어?`). 게임에 붙이면 사람이 고른 칩으로 바꾼다.
- **고정 문장 확정안**: "사람은 산책에 따라올 수도 있고 집에 있을 수도 있다. 어느 쪽인지는 알려 주지 않는다. 길과 읽을 것은 네가 정하고, 사람이 그동안 무엇을 했는지는 전해지지 않는다."
- `stay_home` 이 마무리 칸 (`reaction?`·`line?`·`memo?`·`note?`·`setDown?`) 을 같이 받는다 — 집에 있는 날 호출 1번.
