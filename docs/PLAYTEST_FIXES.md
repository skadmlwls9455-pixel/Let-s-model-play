### 추가 1. 결정에 맞춘 방법 (A2 · A4)

**A2 — 난수 순서를 안 바꾸고 집에 있는 날 반응 고르기**
- 지금 `homeTripFrom`(`brain.js` 1080 부근)은 주 난수 `R` 에서 `tWrap · 스티커 자리 · paper · rLine` 네 번을 뽑고, 반응은 `'졸림'` 으로 고정이다. 메모는 이미 따로 시드한 `memoRng(base.seed)` 를 쓴다.
- 반응도 같은 식으로 **주 `R` 을 건드리지 않는 별도 줄기**로 고른다. `memoRng`(`brain.js:1053`)가 시드에 상수를 XOR 해 줄기를 나누는 관례를 그대로 따른다: `var rr = rng(((base.seed >>> 0) ^ 0x72656163) >>> 0);   /* 'reac' */`. 집 활동(`act.id`)마다 후보를 두고 `rr()` 로 하나 고른다. 문장 고르기는 지금처럼 기존 `rLine` 을 쓴다. 이렇게 하면 외출·빈 차례 결과와, 집에 있는 날의 다른 필드(시간·스티커 자리·종이·메모)가 전부 그대로다.
- **문장 주의**: 지금 `우쭐`("끝까지 다 읽었어", "네가 흘린 힌트, 끝까지 따라갔어")과 `덤덤`("그래도 다녀왔어")의 문장은 산책을 전제로 한다. 집에 있는 날 이 반응을 고르면 사실이 아닌 말이 된다(CURIOSITY_NOTES 원칙 1). 그래서 `world.js` reactions 에 반응마다 `home:` 문장 묶음을 따로 두고, 집에 있는 날엔 그것만 쓴다. 예: 덤덤 = "창밖만 봤어. 그거면 됐어", 우쭐 = "선반 정리 다 했어. 흠, 꽤 깔끔해".

**A4 — 빈 차례 포함, 그날 첫 마친 차례에만 등불 +1**

## A1. 첫 손길이 "?" 다

**근거**
- 톡 → `app.js:348` `on.tap` → `say('?', 'curious', 1600)`.
- `say()`(`app.js:635`)는 말풍선을 띄우고 오늘 로그에 "혼잣말" 줄도 쓴다. 그래서 톡·창문·쓰다듬기가 전부 로그에 남는다.
- 쓰다듬기는 0.35초 꾹 누르기나 문지르기로만 된다(`scene3d.js:1879,1887`). 안내가 없다.
- 플레이에서 4번 톡 쳤는데 4번 다 "?"였다.

**고치는 법** (장면 코드는 안 건드려도 된다)
1. `say()` 를 둘로 나눈다. `murmur(text, expr, ms)` 는 말풍선과 표정만, `say()` 는 지금처럼 로그까지 남긴다. 톡·창문·쓰다듬기·자는 중 "…zZ" 는 `murmur`, 산책·마무리·인사처럼 의미 있는 말만 `say`.
2. 톡은 즉시 몸으로 반응한다. `scene.setExpression('happy')` 의 폴짝 한 번(이미 있음)과 `AUDIO.on('poke')`(없으면 새 효과음 한 개)를 같은 프레임에 부른다. 말풍선은 뒤따라도 된다.
3. 탭 대사는 결정거리 3번 안("?" → "응?" → "…불렀어?" 다음엔 섞인 꼬리)대로 세션 안 탭 순서로 돌린다. 데모 규칙 문장이고, 횟수에서 취향을 만들지 않는다.
4. 처음 한 번만 손가락 힌트를 1.5초 띄운다("꾹 누르면 쓰다듬어", `S.settings.seenPetHint`). 그다음엔 다시 안 띄운다.

**하지 말 것**: 탭 횟수 게이지, 탭 보상, "많이 쓰다듬어 줘서 좋아해" 같은 횟수→감정 문구.

**검증**
- playtest 의 `firstTapBubble` 이 "?" 가 아니고 `tapLogRows` 는 0.
- smoke 단계 추가: 톡 → 첫 반응(표정 바뀜)이 100 ms 안. `scene.expression()` 을 rAF 로 지켜본다.
- smoke 단계 추가: 꾹 400 ms → 하트 파티클.
- 새 문구가 있으면 `python3 tools/subset-fonts.py --check` 가 `stale: none`.

## A2. "오늘은 여기까지" 로 첫 세션이 끝난다

**근거**
- 집에 있을 확률이 낮엔 0.12, 0~5시엔 0.32다(`brain.js:1111` `stayProbability`).
- 집에 있는 날의 마무리 반응은 코드상 **늘 '졸림'**이다(`brain.js:1086`).
- '졸림' 문장 두 개 중 하나가 "오늘은 여기까지. 잘 자"다(`world.js` reactions).
- 따로 돌린 판에서 첫 초대가 10초 만에 이 문장으로 끝났다. 처음 온 사람에겐 "오늘 분량 끝"으로 읽힌다.

**고치는 법**
1. `world.js` '졸림' 문장에서 사람에게 끝을 선언하는 말을 빼고, 문어 자기 상태만 말하는 문장으로 바꾼다(예: "눈이 좀 감겨. 담요 속에 있을게"). 데모 규칙의 템플릿이라 바꿔도 된다. **모델이 `by: 'model'` 로 쓴 말은 지금처럼 글자 그대로 둔다.**

## 이 피드백의 한계
- 소프트웨어 WebGL(SwiftShader)로 돌렸다. 산책 시간은 앱 타이머라 맞지만, 장면 움직임의 부드러움은 실기기에서 다시 봐야 한다.
- 위키는 가짜 응답이었다. 플레이어도 한 명(에이전트)이다. 실제 사람 3~5명의 "처음 2분" 화면 녹화로 A1~A3 우선순위를 확인하길 권한다.
