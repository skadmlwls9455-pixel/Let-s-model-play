## 1. 넓히기 (방향)

주인: "지금은 귀여운 방치형 게임 같긴 한데 크기가 너무 작은 느낌? 맵이 좁아서 약간 답답 … 따로 뚝 끊기는 게 핵심 같긴 하다, 연결시킬 방안 …
문어 집만 띨롱 있으니까 심심하고 현실성 없어 보여서 … 마을에서 이것저것 할 수 있으면 좋겠어. 문어 마을인 거지. 축제 같은 기간도 있고. 이벤트를 좀 넣어보는 거야 계절마다."

- 맵 넓히기: **대찬성**. 바깥을 걸어 다니고 카메라가 따라오는 쪽으로.
- 해변: "해안가 대신에 들어가서 수영하면서 조개 먹는 게임 … 시간당 제한 있는데 잘하든 못하든 일정 갯수는 주자." (※ '시간당 제한' 의 뜻은 아직 안 물었다 — 한 판 길이인지, 한 시간에 받는 조개 상한인지)
- 매일 조금씩 바뀌는 줍기: 좋다.
- 도감 · 박물관: 좋다. 음식 도감도 만들자 (의상 쪽 도감은 이미 있다).
- 놓아둔 것을 보고 오는 손님: 좋다 — 구체 예시를 보고 싶다.
- 벽지 등 인테리어가 자유로우면 좋겠다.
- 사진: "맵들 돌아다니면서 문어랑 사진 찍기 기능은 꼭 … 모션 조개로 사서 문어랑 사진 찍을 수 있는 거야."
- 계절 아이템: "놓친 건 친구가 가지고 있는 집 놀러가면 설계도 받아서 재료 모아서 만드는 식 … 계절이면 몇 개월 단위니까 오히려 재밌는 유인."
  → 11-08 의 '계절 물건은 안 사라짐 · 한정 없음' 을 주인이 고친 것. 조건 (이쪽이 붙임): 영영 못 얻는 것은 없다 (친구 집 · 혼자서도 '지난 철 서랍' · 다음 해 제철), 남은 날 표시와 재촉 없음.
- 멀티: 고려 중. (조사: Vercel 에서 된다 — 먼저 비동기 방문, 실시간은 그다음. `wip/round6-world/README.md` 7절)
- 일 나누기: 다른 계정 세션 + 이 세션 + Console 선불 크레딧 300달러 (갈래 일곱, `wip/round6-world/`).

## 2. 플레이하며 불편했던 것 → 고침 (이 세션, 11-18)

| 주인 말 | 고친 것 |
|---|---|
| "옷 염색시키는 쪽이 의상 마네킹만 있어서 눈에 잘 안 띄는데 … 하얀 원피스라도 마네킹에 입혀서" | 위층 마네킹에 흰 원피스 (분홍 허리 띠 · 퍼지는 치마). 마네킹을 톡해도 재봉틀과 같은 창이 열린다 (`#btn-sew-doll`) |
| "계단이랑 방이 붙어있어서 잘못 방문할 여지 … 계단이나 문을 좀 옮겨줘" | 다락 계단을 뒷벽 오른쪽 구석 (마당 문 바로 옆 — 발치가 문 앞 0.4 m) 에서 **왼벽 앞쪽 구석 (소파 옆)** 으로. 두 문 (마당 · 놀이방) 에서 가장 먼 자리이고, 벽에 붙일 빈 자리가 여기뿐이다 (뒷벽 · 왼벽 나머지는 창 · 보드 · 선반 · 상자가 차 있다). 계단은 **발치에서만** 오른다 (옆구리에 붙어 밀어서는 안 오른다).
  폰 (폭 360~430) 의 기본 구도에선 그 구석이 왼쪽 가장자리 밖이다 → 계단이 안 보이는 동안 **왼쪽 가장자리에 작은 계단 그림 단추** 가 뜬다 (누르면 걸어가 오른다 · 걸어갈 때 화면이 따라온다 — 예전엔 톡해서 걷는 동안 화면이 안 따라왔다). 계단이 화면에 들어오면 단추는 계단 그림 위의 투명 칸으로 돌아간다.
  ※ 다른 안: 계단을 화면 안으로 늘리기 (찍어 보니 소파 위에 겹쳐 어지러웠다) · 방 배치를 바꿔 계단을 뒷벽 가운데로 (주인 승인 거리) |
| "조개 살 때 염색할 옷을 나중에 고르는 걸로 … 구매 하시겠습니까? 같은 버튼 없어서 조개 다 날린 데다가 염료 적용할 옷도 현재 옷으로 자동 설정" | 조개로는 **염료를 산다** (확인 한 번: 살래 / 그만) — 사자마자 물들이지 않는다. 물들이기는 **물들일 것을 고르고** 색을 누른 뒤 확인 한 번. 원래 색으로 돌리기도 확인 한 번 (조개 6 으로 물들이는 것 · 텃밭 염료는 예전 그대로다 — 바뀐 것은 확인과 고르는 차례) |
| "헤어 악세사리나 신발 등도 염색 가능하면" | 옷 · 신발 · 악세사리를 물건마다 따로 물들인다 (`S.user.dyed = { outfit: {…}, shoes: {…}, acc: {…} }`). 예전 색 하나 (`S.user.dye`) 는 그때 입고 있던 옷의 색으로 옮겼다 |
| "새 주제인데 이전 포스터랑 그대로 출력되어서 저장되는 경우" | 원인 둘. ① 도서관 밖 글 (위키 글 · 서가 카드) 은 그림이 전부 같은 들판 그림이었다 → 제목에서 나오는 무늬 한 장 (같은 제목 = 같은 무늬). 저장은 그대로라 이미 있는 포스터도 달라진다. ② 게임이 탭 둘에 열려 있으면 모델 산책이 한 번 더 들어와 같은 포스터가 또 저장됐다 → 지금의 저장에 자리를 적고, 들어온 산책 파일은 다시 재생하지 않는다 (이미 생긴 중복은 지우지 않았다). ③ 문어가 새 포스터를 들고 올 때, 새 그림이 구워지기 전까지 (실패하면 끝까지) 지난 산책의 포스터가 손에 보였다 → 새 포스터를 들 때 지난 그림부터 내려놓는다 |
| "마당에서 집으로 돌아갈 때 그냥 뒤돌기만 하면 계단 안 오르고 바로 집 내부로 … 계단을 오르내릴 수 있도록" | 마당 현관 마루와 계단 세 칸을 실제로 걷는다. 집에서 나오면 문 앞 마루에 서고, 계단을 한 칸 넘게 내려갔다가 다시 올라와 문 쪽으로 밀어야 들어간다 |

## 2-1. 끊김 줄이기 — 답 없이 먼저 한 것 (11-18)

- 방을 옮겨도 스틱 · 방향키가 이어진다: 쥔 채로 문 · 계단을 지나면 도착해서 그대로 걷는다 (예전엔 전환마다 손을 뗐다 다시 눌러야 했다).
- 문 · 계단을 톡해 혼자 걸어갈 때도 화면이 따라온다. 위층에서 내려오면 계단까지 보이게 한 번 따라간다.
- 마당에서는 캐릭터를 화면 가운데 가까이 두고 따라간다 (넓은 바깥의 첫 단계).
