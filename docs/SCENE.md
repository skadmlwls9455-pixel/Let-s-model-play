three.js r128 UMD(`vendor/three.min.js`, 없으면 cdnjs `onerror` 폴백) 로 만든 **절차적** 픽셀아트 다락방. 이미지·모델 파일 없음, 빌드 없음, `file://` 에서 동작.
`APP` 은 `SCENE = SCENE3D.supported() ? SCENE3D : SCENE2D` 하나만 본다(DESIGN §13.1). `?scene=2d` 로 폴백을 강제할 수 있다.

## 공간 · 카메라
- 방 5×5 m, `x,z ∈ [-2.5, 2.5]`, 벽 높이 3 m. 왼쪽 벽(x=-2.5)에 창, 뒷벽(z=-2.5)에 보드·선반·**문(오른쪽 끝, 어둠으로 뚫림)**.
  §13.2 의 앞쪽 문은 직교 시점에서 바닥을 가려 뒷벽으로 옮겼다.
- 직교 다이메트릭: 틸트 32°, 요 45°(드래그 ±25°, **9° 스냅**), 타깃 `(0, 0.75, -0.4)` 를 아트 픽셀 격자에 스냅.
- **픽셀 스냅 (룩 패스 5·8)**: `S.pw` = pixelWorldSize = 직교 프러스텀 폭 / 렌더 타깃 폭 = 1/N (**기본 p=2 줌 1 → 1/27 m = 3.7 cm**, p=3 → 1/18 = 5.56 cm, p=2 줌 ×2 → 1/54). 매 프레임 `snapScreen` 이 카메라 타깃을 카메라 우/상 축 기준 pw 격자에 올리고(패닝·추적 중 크리프 없음), 문어의 논리 위치 `oct.pos` 를 같은 격자에 스냅해 `octG.position` 에 쓴다(걷기 보간은 매끄럽게, 보이는 위치는 정수 픽셀; 폴짝·통통은 `snapUp` 으로 세로 정수 px). 정적 소품(등불·옹이·상자 더미·깔개·화분·이끼·양초·담요·보드·선반·커튼·포스터 칸·기념품)의 x·z 는 빌드 때 `snapPos` 로 **1/27 m**(`SNAP_N` = 18 × 3 / 기본 p 2) 격자에, 받침 치수는 픽셀 배수(p=3 폴백에선 반 픽셀 위상 — 폴백은 느린 기기 전용). `stats().pw`.
- 비율 **18 아트픽셀/m × 3/p**: 기본 **p=2 → 27/m** (1 px ≈ 3.7 cm; 룩 패스 8 — p=3 은 '거칠다'는 피드백), p=3 → 18/m (5.5 cm). 핀치/휠 줌은 `{1, 1.25, 1.5, 2}` 정수 단계.
- 렌더 타깃 = `⌊W/p⌋ × ⌊H/p⌋`, p = 설정 1~4(**기본 2**, `DEF_P`), `W/480` 이상. 360×326 폰 → **178×162** (p=3 → 118×108). `setPixelRatio(1)`, 캔버스 `image-rendering: pixelated`.
- **자동 픽셀 폴백 (룩 패스 8)**: init 뒤 첫 2 s 의 평균 ms/frame(메인 스레드, `frame()` 전체)이 **24 ms** 를 넘으면 이 세션만 p=3 (`st.look.pixelSize`/`autoPixel` 에만, 저장 X; 데브 슬라이더가 덮어쓴다). `stats().autoMs/autoPixel`, 콘솔 `[scene3d] auto pixel 3`. SwiftShader 메인 스레드 평균 10~14 ms 라 폴백 안 됨. 데브 슬라이더의 초기 표시값은 app.js 기본 3 이라 장면의 2 와 다를 수 있다(UI 단계에서 `stats().pixel` 을 읽게).

## 문어 (DESIGN §7.1 · `assets/ref/octopus-ref.png`)
- 로컬 단위 = 머리 반지름 r, 전체 **0.42 배(r = 0.42 m ≈ 방 폭 8%)**. 머리 = 구 r1 (중심 y 0.92, y 0.88 찌그림 → 바닥 틈 1.7 cm), 눈 흰자 2(r 0.24, 둘 다 정면 y 0.67) + 하이라이트 타원(좌상) + 흰 점 + `_` 입(폭 0.3 r × 0.07 r, 눈 아래 — p=2 에서 3×1 px) → **정점색 1메시**. 동공(r 0.13, 검정 + 흰 글린트 r 0.07 ≈ 3 cm = p=2 에서 1 px) 2, 눈꺼풀(몸색) 1, 홍조 원판 2(1메시), `^ ^` 토러스 반원 2(1메시), `— —` 선 2종·큰 흰자·`u` 입(표정, 아래). 다리 8 = 바깥·아래로 말리는 테이퍼 사슬 4마디(두께 0.38 r → 0.13 r, **길이 ≈ 0.9 r**, 밑면이 바닥 y=0 에 닿고 끝이 들림) + 관절 구 + **빨판 점 3**(끝마디 밑면 2 + 그 앞 마디 1, r 0.07~0.08 ≈ 3 cm → p=2 에서 1 px 연한 점), 각각 1메시. 토운 3단(gradientMap 92/170/255 → 문어 램프의 밝은/기본/−2칸)이 p=2 에서 밝은 윗면 · 중간 · 그늘진 오른쪽 아래로 읽히고, 몸 밑은 깊이 외곽선이 1px 어두운 테를 두른다(8-close). 흔들림·걷기는 다리를 위로만 든다. 히트 구 r 0.67 m(≈72 CSS px), 접지 데칼 1.34 m. 패스 기록: `docs/LOOK_LOG.md`.
- 재질 `MeshToonMaterial` + 3단 gradientMap, 정점색. 색은 설정(hue 슬라이더 + 프리셋 6, `settings.octColor`, 기본 `#e8463c`)에서 하이라이트(L+0.14, b+0.07)·빨판(L+0.26)·입(L−0.32) 파생. 색을 바꾸면 한 번 흔들고 팔레트의 문어 램프 5칸만 교체.
- 상태: idle(숨 4 s, 깜빡임 3~7 s, 다리 흔들) · anticipate(600 ms 눌림 + 반눈 `calm`) · walk/carry(1.2 m/s, 다리 번갈아, 통통, 진행 방향으로 회전, 도착 시 0.4 m 폴짝) · away(숨김) · carry(포스터 평면 들기) · hang(포스터가 보드 칸으로 500 ms 날아감) · happy(폴짝 2 + 꼭대기에서 다리 바깥 ×1.3) · sleep(`— —` 눈 + 6 % 납작 + hue ±18° 12 s) · stay · peek(좌우 흔들) · pet(`^ ^` + 홍조 원판 2 + 12 % 눌림 + ±4° 느린 흔들 + 색이 따뜻해짐. 2 s 뒤 APP 이 70% 기대기 / 30% 산책을 고른다 — 시무룩 없음). 눈·입·홍조는 **표정**이 그린다(아래 "초상·표정") — 상태는 기본 표정을 고를 뿐.
- 동공은 포인터를 따라간다(`lookAt` 으로 입력칸도). 가만히 있으면 카메라 쪽을 본다.
- 위치는 `oct.pos`(논리, 걷기 보간)이고 `octG.position` 은 매 프레임 그걸 카메라 우/상 축 픽셀 격자에 스냅한 값(룩 패스 5) — 걷는 동안 실루엣이 반 픽셀로 흐르지 않는다.

## 초상·표정 (룩 패스 8 · DESIGN §15.2 · `assets/ref/ui-ref-portrait-dialog.jpg`)
**표정** `setExpression(expr)` — 장면과 초상이 하나의 표정 상태를 공유한다. 상태(`setOctState`)는 기본 표정만 고른다(`happy→happy · pet→pet · sleep→sleep · anticipate→calm · 나머지→idle`), app.js 가 나중에 `setExpression` 으로 덮어쓴다(로그 대화창 행에서 같은 표정의 초상을 붙인다). `expression()` 로 현재 표정, `SCENE3D.EXPRESSIONS` / `scene.EXPRESSIONS` 로 목록. 모르는 이름은 `idle`.

|---|---|---|

## 앵커 (월드 m) · 상호작용
`door (1.95, 0, -2.05)` · `window (-1.8, 0, 0.4)` · `crate (1.25, 0, -1.0)` · `board (0.1, 0, -2.0)` · `blanket (-1.0, 0, 1.5)` · `center (0, 0, 0.2)`. `moveTo` 는 직선 보행 + 끝에 폴짝, `anchorReached` 콜백과 Promise 둘 다. 담요가 없으면 APP 이 `blanket→center` 로 바꾼다.
레이캐스트: 문어(탭 → 카메라 보고 `?` / 누르고 움직이거나 350 ms 유지 → `pet`) · 창 유리(탭 → `windowTap`: 창가로 걸어가 "비가 와/별이 보여") · 포스터 평면(`posterTap(id)` → 모달) · 기념품(`souvenirTap(sv)` → 그걸 가져온 날의 영수증) · 빈 곳 드래그 → 시점 ±25° · 휠/핀치 → 줌. 말풍선·이름표는 캔버스 밖 HTML(`#oct`)을 머리 위로 투영해 붙인다.

## 데모 패널 (`<details id=demo>` 안, localStorage `ppolppol_look`)
픽셀 1–4 · 디더 0–1(배율: 0.25 = 램프 0.4 칸 / 평지 0.05 칸, 룩 패스 5) · 외곽선 on/off · 시점 −25°~25° · **키 광 0.5–4 · 필 광 0–1**(낮 태양·헤미 세기, 키/필 비율 표시) · 팔레트 칩 4갈래(`settings.palette`, 방 보기 시트와 같은 줄) · 팔레트 스와치 줄(검증 팔레트는 8칸씩 + 문어 램프). 2D 모드에서는 "적용 안 돼" 안내만. `setLook` 은 추가로 `zoom`(0..3 단계)·`focus`(`'oct'` = 문어 중심) 를 받는다 — `tools/look-shots.js` 의 close 샷용(4번째 인자 yaw 로 요 9° 비교 샷 `<pass>-y9-*`). 테스트 훅 `window.__ppolLook = { hour, lantern, weather, octState, anchor, palette, key, fill }` 는 있을 때만 APP 이 읽는다(`palette`·`key`·`fill` 은 저장하지 않고 장면에만).

## 성능 · 접근성 · 폴백
- 기본 p=2 (178×162 타깃, 자동 폴백 p=3 — 위 "공간·카메라"), `antialias:false`, `setPixelRatio(1)`, 섀도맵 2048 PCF(태양만, `autoUpdate` 끄고 뷰티 패스에서만 갱신, 카메라는 방에 꼭 맞춤), 정적 방 = 2메시(`room` + 그림자 안 던지는 `roomHi`) + 보이지 않는 차폐 1메시, 가만히 있을 땐 30 fps, `document.hidden` 이면 rAF 정지, dt ≤ 0.1 s, `destroy()` 가 RT·기하·재질·텍스처 해제 + `forceContextLoss`.
- 모션 감소(설정 또는 OS): 숨쉬기·흔들림·비 정지, 먼지 숨김, 양초 불꽃 깜빡임 정지(중간값), `moveTo` 즉시, 디더 0, 색 전환은 유지.
- WebGL/THREE 없음 또는 `init` 예외 → `SCENE2D`(js/scene2d.js, 1차 구현의 인라인 SVG 레이어 + DOM 문어)가 같은 API(`setCarry`, `jumpTo`, `lookAt`, `setLook`, `palette`, `stats`, `refresh`, `setReducedMotion` 확장 포함)로 받는다. 두 장면 모두 호스트에 `data-items`, `data-posters` 를 쓴다(스모크가 본다).
- 증거: `node tools/evidence3d.js` → `tests/evidence/3d-{lantern0-night,lantern4-day,lantern8-night-clear,pet,away,dark-ui}.png` + 순도·드로우콜·에러 0 검사.
