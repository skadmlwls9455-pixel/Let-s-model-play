# 뽈뽈 문어 — 3D 장면 명세 (js/scene3d.js, 전역 `SCENE3D`)

three.js r128 UMD(`vendor/three.min.js`, 없으면 cdnjs `onerror` 폴백) 로 만든 **절차적** 픽셀아트 다락방. 이미지·모델 파일 없음, 빌드 없음, `file://` 에서 동작.
`APP` 은 `SCENE = SCENE3D.supported() ? SCENE3D : SCENE2D` 하나만 본다(DESIGN §13.1). `?scene=2d` 로 폴백을 강제할 수 있다.

## 공간 · 카메라
- 방 5×5 m, `x,z ∈ [-2.5, 2.5]`, 벽 높이 3 m. 왼쪽 벽(x=-2.5)에 창, 뒷벽(z=-2.5)에 보드·선반·**문(오른쪽 끝, 어둠으로 뚫림)**.
  §13.2 의 앞쪽 문은 직교 시점에서 바닥을 가려 뒷벽으로 옮겼다.
- 직교 다이메트릭: 틸트 32°, 요 45°(드래그 ±25°, **9° 스냅**), 타깃 `(0, 0.75, -0.4)` 를 아트 픽셀 격자에 스냅.
- 고정 비율 **18 아트픽셀/m** (p=3 폰에서 1 px ≈ 5.5 cm). 핀치/휠 줌은 `{1, 1.25, 1.5, 2}` 정수 단계.
- 렌더 타깃 = `⌊W/p⌋ × ⌊H/p⌋`, p = 설정 1~4(기본 3), `W/480` 이상. 360×326 폰 → 120×108. `setPixelRatio(1)`, 캔버스 `image-rendering: pixelated`.

## 문어 (DESIGN §7.1 · `assets/ref/octopus-ref.png`)
- 로컬 단위 = 머리 반지름 r, 전체 **0.42 배(r = 0.42 m ≈ 방 폭 8%)**. 머리 = 구 r1 (중심 y 0.92, y 0.88 찌그림 → 바닥 틈 1.7 cm), 눈 흰자 2(r 0.24, 둘 다 정면 y 0.67) + 하이라이트 타원(좌상) + 흰 점 + `_` 입(폭 0.3 r, 눈 아래) → **정점색 1메시**. 동공(r 0.13, 검정 + 흰 글린트) 2, 눈꺼풀(몸색) 1, 홍조 원판 2(1메시), `^ ^` 토러스 반원 2(1메시). 다리 8 = 바깥·아래로 말리는 테이퍼 사슬 4마디(두께 0.38 r → 0.13 r, **길이 ≈ 0.9 r**, 밑면이 바닥 y=0 에 닿고 끝이 들림) + 관절 구 + 빨판 점 2(끝마디 밑면, 연한 색), 각각 1메시. 흔들림·걷기는 다리를 위로만 든다. 히트 구 r 0.67 m(≈72 CSS px), 접지 데칼 1.34 m. 패스 기록: `docs/LOOK_LOG.md`.
- 재질 `MeshToonMaterial` + 3단 gradientMap, 정점색. 색은 설정(hue 슬라이더 + 프리셋 6, `settings.octColor`, 기본 `#e8463c`)에서 하이라이트(L+0.14, b+0.07)·빨판(L+0.26)·입(L−0.32) 파생. 색을 바꾸면 한 번 흔들고 팔레트의 문어 램프 5칸만 교체.
- 상태: idle(숨 4 s, 깜빡임 3~7 s, 다리 흔들) · anticipate(600 ms 눌림) · walk/carry(1.2 m/s, 다리 번갈아, 통통, 진행 방향으로 회전, 도착 시 0.4 m 폴짝) · away(숨김) · carry(포스터 평면 들기) · hang(포스터가 보드 칸으로 500 ms 날아감) · happy(폴짝 2) · sleep(눈 감음, hue ±18° 12 s) · stay · peek(좌우 흔들) · pet(`^ ^` + 홍조 + 눌림 + 색이 따뜻해짐. 2 s 뒤 APP 이 70% 기대기 / 30% 산책을 고른다 — 시무룩 없음).
- 동공은 포인터를 따라간다(`lookAt` 으로 입력칸도). 가만히 있으면 카메라 쪽을 본다.

## 후처리 (풀스크린 삼각형 1패스, EffectComposer 없음)
1. 장면 → 저해상 RT(sRGB 저장, 24-bit 깊이 텍스처). 2. 같은 장면을 `MeshNormalMaterial` 오버라이드로 노멀 RT.
3. 셰이더: sRGB→선형→OKLab → 그레이드(대비 1.03, 채도 1.07) → **깊이 외곽선**(이웃이 6 cm 이상 멀면, 2단, L×0.66) → **노멀 하이라이트**(가까운 면의 노멀 꺾임, L×1.06, 깊이선이 없는 곳만) → **게이트 Bayer 4×4**(이웃 루마 차 `smoothstep(.004,.055)`, 진폭 = 슬라이더 × 2 × `PAL.step` → 기본 0.25 에서 ≈ ½ 팔레트 칸: 즉흥 0.024 · Apollo 0.029 · Endesga 0.032 · Resurrect 0.029; 카메라가 움직이면 0, 모션 감소면 0) → **허공 비네트**(깊이 = far 인 배경 픽셀만, `uVig` = 깊이 텍스처 있을 때: L −0.1·smoothstep(0.3, 0.9, 중심 거리) + 정적 Bayer 0.06 → 모서리가 밤검정/남색으로 디더됨) → 팔레트 스냅 → Nearest 업스케일.
4. 순도: `tools/evidence3d.js` 가 PNG 고유 색을 센다(≤ 팔레트 크기 + 6; 낮 장면 Apollo 47).

## 조명 = 실제 시계 (1분마다 읽음, 상태가 바뀌면 60 s 이징 · 룩 패스 4 "조명 비율")

## 앵커 (월드 m) · 상호작용
`door (1.95, 0, -2.05)` · `window (-1.8, 0, 0.4)` · `crate (1.25, 0, -1.0)` · `board (0.1, 0, -2.0)` · `blanket (-1.0, 0, 1.5)` · `center (0, 0, 0.2)`. `moveTo` 는 직선 보행 + 끝에 폴짝, `anchorReached` 콜백과 Promise 둘 다. 담요가 없으면 APP 이 `blanket→center` 로 바꾼다.
레이캐스트: 문어(탭 → 카메라 보고 `?` / 누르고 움직이거나 350 ms 유지 → `pet`) · 창 유리(탭 → `windowTap`: 창가로 걸어가 "비가 와/별이 보여") · 포스터 평면(`posterTap(id)` → 모달) · 기념품(`souvenirTap(sv)` → 그걸 가져온 날의 영수증) · 빈 곳 드래그 → 시점 ±25° · 휠/핀치 → 줌. 말풍선·이름표는 캔버스 밖 HTML(`#oct`)을 머리 위로 투영해 붙인다.

## 데모 패널 (`<details id=demo>` 안, localStorage `ppolppol_look`)

## 성능 · 접근성 · 폴백
- `antialias:false`, `setPixelRatio(1)`, 섀도맵 2048 PCF(태양만, `autoUpdate` 끄고 뷰티 패스에서만 갱신, 카메라는 방에 꼭 맞춤), 정적 방 = 2메시(`room` + 그림자 안 던지는 `roomHi`) + 보이지 않는 차폐 1메시, 가만히 있을 땐 30 fps, `document.hidden` 이면 rAF 정지, dt ≤ 0.1 s, `destroy()` 가 RT·기하·재질·텍스처 해제 + `forceContextLoss`.
- 모션 감소(설정 또는 OS): 숨쉬기·흔들림·비 정지, 먼지 숨김, `moveTo` 즉시, 디더 0, 색 전환은 유지.
- WebGL/THREE 없음 또는 `init` 예외 → `SCENE2D`(js/scene2d.js, 1차 구현의 인라인 SVG 레이어 + DOM 문어)가 같은 API(`setCarry`, `jumpTo`, `lookAt`, `setLook`, `palette`, `stats`, `refresh`, `setReducedMotion` 확장 포함)로 받는다. 두 장면 모두 호스트에 `data-items`, `data-posters` 를 쓴다(스모크가 본다).
- 증거: `node tools/evidence3d.js` → `tests/evidence/3d-{lantern0-night,lantern4-day,lantern8-night-clear,pet,away,dark-ui}.png` + 순도·드로우콜·에러 0 검사.
