| `finishIntro` | 배경을 원래 값으로 되돌리고 띠·읽은 색을 비운다 |

`stepIntro` · 공개 API 표 · `probeSky` 는 그대로다. 새 API 는 없다 (`intro()` 옵션 `top` 과 Promise 의 `skyLive` 표시만 늘었다).

### 패치 없이 (지금 scene3d) 돌면

`intro.js` 는 `top` 을 넘기지만 옛 장면은 모른 체한다. `skyLive` 가 없으니 예전처럼 처음 몇 프레임만 `skyHex` 를 읽는다 (매 프레임 `readPixels` 를 하지 않는다). 그래서 옛 곡선(easeOutCubic) 그대로 3.0 s 동안 2.6 화면 높이에서 내려오고, 옛 구름이 그 높이에 퍼진다. 타이틀은 진행도 0.92 에 뜬다 (옛 곡선은 0.86 에 착지하므로 착지 뒤다). 깨지는 것은 없다 (§5).

## 4. 잰 값 (SwiftShader, 360×740 · 412×915 · 1280×800)

**다 덮인 프레임** (60 fps 스텝, 장면에 하늘색 픽셀이 0.2 % 미만인 프레임 수):

| 화면 | 낮 가랑비 | 노을 맑음 | 낮 맑음 | 낮 비 |
|---|---|---|---|---|
| 360×740 | 4 | 3 | — | — |
| 412×915 | — | — | 3 | — |
| 1280×800 | — | — | — | 3 |

그 앞뒤로 2~8 프레임은 몽우리 사이로만 하늘이 조금 보인다 (5 % 미만). 밤 눈은 1 로 재지는데, 밤 눈구름 램프의 가장 어두운 칸이 하늘색 `#172038` 과 같아 잰 값이 적게 나온 것이다 (눈으로 보면 다른 날씨와 같다).

**드로우콜** (`stats().calls`, 하늘 단계 동안 1/40 s 스텝, 다락 평소 = base):

| 시각 · 날씨 | base | 전 최대 / 평균 | 후 최대 / 평균 |
|---|---|---|---|
| 낮 맑음 | 71 | 72 / 59.7 | 72 / 32.7 |
| 낮 가랑비 | 77 | 81 / 68.9 | 80 / 41.2 |
| 밤 비 | 77 | 82 / 69.9 | 81 / 42.7 |
| 밤 눈 | 73 | 77 / 64.9 | 76 / 37.7 |
| 노을 맑음 | 71 | 73 / 60.8 | 73 / 33.8 |

최대는 같거나 1 적다 (착지 직전, 방 + 남은 하늘). 평균은 방이 화면 밖에 있는 시간이 길어져 절반쯤이다.

**연출 시작 비용** (`intro()` 한 번, 하늘 만들기, 중앙값): 전 13 ms → 후 23 ms. 구름 그림이 커지고 뚫는 구름이 늘었다. `clouds.js` 를 `ImageData` 한 번 쓰기 + 먼 덩어리 건너뛰기로 고쳐서 53 ms 에서 줄였다. 화면이 아직 덮개 색일 때 한 번뿐이다. 매 프레임 비용은 늘지 않았다.

**시간** (가짜 시계로 잰 실제 속도, `?intro=1`): 타이틀이 뜨는 때 **전 1.12 s → 후 2.71 s**. 하늘 단계는 3.0 s, '딱' 계단 0.2 s, 반짝 0.4 s, 안내 글은 2.16 s 뒤 멈춘다.

## 7. 이 카드 밖 (제안만, 고치지 않았다)
