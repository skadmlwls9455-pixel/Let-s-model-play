# 세계관 (11-21 · 7차 N 갈래)

## 이야기

이 마을의 문어들은 사람들을 아주 열심히 도왔다. 그러다 하나둘 잠들었다. 사람들은 문어 없이 어렵게 지내다 마을을 떠났다. 플레이어는 어쩌다 이곳에 자리 잡은 사람이다. 도시에서, 자기만 빼고 모두 똑똑한 문어인 회사에 다니다 지쳐서 왔다. 오래 자다 먼저 깬 문어 몇이 가게 셋을 다시 열었고, 나머지는 아직 잔다. 다락의 문어도 마을에서 깨어 있는 문어 가운데 하나다.

게임은 이 이야기를 설명하지 않는다. 처음 한 번의 세 줄과 마을에 남은 흔적으로만 보여 준다.

## 정직

- 문어들이 왜 잠들었는지를 마음 낱말로 말하지 않는다 ("아주 열심히 일했다 → 잠들었다" 까지만).
- 다락 문어에 대해 게임이 말하는 것은 사실 하나뿐이다: 깨어 있었다. 무엇을 느끼는지, 왜 깼는지는 말하지 않는다.
- 마을 문어의 말은 모두 대본이고 이름표에 `대본` 이 붙는다 (docs/NPC.md).
- "지쳐서" 는 플레이어 자신의 사정으로만 쓴다.

## 흔적이 있는 곳

| 흔적 | 어디 | 무엇 |
|---|---|---|
| 처음 세 줄 | 첫 실행, 타이틀을 누른 뒤 · 이름 짓기 앞 (`#story-intro`) | 아래 세 줄. 한 줄씩, 누르면 다음. 건너뛰기 단추 · Esc. 한 번만 (`S.user.story.intro` 에 날짜) |
| 게시판 | 광장 `#btn-plaza-board` → `#story-sheet` | 낡은 쪽지 넷 (그림 + 한 줄), 이야기 차례대로. 본 날짜는 `S.user.story.notices` |
| 자는 문어 넷 | 마을 문 옆 긴 의자 · 빈집 현관 · 바닷가 바위 · 부두 발치 (계약 C6) | 누르면 "자고 있어." 한 줄뿐 |
| 가게 문어의 한마디 | 가게 문어를 누르면 (`talk`) | 몇 갈래가 옛 마을 · 누가 먼저 잠들었는지 · 지금 하는 일을 말한다 (docs/NPC.md) |
| 빈집 · 닫힌 덧문 | 마을 길 왼쪽 (V 갈래가 그린다) | 글 없음 |

## 처음 세 줄

1. 도시의 회사에 다녔어. 나만 빼고 다 똑똑한 문어였고, 다들 아주 열심히 일했어.
2. 나는 지쳐서, 조용한 바닷가 마을로 왔어.
3. 다락에 올라가 보니, 문어 하나가 깨어 있었어.

단추: "건너뛰기". 자동화 브라우저에서는 `?story=1` 을 붙였을 때만 보인다 (입장 연출과 같은 규칙).

## 게시판 쪽지

1. 일손 구해요. 문어라면 누구든. (그림: 상자를 쌓는 문어)
2. 올해 풍어. 문어들 덕분입니다. (그림: 고기를 실은 배와 문어)
3. 문어들이 자고 있어요. 부두 근처에선 조용히. (그림: 부두 위에서 자는 문어와 달)
4. 우리는 떠납니다. 오는 분, 자는 문어들을 부탁해요. (그림: 덧문 닫힌 집과 떠나는 배)

쪽지는 마을 사람들이 쓴 글이라 높임말이다. 시트 제목은 "게시판", 단추는 "닫기".

## 저장

`S.user.story = { intro: 'YYYY-MM-DD' | null, notices: { help | catch | quiet | leave: 'YYYY-MM-DD' } }`. 없으면 빈 값으로 읽고, 모르는 값은 그대로 둔다 (`NPC.normalize`). 내보내기 · 불러오기는 손대지 않는다.
