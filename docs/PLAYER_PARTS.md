# 내 캐릭터 파츠 카탈로그 (PLAYER_PARTS · v1.1 설계 · 11-08 비평 반영판)

내 캐릭터(`js/scene3d.js` '내 캐릭터' 블록, v0 는 커밋 15b0a33)에 **머리 모양 · 머리 색 · 눈 모양 · 눈 색 · 옷 · 신발 · 머리 악세사리**를 붙이기 위한 치수표. 코드가 그대로 옮길 수 있게 전부 숫자(m, 발바닥 y 0, 캐릭터 그룹 `plBody` 좌표)로 적는다. 만드는 길은 문어와 같다: 원시 도형 + 정점색(`mergeParts`) + 툰 3단(`toonP`) + 같은 후처리(팔레트 스냅 · 깊이 외곽선 · 디더), 새 재질·셰이더 프로그램 없음. 레퍼런스(파넬라 '나나곰쿠키' · 동물의 숲 주민)는 실루엣 종류·비율·색 분위기만 참고했고 모양은 베끼지 않았다(이름도 새로 지음).

v1.1 은 비평 두 벌(11-08)을 받아 고친 판이다. 바뀐 핵심: **살결·금발 등 색 전부를 '실광 모델'(필 + 헤미, 해는 차폐 그림자)로 다시 계산**, 흰자와 살결을 다른 칸에, 눈썹–살결–눈 세 띠를 각각 ≥ 1 px 로, 긴 머리·웨이브 뒷덩어리를 닫힌 입체로, 포니테일 꼬리를 옆으로, 안경 구멍을 흰자보다 크게, 깜빡임을 어두운 선으로, 걷기 수치 되돌림. 받아들이지 않은 것은 맨 끝 §6 '비평에 답함' 표.

표기: `Sphere(r, ws, hs, phiStart, phiLength, thetaStart, thetaLength)` = `THREE.SphereGeometry` (각도는 **도(°)로 적었고 코드에선 `deg * DEG`**, theta 는 rad 그대로) · `Cyl(rTop, rBottom, h, seg[, open, thetaStart, thetaLength])` = `CylinderGeometry` · `box(w, h, d)` · `Torus(R, tube, rs, ts, arc)` · `Cone(r, h, seg)` · `Circle(r, seg)` · `M(x, y, z, rx, ry, rz, sx, sy, sz)` (T·R·S — 회전은 지오메트리 원점 기준) · `plTaper(list, a, b, r0, r1, hex, sides)`(a→b 테이퍼 원기둥, r0 가 a 쪽). 색은 `PAL.<램프>[i]` · `FIXED.ink/white` · `mixHex(a, b, k)` · hex. 각도 규약(three.js r128, node 로 확인): Sphere 의 **phi 0° = −x · 90° = +z(얼굴, 카메라 쪽) · 180° = +x · 270° = −z(뒤통수)**, theta 0 = 꼭대기 · π = 바닥. Cylinder 의 thetaStart **90°, length 180° = 뒤 절반(−z)**. Torus arc π = 위로 볼록(∩). 픽셀 환산: p=2 기본 줌 27 px/m → **1 px ≈ 3.7 cm**, 6 cm 규칙 = 1.6 px(그보다 작은 건 '1 px 점·선 의도' 로만, 표시해 둔다).

**두 가지 사실(설계 전제, 코드에서 확인)**
1. **쉬는 자리의 캐릭터 색은 해가 아니라 필·헤미가 정한다.** 다락·놀이방은 보이지 않는 지붕·벽 차폐가 해 그림자를 던져 해(#dfe9ff ×3.0)는 창 모양 빛 조각 안에만 든다. 캐릭터가 서 있는 곳의 빛 = 필 방향광(`#a9cbe2` ×1.3, 방향 (6, 2.5, 8) = 카메라 쪽 낮은 각, 툰 3단 {255, 170, 92}/255) + 헤미(sky `#d6ecf6` / gnd `#4a4030` ×0.36). 필이 **푸른빛**이라 따뜻한 알베도는 채도가 빠지고(#ffd27a 금발 → 올리브 #d0da91, 살결 → 흰 #ebede9), 푸른 알베도는 더 파래진다(#b9cfdd 은빛 → 하늘 #73bed3). 이 문서의 색 스냅은 전부 이 '실광 모델'(`scratchpad/rev/fillmodel.js`, 레포 밖: 알베도(선형) × (필 × 1.3 × 단 + 헤미) → 클램프 → grade(대비 1.03 · 채도 1.07) → apollo 46색 최근접, `uW` (1, 1.3, 1.3), 근소 동률 → 밝은 쪽)로 계산했다. **보정**: 커밋된 증거 `tests/evidence/player/pl-attic-close.png`(192×192)를 디코드하면 금발 머리칼 앞·윗면 #d0da91 7712 px(#e8c170 는 테두리 256 px, #de9e41·#e7d5b3 는 머리칼에 없음) · 살결 앞면 #ebede9 3424 px · 턱 아래 #e7d5b3 → #c7cfcc · 눈 #253a5e · 원피스 #253a5e/#172038 · 깃 #ebede9 — 모델은 금발 앞면 #d0da91 · 윗면 #e8c170 · 살결 #ebede9 · 깃 #ebede9 · 원피스 #253a5e/#172038 로 맞고 눈만 한 칸 어둡게(#202e37) 나온다 → **오차 ±1 칸**, 확정은 §5 색 집계로. 창 빛 조각을 지날 때(걷기 스트립 일부 칸)는 밝은 색이 전부 #ebede9 로 뜬다 — v0 와 같고 바꾸지 않는다.
2. **부품 사이엔 깊이 외곽선이 안 생긴다.** 후처리 잉크선은 `dei = floor(smoothstep(0.06, 0.5, dd) × 2) / 2` — 이웃 한 칸이 **0.28 m 이상** 멀어야 반 세기 선이 난다(0.06 은 smoothstep 의 시작일 뿐 0.5 미만은 floor 로 0). 머리칼–이마 0.045 · 흰자–살결 0.03 · 코 0.04 같은 돌출은 선을 못 만든다. 그러므로 **얼굴·옷 부품의 경계는 전부 '다른 apollo 칸'으로만 생긴다** — 아래 모든 색은 '이웃 부품과 다른 칸에 앉는가'로 골랐다. 잉크선은 실루엣(바닥·벽과 ≥ 0.3 m 차)에만 기대한다.

### 0.2 "머리가 저게 뭐야" → 머리카락 다듬기
v0 머리칼(큰 구 덮개 + 가운데 갈래 혹 구)은 혹처럼 보였다. v1 원칙:
1. **모든 머리칼 조각은 같은 반지름 r_h 의 얇은 구 껍질 조각**(`Sphere(r_h, ws, hs, phiStart, phiLength, thetaStart, thetaLength)`)으로 깎아 앞머리·옆머리·뒷머리를 따로 만든다. 껍질 중심은 머리 구 중심보다 **+0.03 위 · −0.03 뒤 = (0, 0.90, −0.03)**, **r_h = 0.38, 여섯 스타일 모두 같다**(웨이브도 — v1.0 의 0.39 는 악세사리 치수(r_h 0.38 기준)와 어긋났다). 두께: 옆 0.03 · 정수리 0.067 · 이마 앞 0.045(앞머리 끝 z 0.301 vs 이마 0.256).
2. **조각끼리 반지름을 다르게 하지 않는다 · 같은 반지름의 조각이 겹치지 않게**(z-fight) phi/theta 창을 **서로 보완**하게 자른다: 윗덮개의 비운 앞 창 = 앞머리 창, 윗덮개 아래 theta = 옆·뒷머리 시작 theta.
3. **두개골 위에 구를 얹지 않는다**(혹 금지). 구는 매듭 · 다발 끝 · 웨이브 끝단에만.
4. 앞머리는 이마를 덮는 **매끈한 가르마/일자/옆으로 넘김** — 두 조각의 theta 길이를 다르게 해 아래 끝 높이를 비대칭(**1.092 / 1.118**)으로 두면 '가르마' 로 읽힌다. 아래 끝 y = 0.90 + 0.38·cos(thetaEnd). **앞머리 끝은 어떤 스타일이든 ≥ 1.09**(눈썹 윗선 1.053 + 살결 1 px).
5. 옆머리가 얼굴 양옆을 감싸고(눈 바깥 끝 ±0.219 과 옆머리 안쪽 끝 ±0.267 사이 살결 1.3 px), 뒷머리 길이가 스타일을 정한다: 짧은머리 = 귀(y 0.78) · 단발 = 턱 위(0.585) · 긴 머리 = 엉덩이(0.24).
6. 양갈래·포니테일은 `plTaper` 체인 + 끝 구. **포니테일 꼬리는 한쪽(+x)으로 늘어뜨려 정면에서도 보이게**(§2.1).

## §3 API 계약 (CONTEXT.md 그대로 — 바꾸지 않는다) · 기본값 · 저장 · UI

- **`SCENE3D.PLAYER_PARTS`** (정적 export, 2D 에서도 `SCENE3D` 가 있으면 읽는다):
  `{ hair: [{id, name}], hairColor: [{id, name, hex}], eyes: [{id, name}], eyeColor: [{id, name, hex}], outfit: [{id, name}], shoes: [{id, name}], acc: [{id, name}] }` — 위 표 순서대로, `acc[0] = { id: 'none', name: '없음' }`. `name` 은 칩에 들어가는 한국어(위 표의 name): hair `단발 짧은머리 긴생머리 양갈래 포니테일 웨이브` · hairColor `금발 밤갈색 먹남색 은빛 분홍 연두` · eyes `동그란 반짝 졸린 아몬드 웃는 점`(§0.4) · eyeColor `흑갈색 호두색 바다색 잎새색 꿀색 제비꽃` · outfit `원피스 니트 후드 멜빵 비옷` · shoes `단화 부츠 운동화 로퍼` · acc `없음 리본 베레모 동글안경 고양이귀 밀짚모자`. hairColor 의 `hex` 는 §2.2 의 알베도 hex(`PAL.amber[3]` 는 빌드 때 hex 로 풀어 넣는다).
- **`SCENE3D.PLAYER_DEFAULT`** = v0 모습에 해당하는 id:
  `{ hair: 'bob', hairColor: 'blonde', eyes: 'round', eyeColor: 'dark', outfit: 'dress', shoes: 'flat', acc: 'ribbon' }` (단발 · 금발 · 동그란 눈 · 어두운 눈 · 남색 원피스 · 짧은 신발 · 머리 리본).
- **`SCENE.init(container, opts)`** 가 `opts.player`(cfg) 를 받는다. **`scene.setPlayer(cfg)`**: 모르는 범주·id 는 기본값으로 채우고, 위치·걷기 상태(`PL`)는 그대로 두고 7 메시의 지오메트리만 다시 만든다(옛 지오메트리 `dispose`, `keep` 목록에서도 교체). 눈 메시의 흰자(tag 1)·글린트(tag 2) 태그와 현재 눈썹 색(`browHex`)을 `PL` 에 두어 깜빡임 recolor 가 쓴다. **`scene.player()`** 결과에 `look: cfg`(정규화된 것) 가 들어간다. 2D(`js/scene2d.js`): `setPlayer` 는 아무것도 안 하고 `player()` 는 `{ place: 'attic', look: cfg }`.

- **설정 저장 스키마**(`js/app.js` 기본값, 약 187행): `settings: { motion, thumbs, lastSeen, octColor, flipped, palette, pixelFont, albumSeen, player: SCENE3D.PLAYER_DEFAULT }` — 복원(`Object.assign(d.settings, s.settings)`) 뒤 `player` 가 없거나 키가 빠졌거나 id 가 목록에 없으면 그 칸만 기본값으로(`normalizePlayer(cfg)` 를 app 과 scene 이 같은 규칙으로). 내보내기/불러오기는 settings 에 들어 있으니 그대로. `SCENE.init(..., { player: S.settings.player })`.
- **설정 시트 UI**(`renderSettings`, '문어 색' 섹션 바로 아래 `h3 '내 모습'`): 범주마다 한 줄(라벨 + 칩들), 줄 순서 **머리 · 머리 색 · 눈 · 눈 색 · 옷 · 신발 · 악세사리**. 색(머리 색 · 눈 색)은 `.preset` 동그라미(36 px, `data-hex`, `title`/`aria-label` = name) · 나머지는 `.fchip` 글자 칩, `aria-pressed`, 누르면 `S.settings.player[범주] = id` → `save()` → `scene.setPlayer(cfg)` → 미리보기 갱신. 눈 색 줄 아래 작은 글 한 줄: 눈 모양이 `smile`/`dot` 이면 "이 눈 모양은 눈 색이 안 보여요", 아니면 "눈 색은 확대해서 보면 잘 보여요"(칩은 그대로 둔다). **미리보기**: `playerPortrait` 가 있을 때만 캔버스 1개(`image-rendering: pixelated`, 64 → **96 px** 표시), 섹션 제목 오른쪽. 글·칩에 이모지·기호 없음. 탭 영역 44 px 이상(`.fchip`/`.preset` 의 `::before inset:-6px` 수법 그대로).

## §4 드로우콜 · 메시 예산

- 메시 수: **7 그대로**(plHead · plEyes · plTorso · plArmL · plArmR · plLegL · plLegR) + 데칼 1. 악세사리·머리칼·코·홍조는 전부 plHead 에 합친다(눈썹·입은 §0.4 로 없음). 긴 머리 커튼·웨이브 덩어리·꼬리·다발도 plHead(머리와 같이 bob, 따로 흔들지 않음). **깜빡임의 '감은 눈 선' 은 메시 추가 없이 눈 메시 정점색 recolor**(태그 1·2, 깜빡임 시작·끝에 한 번씩 색 속성 업로드).

- 2D 폴백: 캐릭터 없음(계약대로 `setPlayer` 무동작).
