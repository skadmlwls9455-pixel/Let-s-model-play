# 내 캐릭터 파츠 카탈로그 (PLAYER_PARTS · v1 설계 · 11-08)

내 캐릭터(`js/scene3d.js` '내 캐릭터' 블록, v0 는 커밋 15b0a33)에 **머리 모양 · 머리 색 · 눈 모양 · 눈 색 · 옷 · 신발 · 머리 악세사리**를 붙이기 위한 치수표. 코드가 그대로 옮길 수 있게 전부 숫자(m, 발바닥 y 0, 캐릭터 그룹 `plBody` 좌표)로 적는다. 만드는 길은 문어와 같다: 원시 도형 + 정점색(`mergeParts`) + 툰 3단(`toonP`) + 같은 후처리(팔레트 스냅 · 깊이 외곽선 · 디더), 새 재질·셰이더 프로그램 없음. 레퍼런스(파넬라 '나나곰쿠키' · 동물의 숲 주민)는 실루엣 종류·비율·색 분위기만 참고했고 모양은 베끼지 않았다(이름도 새로 지음).

표기: `Sphere(r, ws, hs, phiStart, phiLength, thetaStart, thetaLength)` = `THREE.SphereGeometry` (각도는 **도(°)로 적었고 코드에선 `deg * DEG`**, theta 는 rad 그대로) · `Cyl(rTop, rBottom, h, seg[, open, thetaStart, thetaLength])` = `CylinderGeometry` · `box(w, h, d)` · `Torus(R, tube, rs, ts, arc)` · `Cone(r, h, seg)` · `Circle(r, seg)` · `M(x, y, z, rx, ry, rz, sx, sy, sz)` · `plTaper(list, a, b, r0, r1, hex, sides)`(a→b 테이퍼 원기둥, r0 가 a 쪽). 색은 `PAL.<램프>[i]` · `FIXED.ink/white` · `mixHex(a, b, k)` · hex. 각도 규약(three.js r128, node 로 확인): Sphere 의 **phi 0° = −x · 90° = +z(얼굴, 카메라 쪽) · 180° = +x · 270° = −z(뒤통수)**, theta 0 = 꼭대기 · π = 바닥. Cylinder 의 thetaStart **90°, length 180° = 뒤 절반(−z)**. Torus arc π = 위로 볼록(∩). 픽셀 환산: p=2 기본 줌 27 px/m → **1 px ≈ 3.7 cm**, 6 cm 규칙 = 1.6 px(그보다 작은 건 '1 px 점·선 의도' 로만, 표시해 둔다).

### 0.2 "머리가 저게 뭐야" → 머리카락 다듬기
v0 머리칼(큰 구 덮개 + 가운데 갈래 혹 구)은 혹처럼 보였다. v1 원칙:
1. **모든 머리칼 조각은 같은 반지름 r_h 의 얇은 구 껍질 조각**(`Sphere(r_h, ws, hs, phiStart, phiLength, thetaStart, thetaLength)`)으로 깎아 앞머리·옆머리·뒷머리를 따로 만든다. 껍질 중심은 머리 구 중심보다 **+0.03 위 · −0.03 뒤 = (0, 0.90, −0.03)**(v0 와 같은 오프셋), **r_h = 1.086 r = 0.38**(두께 옆 0.03 · 정수리 0.067 · 이마 앞 0.02~0.03 m — 두께 0.03~0.05 **m** 의 모자 꼴). 웨이브만 r_h 0.39.
2. **조각끼리 반지름을 다르게 하지 않는다**(깊이 외곽선 패스가 내부 선을 그린다) · **같은 반지름의 조각이 겹치지 않게**(z-fight) phi/theta 창을 **서로 보완**하게 자른다: 윗덮개의 비운 앞 창 = 앞머리 창, 윗덮개 아래 theta = 옆·뒷머리 시작 theta.
3. **두개골 위에 구를 얹지 않는다**(혹 금지). 구는 매듭 · 다발 끝 · 웨이브 끝단에만.
4. 앞머리는 이마를 덮는 **매끈한 가르마/일자/옆으로 넘김** — 두 조각의 theta 길이를 다르게 해 아래 끝 높이를 비대칭(1.01 / 1.04)으로 두면 '가르마' 로 읽힌다. 아래 끝 y = 0.90 + r_h·cos(thetaEnd).
5. 옆머리가 얼굴 양옆을 감싸고(눈 바깥 끝 ±0.22 과 옆머리 안쪽 끝 ±0.27 사이 살결 1 px), 뒷머리 길이가 스타일을 정한다: 짧은머리 = 귀(y 0.78) · 단발 = 턱 위(0.59) · 긴 머리 = 엉덩이(0.24).
6. 양갈래·포니테일은 `plTaper` 체인 + 끝 구. 1× 와 2× 둘 다 **스크린샷을 Read 로 직접 보고** 못생겼으면 고친다(웨이브가 가장 위험 — §2.1).

기준 높이(머리 r 0.35 · 중심 0.87): 머리 구 꼭대기 1.213 · 바닥 0.527(턱) · 머리칼 껍질 꼭대기 **1.28**(실루엣 키) · 눈썹 0.97 · 눈 0.86 · 귀 높이 0.78.

## §3 API 계약 (CONTEXT.md 그대로 — 바꾸지 않는다) · 기본값 · 저장 · UI

- **`SCENE3D.PLAYER_PARTS`** (정적 export, 2D 에서도 `SCENE3D` 가 있으면 읽는다):
  `{ hair: [{id, name}], hairColor: [{id, name, hex}], eyes: [{id, name}], eyeColor: [{id, name, hex}], outfit: [{id, name}], shoes: [{id, name}], acc: [{id, name}] }` — 위 표 순서대로, `acc[0] = { id: 'none', name: '없음' }`. `name` 은 칩에 들어가는 한국어 4자 안팎(위 표의 name).
- **`SCENE3D.PLAYER_DEFAULT`** = v0 모습에 해당하는 id:
  `{ hair: 'bob', hairColor: 'blonde', eyes: 'round', eyeColor: 'dark', outfit: 'dress', shoes: 'flat', acc: 'ribbon' }` (단발 · 금발 · 동그란 눈 · 어두운 눈 · 남색 원피스 · 짧은 신발 · 머리 리본).
- **`SCENE.init(container, opts)`** 가 `opts.player`(cfg) 를 받는다. **`scene.setPlayer(cfg)`**: 모르는 범주·id 는 기본값으로 채우고, 위치·걷기 상태(`PL`)는 그대로 두고 7 메시의 지오메트리만 다시 만든다(옛 지오메트리 `dispose`, `keep` 목록에서도 교체). **`scene.player()`** 결과에 `look: cfg`(정규화된 것) 가 들어간다. 2D(`js/scene2d.js`): `setPlayer` 는 아무것도 안 하고 `player()` 는 `{ place: 'attic', look: cfg }`.
- **`scene.playerPortrait(opts) → 64×64 canvas`** (있으면 좋음): 문어 `portrait()` 과 같은 길 — 레이어 2 전용 3점 조명(`pCam` · `rtP/rtPN/rtPO` · `postP` 재사용, 같은 후처리) · 캐시 키 = `JSON.stringify(cfg) + '|' + PAL.source + '|' + bg`. 프레이밍: 타깃 = 머리 중심 (0, 0.87 − 0.05, 0) 캐릭터 그룹 좌표 · 위에서 15° · 반폭 1.3 × 0.35 = 0.455 m(머리 19 px → 초상 64 px 안에 머리 지름 ≈ 49 px, 깃·어깨 윗선이 아래에 들어온다) · 정지 자세(팔·다리 회전 0, `plBody` 스케일 1, 깜빡임 없음) · 카메라 쪽을 본다. 캐릭터 그룹이 숨은 장소(바깥 보는 중)여도 문어 초상처럼 잠깐 보이게 해 찍는다. `setPlayer` 가 캐시를 비운다(`portraitFlush` 와 같은 꼴). **위험하면 빼고 보고한다**(GL 읽기 실패·컨텍스트 잃음 땐 빈 캔버스, 캐시하지 않음).
- **설정 저장 스키마**(`js/app.js` 기본값, 약 187행): `settings: { motion, thumbs, lastSeen, octColor, flipped, palette, pixelFont, albumSeen, player: SCENE3D.PLAYER_DEFAULT }` — 복원(`Object.assign(d.settings, s.settings)`) 뒤 `player` 가 없거나 키가 빠졌거나 id 가 목록에 없으면 그 칸만 기본값으로(`normalizePlayer(cfg)` 를 app 과 scene 이 같은 규칙으로). 내보내기/불러오기는 settings 에 들어 있으니 그대로. `SCENE.init(..., { player: S.settings.player })`.
- **설정 시트 UI**(`renderSettings`, '문어 색' 섹션 바로 아래 `h3 '내 모습'`): 범주마다 한 줄(라벨 + 칩들), 줄 순서 **머리 · 머리 색 · 눈 · 눈 색 · 옷 · 신발 · 악세사리**. 색(머리 색 · 눈 색)은 `.preset` 동그라미(36 px, `data-hex`, `title`/`aria-label` = name) · 나머지는 `.fchip` 글자 칩, `aria-pressed`, 누르면 `S.settings.player[범주] = id` → `save()` → `scene.setPlayer(cfg)` → 미리보기 갱신. 눈 모양이 `smile`/`dot` 이면 눈 색 줄 아래에 작은 글 한 줄 "이 눈 모양은 눈 색이 안 보여요"(칩은 그대로 둔다). **미리보기**: `playerPortrait` 가 있을 때만 캔버스 1개(`image-rendering: pixelated`, 64 → **96 px** 표시), 섹션 제목 오른쪽. 글·칩에 이모지·기호 없음. 탭 영역 44 px 이상(`.fchip`/`.preset` 의 `::before inset:-6px` 수법 그대로).
- **문서 메모**: 이 설정 시트 자리는 **옷방(왼쪽 문)이 생기기 전까지의 임시 자리**다 — PLAYER_PROGRESSION §7 · §8.2 · OWNER_DECISIONS 11-07: 옷장·가게는 옷방에, 옷방 문은 내 모습을 만든 날 생긴다. 옷방이 오면 이 섹션은 옷장 시트로 옮긴다(저장 스키마 `settings.player` 는 그대로).
