## 가게 방 (걸어 들어가는 가게 — 11-21 밤, 주인: "옷가게 맵을 아예 따로 만들고 마네킹에 입혀진 거를 입어보고 살 수 있는")

가게는 방이다. 아래의 시트 (`#shop-sheet`) 는 방이 없을 때 (2D · 장면 함수 없음) 의 뒷길로 남는다. 규칙 (하루 네 벌 · 값 · 두 탭) 은 같다.

| 박자 | 하는 일 (`js/app.js` `[7-S]`) | 다른 갈래의 것 (있을 때만 부른다) |
|---|---|---|
| 들어감 | `ppol:room` → `roomSet('clothes')`: 마네킹 넷에 오늘의 네 벌 (`roomDress`) · `shop.enter` | `scene.enterRoom` · `scene.mannequins` |

| 입어 보기 | `roomTry`: 내가 갈아입고 한 바퀴, 그 마네킹은 민몸. **아무것도 저장 안 함** · `shop.tryon` | `APP.tryOn` · `scene.playerPose('twirl')` |
| 거울 | `roomMirror`: 가까이 → 자세 → 돌아옴 · `shop.mirror` | `#btn-room-mirror` · `scene.playerCloseup` |
| 계산 | 계산대 · 가게 문어 톡 → 계산대 앞으로 걸어가 `shopListOpen(kind, 'card')`: 계산대 위 목록 카드 (아래 「계산대 목록」). 산 옷은 옷장에 넣은 것만 값을 낸다 · 입어 보던 옷은 입은 채 (입어 보지 않고 산 옷은 옷장에만) · 마네킹엔 팔림 표 (내일까지) · `shop.pay { shells }` | `#btn-room-counter` · `#btn-npc-clothes` · `#btn-npc-goods` · `APP.ownItem` · `APP.wear` |

| 잡화점 | 선반 그림 = 그날 파는 것 (`scene.goodsShelf(items)` — 들어갈 때 · 산 뒤 · 날이 바뀔 때). `roomShelf(i)`: 선반 톡 → 그 물건 이름 · 값 · `계산대에서 살 수 있어` (진열 차례대로, 빈 자리는 빈 선반) · `goods.enter` | `#btn-shelf-0..5` · `scene.goodsShelf` |

카드는 `<dialog>` 가 아니라 `#scene` 안의 `div#shop-card` (`data-npc-avoid` — 대사창이 비켜 선다) 이고, 자리는 그 단추의 화면 위치 위 · 아래 · 옆 중에 캐릭터 · 큰 단추 · 상태 줄을 가리지 않는 곳. 카드 밖을 누르면 접힌다 (Esc 도, 다른 창이 떠 있거나 글 칸에 쓰는 중이면 Esc 는 그쪽 것).
테스트 손잡이: `APP.shopRoom` → `{ key, basket, tried, card }` · `APP.shopList` → `{ id, card, cart, total, msg, done }`.

## 계산대 목록 (`listOpen` — 11-24, 주인: "계산대로 가면 리스트업된 게 쭈르르 떠서 그걸 담는 걸로 … 조개 얼마 남았는지도 띄워주고")

사는 건 이 목록에서만 (가게 방 · 2D 시트 · 미용실이 같은 부품).

- 머리: 가게 문어 얼굴 · `<이름>의 계산대` · 늘 `조개 N`, 담으면 `담으면 M 남아` (`aria-live`).
- 줄: 그림 48 · 이름 · 값표. 옷은 줄 톡 = 담기 / 빼기 (`aria-pressed`), 잡화는 `−` `+` (씨앗은 그날 남은 수까지, 염료는 9 까지 · 단추 이름에 지금 개수). 가진 것 · 다 판 것 · 지금 것은 흐린 줄 (톡하면 `이미 가지고 있어` · `오늘은 이게 다야` · `지금 이거야`).
- 담으면 조개가 모자라는 줄은 안 담기고 값표가 흔들리며 한 줄: `조개가 N개 모자라`. 갈래마다 하나인 목록 (미용실) 은 바뀌어 빠질 같은 갈래 것을 빼고 센다 (값 있는 새 색 A 를 담은 채 B 를 누르면 B 값만 — 11-28 검토).
- **담기는 아무것도 쓰지 않는다.** `사기 (합계)` 를 누른 뒤에만, 한 번 (뜬 뒤 0.6 s 안의 누름은 안 받음 · 두 번 톡해도 한 번). 값 · 가진 조개 · 가짐은 그 자리에서 다시 본다 (`SHOP.buy` 를 한 개씩 — 옷장이 안 받은 옷은 값을 안 낸다).
- 계산 뒤 같은 카드가 영수증으로 1.5 s (`산 것 · N 냈어`, 묻는 말 · 단추 없음, 포커스는 합계 줄) → 닫힘 · 가게 문어 대본 한 줄.
- `닫기` · Esc · 카드 밖 톡 · 방을 나감 → 담은 것은 버린다 (조개는 안 나간다). 닫으면 포커스는 계산대 (의자) 단추로. 어느 길로 접어도 `onClose` 가 돈다 (11-28 검토: 카드 밖 톡 · Esc 는 예전에 건너뛰어 미용실 미리 보기가 남았다). 대사창 (`#npc-box`) 톡은 말 넘기기라 카드를 접지 않는다.
- 다른 탭의 저장 · 날 바뀜: 담은 것은 두고 조개 · 가짐 · 남은 수만 새로 (담은 수는 남은 수에 맞춘다). 영수증 동안에는 다시 그리지 않는다.
- 두 글꼴 16px 바닥 · 누를 것 44px · 줄만 굴러가고 머리 · 단추는 늘 보인다 (320 폭은 `−` `+` 를 아랫줄로, 가로 화면은 상태 줄과 큰 단추 사이 높이까지).
- 부품 쪽 고리: `listOpen({ id, title, host: 'card' | 요소, anchor, items(), buy(lines) → { got, paid }, buyText, seeMe, onChange, onPick(x), onShort(x | null, 모자란 수), onDone(res, paid), onClose, after })`.

## 미용실 (11-24, 방 · 의자는 건물 갈래, 새 색은 캐릭터 갈래)

- 의자에 앉으면 (`ppol:salon-seat { on: true }`) 같은 목록으로 머리 색 · 머리 모양 (색이 먼저) — 갈래마다 하나. 고르면 앉은 채로 미리 입혀 봄 (`APP.tryOn` — 받는 갈래만). 지금 것은 `지금` 표시.
- 카드는 앉은 내 캐릭터를 덮지 않는다 (`seeMe`): 몸 위 · 아래 중 넓은 쪽 높이까지 줄이고 줄은 카드 안에서 굴러감 (그 쪽이 196px = 머리 · 단추 줄 · 줄 하나 이상일 때 — 320×568 도). 위 · 아래가 모자라면 (가로 화면) 카드를 좁혀 (280~340px) 몸 옆에. 그것도 안 되면 예전 자리.
- 대사창 (NPC 갈래 — 가운데에서 위아래로만 비켜 선다) 이 카드 반대쪽에 설 자리가 있을 때만 목록이 떠 있는 동안 소라가 말한다 (`salon.sit` · `pick` · `short`). 자리가 없으면 (가로 화면 · 몸 옆 · 예전 자리) 말하지 않는다 — 대사창이 `바꾸기` · `닫기` 를 가렸다. 앉을 때 말은 카드가 자리를 잡은 뒤 (길어야 1.5 s), 그 사이 벌써 골랐으면 건너뛴다. 바꾼 뒤 `salon.after` 는 영수증 위라 그대로.
- 지금 가진 모양 · 색은 공짜 `바꾸기` (영수증 `바꿨어`). 값 있는 새 색은 캐릭터 갈래의 `APP.salonCatalogue()` → `{ styles, colors: [{ id, name, hex, price, owned }] }` (값 0 = 가진 것) 와 `APP.salonBuy(kind, id)` ('가짐' 만 적음) 가 있을 때만 판다: 입을 수 있는 색 (장면 목록에 있는 것) 만 · `salonBuy` 가 받은 뒤에 조개를 내고 영수증 (`shop.got['hairColor:id']`) · 두 탭은 옷과 같은 길 (다른 탭의 저장이 영수증을 모르면 값과 함께 다시 얹고 `salonBuy` 로 가짐도 다시). 없으면 값 있는 줄은 목록에 없다.
- 일어나면 (`on: false` — 목록이 이미 접혔어도) · 방을 나서면 (`ppol:room-leaving` · `ppol:room` · 키보드로 `밖으로` — 앉은 채 나가면 일어남 신호가 없다) 목록과 미리 보기를 접고 고른 것은 버린다.
- 미용사 소라 대본 (NPC 갈래의 열쇠): 앉을 때 `salon.sit` · 색을 고를 때 `salon.pick { color }` · 색이 모자랄 때 `salon.short { need }` · 색을 바꾼 뒤 `salon.after { shells }`. 대본이 색 이야기 (병 · 칠) 라 머리 모양만 고르거나 바꿀 때는 말하지 않는다. `salon.leave` (나갈 때) 는 건물 갈래가 부른다 (`ppol:room-leaving` — 문 쪽으로 걷기 시작할 때 · `밖으로` 를 바로 누른 때).

## 옷가게 선반 규칙 (방 · 시트 같음)

- 하루 **네 개**. 살 수 있는 옷 (옷장 목록에서 `shop: { price }` 가 있는 것, 계약 C4) 전부를 한 바퀴 = `ceil(N / 4)` 일에 한 번씩 돌린다 (N 이 40 이하면 열흘 안).
- 바퀴마다 시드 (`shop|clothes|바퀴 번호`) 로 섞고, 값으로 반을 갈라 **싼 것 둘 · 비싼 것 둘**이 하루에 오게 엇갈려 놓는다 (오늘 살 것 하나 · 모아서 살 것 하나).
- 전에 산 옷은 다음 차례의 아직 없는 옷으로 바뀐다. **오늘 산 옷은 체크 표시와 함께 그 자리에 남는다.** 다 가졌으면 있는 것을 표시와 함께 보여 준다.
- 같은 날 · 같은 목록이면 어느 기기에서나 같은 선반.
- 2D 시트 (방이 없을 때): 그림 띠 아래에 같은 계산대 목록 (시트에서도 사는 건 목록에서만, `닫기` 는 시트를 닫는다).
- 그림 (옷 · 씨앗 봉투 · 염료 병) 은 한 점이 기기 px 의 정수배가 되게 크기를 맞춘다 (`shopSnap` — 2.625 배율에서 64px 자리의 32px 그림은 5배).
- 값은 옷장 목록 (캐릭터 갈래) 에서 온다. 여기에는 옷 값 표가 없다.

## 바닷가 조개

다섯 자리 중 **그날의 셋** (시드 `beach|날짜`). 주우면 조개 +1, 그 자리는 다음 날까지 쉰다. 장면에는 남은 자리만 알린다 (`scene.beachShells(list)` — 바깥 갈래). 화면에 세는 글은 없다.

## 저장 (`S.user`, 모르는 칸은 그대로 둔다)

```
shop  = { got: { '갈래:id': 'YYYY-MM-DD' (산 날 — 옷 · 미용실 새 색 'hairColor:id') }, day: { key, seeds } | null }
beach = { day: 'YYYY-MM-DD' | null, picked: [자리] }
```

- 옷을 가졌는지는 캐릭터 갈래의 `user.owned` (`APP.ownItem` · `APP.wardrobe()` 의 `owned`) **하나만** 본다. `shop.got` 은 '언제 샀나' 기록이다: 다른 탭의 늦은 저장이 옷장을 덮었으면 기록에 있는 옷을 `APP.ownItem` 으로 다시 넣는다 (`shopSync`).
- 사기는 `SHOP.buy` 가 값 · 가진 조개 · 가짐을 다시 보고, 옷장에 넣기가 실패하면 (`ownItem` 이 던지거나 `false`) 조개도 안 나간다.
- 두 탭: 이 탭이 60 s 안에 산 것 · 주운 것은 **다른 탭의 저장을 받은 때에만** 다시 얹는다 (불러오기 · 초기화 뒤에는 얹지 않는다) (`SHOP.merge` — 산 것 합집합 · 같은 날 씨앗 수는 큰 쪽 · 주운 자리 합집합). 조개 수는 지금까지의 두 탭 규칙 그대로 (장부 없음). 시트를 열거나 옷가게에 들어가도 (다시 얹지 않는 `shopSync()`) 그 60 s 목록은 그대로 둔다 (11-28 검토: 예전엔 비워서 그 뒤에 온 늦은 저장이 산 것을 공짜로 만들었다).
- 다시 얹을 조개가 모자라면: 산 옷 · 색이 두 탭 합치기 (`ownedMerge` — 가진 것은 줄지 않는다) 로 이미 내 것이면 남은 조개를 다 내고 영수증과 함께 남긴다 (두 탭이 같은 조개를 함께 썼다 — 공짜로 남지 않게). 아직 안 가졌으면 그 산 것은 버린다 (씨앗도).
