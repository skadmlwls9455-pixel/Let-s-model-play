# 다국어 — 방의 언어 (ko · en · ja) · 2026-11-10

주인의 뜻: "일본어·영어도. 기존 클로드 사용자의 언어 설정을 따라가서 언어가 알아서 맞춰지는 것." 이 문서는 그 길을 어떻게 나눴는지, 지금 어디까지 됐는지, 주인이 정할 것이 무엇인지 적는다.

## 한 줄 설계

**언어는 방에 붙는다.** 방 하나 = 한 사람 = 한 언어. 모델에게 가는 글 (안내문 · 도구 설명 · 상태 · 오류 · 물음), 문 밖의 도서관 (그 언어의 위키백과), 오늘의 서가, 열람실 이름, 엽서 꼬리표가 전부 방의 언어를 따른다. 문어가 남기는 글도 방의 언어로 쓰인다 (안내문에 한 줄: "이 방의 언어는 ○○다. 네가 남기는 글도 ○○로 쓴다") — 사람이 게임 화면에서 그 언어로 읽기 때문이다.

언어는 어디서 오나 (우선순위 순):

| 길 | 누가 | 언제 | 어디에 남나 |
|---|---|---|---|
| 1. 방을 만들 때 | 게임이 기기 언어 (`navigator.language`) 를 `POST /api/room {lang}` 로 보낸다 | 설정 › 내 Claude 와 연결 › 방 만들기 | `meta.lang` (바뀌지 않는다) |
| 2. 로컬 stdio | `PPOLPPOL_LANG=en` | 서버를 띄울 때 | 환경 변수 |
| 3. 둘 다 없으면 | 모델이 `ppolppol_look_room {lang}` 으로 대화의 언어를 한 번 알려 준다 | 첫 look_room | `state.lang` (그 뒤로 고정 — 모델이 다시 바꾸지 못한다) |

3번이 "클로드 사용자의 언어 설정을 따라가는" 길이다: 서버는 claude.ai 의 언어 설정을 볼 수 없지만 (MCP 에 locale 이 없다 — SDK 를 확인했다), 모델은 대화의 언어를 안다. 1번이 있으면 3번은 무시된다 — 사람이 게임에서 읽는 언어가 우선이다.

**먼 바다 문** (등불 4칸 뒤 사람이 한 번 열어 주는 문) 너머는 방의 언어 밖의 위키 하나: ko → en, ja → en, **en → ja** (`I18N.FAR`). 그 밖의 언어는 "이 방의 지도에 없다" 고 거절한다.

## 된 것 (이 PR)

- `mcp/i18n.js` — 세 언어 사전. ko 글은 전과 글자 하나 다르지 않다 (시험이 본다). 열쇠가 세 언어 모두 같은지도 시험이 본다.
- `mcp/core.js` — 방의 언어 (`lang()` · `far()` · `setLang()`), 위키 API 를 언어별로 (`{lang}.wikipedia.org`), 출처 주소 검사도 언어별로, 모든 오류·물음·때·등불 글이 사전에서. 찾아보기 (find) 도 방의 언어로.
- 오늘의 서가: ko 는 전처럼 `js/shelf.js` (게임과 같은 뽑기), en·ja 는 `mcp/data/shelf.<lang>.json` (`tools/build-shelf.js en ja` — 영어 알찬 글 7,031편 · 일본어 秀逸+良質 2,640편에서 각 600편 표본). 없으면 위키 분류에서 산다.
- 열람실 이름 · 방의 위키 글: `mcp/data/rooms.i18n.json` (`tools/build-room-names.js` — ko.wikipedia 언어 링크. 62개 방 중 en 58 · ja 57. 없는 방은 ko 이름·ko 글 그대로: rain · cipher · blanket 등).
- 책 · 서가 카드 번역본: `library/books/<lang>/<방>.md`, `library/cards/<lang>/<ID>.md` — 책 32권 · 카드 82장 전부 en·ja 번역본이 있다 (228편, 2026-11-10, Claude 가 옮김 — 주인: "번역본 없는 게 없도록"). `by` 에 옮긴 이 (`… · English by Claude (AI)` / `… · 日本語訳 Claude (AI)`), `original:` 에 원본 지문 (`tools/stamp-translations.js`) — 원문이 바뀌면 check-books 가 "원본이 바뀜", 번역이 없으면 "번역 없음" 으로 알린다. 길이 눈금은 언어별 (`core.bookLimits`: en ×3 · ja ×1.1). 규칙·점검은 [library/README](../library/README.md). 번역본이 없는 새 글은 원본 (ko) 을 주되 `cards` 목록에 `(ko)` 표시, 읽으면 `book.lang: "ko"`. 원본 없는 번역본은 오류.
- `mcp/tools.js` — 안내문 · 도구 제목·설명 · 스키마 설명이 방의 언어로 (initialize 때 정해진다). look_room 에 `lang` 칸. `target.lang` 에 ja. 도구 정의 크기: ko 5,580 B · en 5,529 B · ja 5,676 B (상한 5,700 — 전엔 5,500).
- `mcp/postcard.js` — 엽서 꼬리표 (읽음 · 서가 카드 · 출처 · 반응 …) 가 방의 언어. 모델 글은 어느 언어든 그대로.
- `mcp/http.js` · `api/room.js` · `mcp/store.js` — 방 만들 때 `lang` 을 받아 `meta.lang` 에. 오류 문장도 그 방의 언어.
- 게임 쪽 두 줄: 방 만들기가 `navigator.language` 를 보낸다 (js/app.js), 출처 주소 검사에 ja (js/app.js · js/brain.js), 반응 얼굴에 en·ja 낱말 (hop · ぴょん …).
- 시험: `cd mcp && npm test` 176 통과 — en 방 단위 (위키 언어 · 먼 바다 · 찾아보기 · 방 이름 · 번역 카드 · 엽서 · 언어 없는 방), 길이 눈금 · 지문, en · ja stdio 왕복 (안내문·도구가 그 언어, 한글 0, 예산, 오늘의 카드 제목이 번역본, 카드를 읽으면 그 언어의 글).

## 안 된 것 (다음)

1. **게임 화면 (UI) 의 다국어.** `js/app.js` 634줄 · `index.html` 116줄 · `js/brain.js` 225줄 (일기 문장 등) 에 한국어가 박혀 있다. 주 세션이 지금 app.js 를 계속 고치고 있어 이번엔 손대지 않았다 (충돌). 주인이 다른 세션에서 하기로 (2026-11-10). 길: `js/i18n.js` (`I18N.t(key)` + 사전 ko/en/ja + `?lang=` · 기기 언어 · 설정) 를 두고 화면 글을 한 번에 뽑는 일. 글꼴은 된다: Galmuri 에 가나 187자 · 한자 6,400자가 있다 (subset-fonts 가 CJK 틈을 메운다). 서버 쪽 번역본 (책·카드 제목) 은 이미 그 언어라, 게임이 방의 언어를 알면 그대로 보이면 된다.
2. **세계 데이터 (`js/world.js`) 의 방 이름 · 단서 · 기억 · 다리 글 858줄.** 서버는 이름·위키만 언어 링크로 대신했고, 단서 (`clue`) 는 위키를 못 읽을 때만 ko 그대로 간다. 게임 화면이 다국어가 될 때 같이.
3. **방의 언어 바꾸기.** 지금은 방을 만들 때 한 번. 게임에 언어 설정이 생기면 바꾸는 길 (`POST /api/room/<key>` 같은 것) 이 필요하다. 그때까지는 새 방을 만든다.
4. **stdio 에서 모델이 언어를 정한 뒤의 도구 설명.** 도구 목록은 initialize 때 실렸으므로 look_room 으로 언어를 정해도 설명은 그대로다 (`sendToolListChanged` 로 다시 실을 수 있다 — 아직 안 함). 원격 방은 요청마다 서버를 새로 만들어서 문제없다.
5. 스킬 (`.claude/skills/ppolppol-octopus-play/SKILL.md`) 은 한국어 하나. 로컬 Claude Code 용이라 뒤로.
6. 새 책·카드는 번역 전까지 en·ja 방에 `(ko)` 로 보인다 — 번역은 같은 방식 (Claude 에 시키고 check-books + stamp) 으로 그때그때.

## 주인이 정할 것

- **먼 바다 문의 언어표** `I18N.FAR` — ko→en · ja→en · en→ja 로 두었다. 뜻: 먼 바다 문은 "방의 언어가 아닌 위키 하나" 로 나가는 문이라, 영어 방에선 영어 위키가 이미 집 (문 밖 도서관) 이어서 다른 언어 하나를 골라야 했고, 서버가 지금 읽을 수 있는 세 언어 중 남는 것이 일본어뿐이라 ja 로 두었다. 바꾸려면 `I18N.FAR.en` 한 줄 + 그 언어를 `I18N.LANGS`/`norm` 에 (de · fr · es 같은 큰 위키도 된다 — 먼 바다는 글만 읽으므로 사전은 필요 없다). 후보: ja (지금) · ko (문어의 고향, 작은 위키) · de/fr/es (큰 위키).
- **방의 언어를 사람이 바꿀 수 있게 할지** (3번) — 게임 설정에 언어 고르기를 둘지.

## PROTOCOL 제안 (주 세션이 고친다)

- `peek` 이벤트 `target.lang` 은 지금까지 `"en"` 만 (먼 바다). 이제 `"en" | "ja"` 가 온다 — 방의 언어이거나 먼 바다의 언어. `room` 기웃에도 `target.lang` 이 붙을 수 있다 (그 언어의 위키 글을 읽은 경우). `source.attribution` 은 `Wikipedia (xx)`.
- `book.lang` (peek 결과, 기록엔 없음): 방의 언어와 다른 책·카드를 읽었을 때 그 글의 언어.
