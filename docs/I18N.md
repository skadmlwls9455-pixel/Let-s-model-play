# 다국어 — 방의 언어 (ko · en · ja · de · fr · es · it · pt · id · hi = claude.ai 화면 언어 전부) · 2026-11-10

주인의 뜻: "일본어·영어도. 기존 클로드 사용자의 언어 설정을 따라가서 언어가 알아서 맞춰지는 것." → 같은 날 밤: "번역본 없는 게 없도록", "일본어 말고 영어를 메인으로. 독일어·프랑스어·스페인어도, 영어를 가장 우선." → 더 늦은 밤: "방의 언어는 기존 클로드 설정에 따르되 바꿀 수 있는 걸로. 독일어로 거절하거나 하지 않게 각 양은 똑같이. 100권 있다고 치면 100권 각각 모든 언어별로 번역판이 있어야 해." → 더 늦게: "클로드에서 지원하는 모든 각 언어별로 확장해줄래? 지금은 빠진 게 있을 거 같아서." (→ 아래 "열 언어로"). 이 문서는 그 길을 어떻게 나눴는지, 지금 어디까지 됐는지, 주인이 정할 것이 무엇인지 적는다.

## 한 줄 설계

**언어는 방에 붙고, 대화를 따라간다.** 방 하나 = 한 사람 = 한 언어. 모델에게 가는 글 (안내문 · 도구 설명 · 상태 · 오류 · 물음), 문 밖의 도서관 (그 언어의 위키백과), 오늘의 서가, 열람실 이름, 엽서 꼬리표가 전부 방의 언어를 따른다. 문어가 남기는 글도 방의 언어로 쓰인다 (안내문에 한 줄: "이 방의 언어는 ○○다. 네가 남기는 글도 ○○로 쓴다") — 사람이 게임 화면에서 그 언어로 읽기 때문이다.

언어는 어디서 오나 (우선순위 순):

| 길 | 누가 | 언제 | 어디에 남나 |
|---|---|---|---|
| 1. 사람이 정해 둔 것 | 게임 설정 › 내 Claude 와 연결 › **방의 언어** (`POST /api/lang/<열쇠> {lang}`) · 로컬 stdio 는 `PPOLPPOL_LANG` | 언제든 | `meta.lang` + `meta.pin` (환경 변수) — 모델이 바꾸지 못한다. 설정에서 `자동` 으로 돌리면 고정이 풀린다 |
| 2. 대화의 언어 | 모델이 `ppolppol_look_room {lang}` 에 사람이 대화에서 쓰는 언어를 적는다 (안내문이 매번 적으라고 한다) | 매 look_room | `state.lang` — 바뀌면 방도 바뀐다. 원격 방은 `http.js` 가 `meta.lang` 에 비춰서 다음 initialize 의 안내문·도구부터 그 언어, stdio 는 도구 정의를 그 자리에서 다시 싣는다 (`update` → `tools/list_changed`) |
| 3. 처음 값 | 게임이 기기 언어 (`navigator.language`) 를 `POST /api/room {lang}` 로 보낸다 | 방을 만들 때 | `meta.lang` (열 밖이면 `I18N.DEFAULT` = en) — 모델이 말하기 전까지만 |
| 4. 아무것도 없으면 | | | ko |

2번이 "클로드 사용자의 언어 설정을 따라가는" 길이다: 서버는 claude.ai 의 언어 설정을 볼 수 없지만 (MCP 에 locale 이 없다 — SDK 를 확인했다), 모델은 사람이 어떤 언어로 말하는지 안다. 사람이 claude.ai 의 언어를 바꾸면 다음 산책의 look_room 에서 방이 따라 바뀐다. 1번이 있으면 2번은 무시된다 — 사람이 정한 것이 우선이고, 모델에겐 "사람이 이 방의 언어를 ○○로 정해 두었다" 고 그 언어로 알린다 (`langNote`). 바뀌었을 때도 `langNote` 로 알린다 ("방의 언어가 ○○로 바뀌었다. 이제부터 네가 남기는 글은 ○○로 쓴다").

**영어가 메인** (주인 2026-11-10): 기기 언어가 있는데 열 언어 밖이면 (zh-TW 같은) 처음 값이 영어다 (`I18N.DEFAULT`). 그 뒤는 대화를 따른다.

**먼 바다 문** (등불 4칸 뒤 사람이 한 번 열어 주는 문) 너머는 **나머지 아홉 언어의 위키 전부** — 어느 방이든 같다 (`I18N.FAR[lang]` = 열에서 그 언어를 뺀 목록). 언어로 거절하는 일은 없다 (전엔 "그 언어는 이 방의 지도에 없다" 가 있었다 — 주인: "독일어로 거절하거나 하지 않게"); 문이 닫혀 있으면 "아직 닫혀 있다" 만 (`farClosed`).

**양은 똑같이** (주인): 어느 언어의 방이든 받는 것이 같다 — 집 위키 하나 + 먼 바다 아홉, 오늘의 서가 600편 표본, 열람실 65개 전부의 이름 (위키 있는 62개는 위키 제목도), 책 32권 · 카드 82장 전부의 번역본. 책·카드는 **모든 글에 열 언어 전부** 가 규칙이다 — `check-books` 가 빠진 번역을 오류로 막고 시험도 전수를 본다.

## 된 것

- `mcp/i18n.js` + `mcp/i18n/<lang>.js` — 열 언어 사전 (ko 원본 · en 은 주 세션이 · ja·de·fr·es·it·pt·id·hi 는 Claude 보조 세션이 en 을 틀로, ko 를 뜻의 기준으로 옮김). 열쇠·함수 모양이 열 언어 모두 같은지, 집 활동 문장이 world.js 의 활동을 다 덮는지 시험이 본다. 먼 바다 글은 `N(far)` (위키 이름들) · `C(far)` (코드들) 로 쓴다. 언어 줄 (`instructions[5]`) 이 "방의 언어는 대화를 따른다: look_room 의 lang 에 사람이 대화에서 쓰는 언어를 적으면 바뀐다; 사람이 게임에서 정해 두었으면 그것이 우선" 을 말한다. `langChanged` · `langPinned` 알림.
- `mcp/core.js` — 방의 언어 (`lang()`: 사람이 정한 것 > 모델이 알려 준 대화의 언어 > 기기 언어 > ko · `setLang()` 은 사람이 정한 방에선 false · `far()` 는 나머지 아홉), `lookRoom {lang}` 이 언어를 따라가고 `lang` · `langNote` 를 돌려준다, 위키 API 를 언어별로, 출처 주소 검사도 언어별로, 모든 오류·물음·때·등불 글이 사전에서. 찾아보기 (find) 도 방의 언어로.
- 오늘의 서가: ko 는 전처럼 `js/shelf.js` (게임과 같은 뽑기), 나머지는 `mcp/data/shelf.<lang>.json` (`tools/build-shelf.js en ja de fr es it pt id hi` — 알찬·좋은 글 분류에서 각 600편 표본: en 7,031 · ja 2,640 · de 7,502 · fr 6,608 · es 4,866 · it 1,230 · pt 3,572 · id 716 · hi 896 — hi 는 자기 알찬 글이 44편뿐이라 영어 알찬 글의 언어 링크로 다리를 놓았다, `core.SHELF_VIA`). 없으면 위키 분류에서 산다.
- 열람실 이름 · 방의 위키 글: `mcp/data/rooms.i18n.json` (`tools/build-room-names.js [언어…]` — ko.wikipedia 언어 링크, 없는 언어는 영어 글의 언어 링크로 한 번 더) 위에 `mcp/data/rooms.manual.json` (손으로 적고 그 위키에 글이 있는지 API 로 확인한 것) 을 덮는다 → **65개 방 전부 열 언어** (위키 있는 62개는 제목도). 손으로 채운 방: rain · cipher · blanket · pinecone · starfish (언어 링크가 Bulgasari 괴물로 가 있었다) · shell · honeycomb · chalk, 위키 없는 octopus_nerves · slow_room · letter_room 은 이름만; it·pt·id·hi 는 아래 "열 언어로". 그 언어 위키에 글이 없는 방은 manual 에 `wiki: null` (확인했음) — `core.roomWiki` 가 **그 언어 → 영어 → ko** 순으로 떨어진다. 같은 김에 `js/world.js` 에서 동음이의 문서를 가리키던 셋 (비 → 비 (날씨), 암호 → 암호 (암호학), 불가사리 → 불가사리류) 을 고쳤다 — 한국어 방도 진짜 글을 읽게.
- 책 · 서가 카드 번역본: `library/books/<lang>/<방>.md`, `library/cards/<lang>/<ID>.md` — 책 32권 · 카드 82장 전부 en · ja · de · fr · es · it · pt · id · hi (1,026편, 2026-11-10, Claude 보조 세션이 옮김 — 영어 먼저, 나머지 일곱은 ko 원문 + en 참고). `by` 에 옮긴 이, `original:` 에 원본 지문 (`tools/stamp-translations.js`) — 원문이 바뀌면 check-books 가 "원본이 바뀜", 번역이 없으면 **오류** "번역 없음". 길이 눈금은 언어별 (`core.bookLimits`: en ×3 · de·fr·es·it·pt·id·hi ×3.5 · ja ×1.1). 규칙·점검은 [library/README](../library/README.md). 안전망: 혹시 번역본 없이 서버가 뜨면 원본 (ko) 을 주되 `cards` 목록에 `(ko)` 표시, 읽으면 `book.lang: "ko"`. 원본 없는 번역본은 오류.
- `mcp/tools.js` — 도구 정의를 방의 언어로 만든다 (`defs`). look_room 뒤 언어가 바뀌었으면 살아 있는 연결 (stdio, `hooks.live`) 에선 제목·설명·스키마를 다시 싣는다; 원격 방은 요청마다 새로 만들어서 저절로. `target.lang` 은 열 언어. 도구 정의 크기: ko 5,778 · en 5,712 · ja 5,859 · de 5,790 · fr 5,862 · es 5,853 · it 5,852 · pt 5,799 · id 5,854 B (상한 6,000) · hi 7,153 B (데바나가리는 글자당 3바이트 — 상한 7,500).
- `mcp/postcard.js` — 엽서 꼬리표 (읽음 · 서가 카드 · 출처 · 반응 …) 가 방의 언어. 모델 글은 어느 언어든 그대로.
- `mcp/http.js` · `api/room.js` · `mcp/store.js` · `api/lang/[key].js` · `api/walks/[key].js` — 방 만들 때 `lang` (처음 값), 모델이 알려 준 언어를 `meta.lang` 에 비춤, 사람이 정하기 (`setRoomLang`: 열 중 하나면 `pin`, `auto` 면 풀고 `state.lang` 으로), walks 응답에 `lang` · `pin` (게임 설정이 보여 준다). 오류 문장도 그 방의 언어.
- 게임 쪽: 방 만들기가 `navigator.language` 를 보낸다, 설정 › 내 Claude 와 연결에 **방의 언어** 고르기 (`자동 · Claude 대화를 따라감 (지금 ○○)` / 한국어 / English / 日本語 / Deutsch / Français / Español / Italiano / Português / Bahasa Indonesia / हिन्दी → `/api/lang`), 출처 주소 검사에 열 언어 (js/app.js · js/brain.js), 반응 얼굴에 en·ja 낱말. 글꼴 서브셋에 라틴 보충·확장 A (é ü ß ñ ã ç …) — 힌디어 (데바나가리) 는 Galmuri 에 없어 게임 화면에선 기기 글꼴로 보인다.
- 시험: `cd mcp && npm test` 244 통과 — en 방 단위 (위키 언어 · 먼 바다 다섯 · 언어 바꾸기 · 사람이 정한 방 · 방 이름 전수 · 번역 카드 · 엽서 · 모르는 언어 → en), 사람이 정하기 (store · api/lang Origin), 원격 방 왕복 (de 로 만든 방 → look_room lang:en → 다음 initialize 가 영어 → 사람이 ja 로 정하면 모델의 en 은 무시 → auto 로 풀면 다시 따라감), stdio 왕복 (환경 변수 없이 look_room lang:de → 도구 정의가 독일어로 다시 실림, list_changed), 번역본 1,026편 전수 (지문 · 한글 0 · by), ko 밖 아홉 언어 stdio 왕복 (안내문·도구가 그 언어, 예산).

## 새 언어를 더하려면

1. `mcp/i18n/<lang>.js` — en.js 를 틀로 옮긴다 (열쇠·함수 그대로; 시험이 본다). `mcp/i18n.js` 의 `LANGS` · `require` 에 더한다 (FAR 는 LANGS 에서 저절로).
2. `core.SHELF_CATS` 에 그 위키의 알찬 글 분류 (100편이 안 되면 `core.SHELF_VIA[lang] = 'en'` 으로 영어 알찬 글의 언어 링크를 더한다) → `node tools/build-shelf.js <lang>`; `node tools/build-room-names.js` (인자 없으면 ko 밖 전부; ko 링크 → 영어 글의 링크 순); 그래도 없거나 엉뚱한 방은 `mcp/data/rooms.manual.json` 에 손으로 — 그 위키에 글이 없으면 `wiki: null` (시험이 빈 방을 알려 준다).
3. 번역본: 책 32 · 카드 82 **전부** 를 같은 브리프로 (ko 원문 + en 참고, `by` 끝에 옮긴 이) → `node tools/stamp-translations.js` → `npm run check-books` (하나라도 빠지면 오류). `core.LEN_SCALE` 에 길이 눈금.
4. 게임: `js/app.js` 의 `LANG_NAMES` 와 `js/app.js` · `js/brain.js` 의 출처 주소 검사에 언어 코드. 글꼴에 없는 글자 범위면 기기 글꼴로 보인다 — 픽셀 글꼴로 보이게 하려면 그 구역이 든 OFL 글꼴의 서브셋을 `tools/subset-fonts.py` 의 덧붙임 면 (ADDON_*, 데바나가리가 보기) 처럼 Galmuri family 에 얹는다 (fontTools 필요: `python3 -m venv /tmp/ftenv && /tmp/ftenv/bin/pip install fonttools brotli`).
5. 시험: `mcp/test/run.js` 의 `i18nProtocol('<lang>')` 호출과 `want` (bell 의 그 언어 이름).

## 열 언어로 (2026-11-10 늦은 밤)

주인: "클로드에서 지원하는 모든 각 언어별로 확장해줄래? 지금은 빠진 게 있을 거 같아서." claude.ai 화면 언어 목록 (support.claude.com 글 10769299, 2026-11 확인) 은 영어 · 프랑스어 · 독일어 · 힌디어 · 인도네시아어 · 이탈리아어 · 일본어 · 한국어 · 포르투갈어 (브라질) · 스페인어 (스페인 · 라틴아메리카) 열하나 → 코드로는 열: 스페인어 둘은 `es` 하나 (위키도 하나), 새로 `it` · `pt` (브라질 용법, você) · `id` (표준 인도네시아어, kamu) · `hi` (표준 힌디어, तुम · 아라비아 숫자). 중국어는 공식 목록에 없어서 (제3자 글만) 넣지 않았다 — 들어오면 위 "새 언어를 더하려면" 그대로.

- 사전 넷은 Claude 보조 세션 (Sonnet) 이 en.js 를 틀로, ko.js 를 뜻의 기준으로 옮겼다 (열쇠 같음은 시험이 본다). 도구 정의가 lang enum 열 + 먼 바다 아홉으로 커져서 상한을 5,800 → 6,000 B 로 올렸다; hi 는 데바나가리가 글자당 3바이트라 7,153 B (상한 7,500) — 토큰으로는 다른 언어와 비슷한 분량.
- 서가: it 1,230 · pt 3,572 · id 716 편에서 600 표본. **hi 위키는 알찬 글이 44편뿐** 이라 다리를 놓았다: 영어 알찬 글 전체 가운데 힌디어 위키에도 있는 글 (언어 링크, 861편) 을 더해 896편에서 600 표본 (`core.SHELF_VIA = { hi: 'en' }`, `build-shelf.js` 가 결과에 `via` 를 적는다).
- 열람실 이름: `build-room-names.js` 에 2차 — ko 글에 링크가 없는 언어는 영어 글의 언어 링크로 (18개 채움). 그래도 없는 것은 `rooms.manual.json` 에 손으로 (API 로 확인): lock · octopus · ink · riddle (pt) · feather · moss · name (it) · octopus · shell · cipher · honeycomb · spiral · riddle (hi), 이름만인 방 셋에 네 언어 이름. **hi 위키에 글이 없는 방** (quill · knot_theory · mobius · tessellation · whale_song) 과 id 의 knot_theory 는 `wiki: null` 로 두고 `core.roomWiki` 가 그 언어 → 영어 → ko 로 떨어진다 (전엔 바로 ko — 영어가 메인이라 바꿨다).
- 번역본 456편 (책 32 · 카드 82 × 4) — 열여섯 Sonnet 세션, 같은 브리프 (ko 원문 + en 참고; 숫자는 it·pt·id 가 3,66 · 1.000, hi 가 3.66 · 1,000). 길이 it 2.2–2.9× · pt 2.2–2.7× · id 2.3–2.8× · hi 2.1–2.6× (ko 글자 수 대비) → `LEN_SCALE` 넷 다 3.5.
- 게임: `LANG_NAMES` 에 Italiano · Português · Bahasa Indonesia · हिन्दी, 출처 주소 검사 열 언어. **언어별 UI 이미지는 없다** — 그림은 전부 언어 중립 (문어 · 방 · 날씨 · 엽서 틀) 이고 글자는 글꼴·꼬리표뿐이라 언어마다 그릴 것이 없었다. 글꼴: it·pt·id 는 라틴 보충·확장 A 로 이미 된다. **hi (데바나가리) 는 Galmuri 에 없어** 처음엔 기기 글꼴로 보였다 → 주인 ("힌디어 픽셀 글꼴 얹어줘"): GNU Unifont (16px 격자, OFL 1.1 / GPL 2+ 글꼴 예외 이중) 의 데바나가리 구역 161자만 떼어 `vendor/fonts/Unifont-Devanagari.sub.woff2` (3 KB) 로 두고, Galmuri 세 가족에 같은 family 이름의 면으로 덧붙였다 (`tools/subset-fonts.py`, unicode-range 로 힌디어가 나올 때만 받는다; 라이선스 `UNIFONT-LICENSE.txt`). Galmuri 는 2× (16/20/24px) 로 쓰이고 Unifont 격자는 16px 라 정수 배가 되게 `size-adjust`: Galmuri7 16px → 1× · Galmuri9 20px → 80% = 16px 1× · Galmuri11 24px → 133% = 32px 2× (1× 면 옆 한글의 6할 크기라 너무 작고, 2× 면 1.2배 — 2× 를 골랐다). 오픈 라이선스 데바나가리 픽셀 글꼴은 Unifont 뿐이었다 (GitHub DevanagariPixel 은 라이선스 없음, FontStruct 것들은 글자 수·모양 미확인). Unifont 는 글자마다 그림 하나뿐 (GSUB 없음) 이라 결합 자음은 할란트 (्) 가 그대로 보이는 타자기체고, ि 같은 앞 모음 기호는 브라우저의 인도계 정렬만 받는다 — 읽히지만 활자체는 아니다. Chrome 에서 세 크기 모두 격자에 맞게 찍히는 것을 확인했다 (`~/Downloads/힌디어_픽셀글꼴_확인.png`).

## 주인이 정할 것

- **먼 바다 문 자체.** "거절하지 않게" 를 언어에 대해 적용했다 (어느 방이든 아홉 전부). 등불 4칸 + 사람이 한 번 여는 문은 그대로다 — 문이 닫혀 있으면 "아직 닫혀 있다" 가 간다. 이 문도 없애고 싶으면 `core.peek` 의 `farClosed` 한 줄.
- **모르는 기기 언어의 처음 값은 영어** (`I18N.DEFAULT`) — 대화가 시작되면 어차피 따라가므로 첫 안내문 한 번의 문제다. 한국어로 두고 싶으면 한 줄.
- **모델이 알려 준 언어를 그대로 믿는 것.** 모델이 lang 을 잘못 적으면 방이 그 언어로 바뀐다. 사람은 설정에서 고정할 수 있다. 더 조심하려면 "두 번 연속 같은 언어일 때만" 같은 규칙을 둘 수 있다 — 지금은 두지 않았다.
- 힌디어 글꼴의 모양: Unifont 는 결합 자음을 할란트 그대로 보이는 타자기체다. 더 나은 OFL 데바나가리 픽셀 글꼴이 나오면 `tools/subset-fonts.py` 의 ADDON_* 만 바꾸면 된다. 24px 자리의 2× (옆 글자보다 1.2배) 가 거슬리면 `ADDON_FAMILIES` 의 Galmuri11 을 66.67% (1×, 6할 크기) 로.
- 중국어를 넣을지 (claude.ai 화면 언어 목록 밖 — 대만·싱가포르·말레이시아처럼 Claude 를 쓸 수 있는 중국어권은 있다. 넣으면 위 4단계 그대로; zh 위키는 간체·번체 변환이 있어 제목 표기를 하나 정해야 한다).
## PROTOCOL 제안 (주 세션이 고친다)

- `peek` 이벤트 `target.lang` 은 열 언어 중 하나 — 방의 언어이거나 먼 바다의 언어. `room` 기웃에도 `target.lang` 이 붙을 수 있다 (그 언어의 위키 글을 읽은 경우). `source.attribution` 은 `Wikipedia (xx)`.
