# 다국어 — 방의 언어 (ko · en · ja · de · fr · es) · 2026-11-10

주인의 뜻: "일본어·영어도. 기존 클로드 사용자의 언어 설정을 따라가서 언어가 알아서 맞춰지는 것." → 같은 날 밤: "번역본 없는 게 없도록", "일본어 말고 영어를 메인으로. 독일어·프랑스어·스페인어도, 영어를 가장 우선." → 더 늦은 밤: "방의 언어는 기존 클로드 설정에 따르되 바꿀 수 있는 걸로. 독일어로 거절하거나 하지 않게 각 양은 똑같이. 100권 있다고 치면 100권 각각 모든 언어별로 번역판이 있어야 해." 이 문서는 그 길을 어떻게 나눴는지, 지금 어디까지 됐는지, 주인이 정할 것이 무엇인지 적는다.

## 한 줄 설계

**언어는 방에 붙고, 대화를 따라간다.** 방 하나 = 한 사람 = 한 언어. 모델에게 가는 글 (안내문 · 도구 설명 · 상태 · 오류 · 물음), 문 밖의 도서관 (그 언어의 위키백과), 오늘의 서가, 열람실 이름, 엽서 꼬리표가 전부 방의 언어를 따른다. 문어가 남기는 글도 방의 언어로 쓰인다 (안내문에 한 줄: "이 방의 언어는 ○○다. 네가 남기는 글도 ○○로 쓴다") — 사람이 게임 화면에서 그 언어로 읽기 때문이다.

언어는 어디서 오나 (우선순위 순):

| 길 | 누가 | 언제 | 어디에 남나 |
|---|---|---|---|
| 1. 사람이 정해 둔 것 | 게임 설정 › 내 Claude 와 연결 › **방의 언어** (`POST /api/lang/<열쇠> {lang}`) · 로컬 stdio 는 `PPOLPPOL_LANG` | 언제든 | `meta.lang` + `meta.pin` (환경 변수) — 모델이 바꾸지 못한다. 설정에서 `자동` 으로 돌리면 고정이 풀린다 |
| 2. 대화의 언어 | 모델이 `ppolppol_look_room {lang}` 에 사람이 대화에서 쓰는 언어를 적는다 (안내문이 매번 적으라고 한다) | 매 look_room | `state.lang` — 바뀌면 방도 바뀐다. 원격 방은 `http.js` 가 `meta.lang` 에 비춰서 다음 initialize 의 안내문·도구부터 그 언어, stdio 는 도구 정의를 그 자리에서 다시 싣는다 (`update` → `tools/list_changed`) |
| 3. 처음 값 | 게임이 기기 언어 (`navigator.language`) 를 `POST /api/room {lang}` 로 보낸다 | 방을 만들 때 | `meta.lang` (여섯 밖이면 `I18N.DEFAULT` = en) — 모델이 말하기 전까지만 |
| 4. 아무것도 없으면 | | | ko |

2번이 "클로드 사용자의 언어 설정을 따라가는" 길이다: 서버는 claude.ai 의 언어 설정을 볼 수 없지만 (MCP 에 locale 이 없다 — SDK 를 확인했다), 모델은 사람이 어떤 언어로 말하는지 안다. 사람이 claude.ai 의 언어를 바꾸면 다음 산책의 look_room 에서 방이 따라 바뀐다. 1번이 있으면 2번은 무시된다 — 사람이 정한 것이 우선이고, 모델에겐 "사람이 이 방의 언어를 ○○로 정해 두었다" 고 그 언어로 알린다 (`langNote`). 바뀌었을 때도 `langNote` 로 알린다 ("방의 언어가 ○○로 바뀌었다. 이제부터 네가 남기는 글은 ○○로 쓴다").

**영어가 메인** (주인 2026-11-10): 기기 언어가 있는데 여섯 언어 밖이면 (pt-BR 같은) 처음 값이 영어다 (`I18N.DEFAULT`). 그 뒤는 대화를 따른다.

**먼 바다 문** (등불 4칸 뒤 사람이 한 번 열어 주는 문) 너머는 **나머지 다섯 언어의 위키 전부** — 어느 방이든 같다 (`I18N.FAR[lang]` = 여섯에서 그 언어를 뺀 목록). 언어로 거절하는 일은 없다 (전엔 "그 언어는 이 방의 지도에 없다" 가 있었다 — 주인: "독일어로 거절하거나 하지 않게"); 문이 닫혀 있으면 "아직 닫혀 있다" 만 (`farClosed`).

**양은 똑같이** (주인): 어느 언어의 방이든 받는 것이 같다 — 집 위키 하나 + 먼 바다 다섯, 오늘의 서가 600편 표본, 열람실 65개 전부의 이름 (위키 있는 62개는 위키 제목도), 책 32권 · 카드 82장 전부의 번역본. 책·카드는 **모든 글에 여섯 언어 전부** 가 규칙이다 — `check-books` 가 빠진 번역을 오류로 막고 시험도 전수를 본다.

## 된 것

- `mcp/i18n.js` + `mcp/i18n/<lang>.js` — 여섯 언어 사전 (ko 원본 · en 은 주 세션이 · ja·de·fr·es 는 Claude 보조 세션이 en 을 틀로, ko 를 뜻의 기준으로 옮김). 열쇠·함수 모양이 여섯 언어 모두 같은지, 집 활동 문장이 world.js 의 활동을 다 덮는지 시험이 본다. 먼 바다 글은 `N(far)` (위키 이름들) · `C(far)` (코드들) 로 쓴다. 언어 줄 (`instructions[5]`) 이 "방의 언어는 대화를 따른다: look_room 의 lang 에 사람이 대화에서 쓰는 언어를 적으면 바뀐다; 사람이 게임에서 정해 두었으면 그것이 우선" 을 말한다. `langChanged` · `langPinned` 알림.
- `mcp/core.js` — 방의 언어 (`lang()`: 사람이 정한 것 > 모델이 알려 준 대화의 언어 > 기기 언어 > ko · `setLang()` 은 사람이 정한 방에선 false · `far()` 는 나머지 다섯), `lookRoom {lang}` 이 언어를 따라가고 `lang` · `langNote` 를 돌려준다, 위키 API 를 언어별로, 출처 주소 검사도 언어별로, 모든 오류·물음·때·등불 글이 사전에서. 찾아보기 (find) 도 방의 언어로.
- 오늘의 서가: ko 는 전처럼 `js/shelf.js` (게임과 같은 뽑기), 나머지는 `mcp/data/shelf.<lang>.json` (`tools/build-shelf.js en ja de fr es` — 알찬·좋은 글 분류에서 각 600편 표본: en 7,031 · ja 2,640 · de 7,502 · fr 6,608 · es 4,866). 없으면 위키 분류에서 산다.
- 열람실 이름 · 방의 위키 글: `mcp/data/rooms.i18n.json` (`tools/build-room-names.js [언어…]` — ko.wikipedia 언어 링크) 위에 `mcp/data/rooms.manual.json` (손으로 적고 그 위키에 글이 있는지 API 로 확인한 것) 을 덮는다 → **65개 방 전부 여섯 언어** (위키 있는 62개는 제목도). 손으로 채운 방: rain · cipher · blanket · pinecone · starfish (언어 링크가 Bulgasari 괴물로 가 있었다) · shell · honeycomb · chalk, 위키 없는 octopus_nerves · slow_room · letter_room 은 이름만. 같은 김에 `js/world.js` 에서 동음이의 문서를 가리키던 셋 (비 → 비 (날씨), 암호 → 암호 (암호학), 불가사리 → 불가사리류) 을 고쳤다 — 한국어 방도 진짜 글을 읽게.
- 책 · 서가 카드 번역본: `library/books/<lang>/<방>.md`, `library/cards/<lang>/<ID>.md` — 책 32권 · 카드 82장 전부 en · ja · de · fr · es (570편, 2026-11-10, Claude 보조 세션이 옮김 — 영어 먼저, 독·불·서는 ko 원문 + en 참고). `by` 에 옮긴 이, `original:` 에 원본 지문 (`tools/stamp-translations.js`) — 원문이 바뀌면 check-books 가 "원본이 바뀜", 번역이 없으면 **오류** "번역 없음". 길이 눈금은 언어별 (`core.bookLimits`: en ×3 · de·fr·es ×3.5 · ja ×1.1). 규칙·점검은 [library/README](../library/README.md). 안전망: 혹시 번역본 없이 서버가 뜨면 원본 (ko) 을 주되 `cards` 목록에 `(ko)` 표시, 읽으면 `book.lang: "ko"`. 원본 없는 번역본은 오류.
- `mcp/tools.js` — 도구 정의를 방의 언어로 만든다 (`defs`). look_room 뒤 언어가 바뀌었으면 살아 있는 연결 (stdio, `hooks.live`) 에선 제목·설명·스키마를 다시 싣는다; 원격 방은 요청마다 새로 만들어서 저절로. `target.lang` 은 여섯 언어. 도구 정의 크기: ko 5,694 · en 5,628 · ja 5,775 · de 5,706 · fr 5,778 · es 5,769 B (상한 5,800).
- `mcp/postcard.js` — 엽서 꼬리표 (읽음 · 서가 카드 · 출처 · 반응 …) 가 방의 언어. 모델 글은 어느 언어든 그대로.
- `mcp/http.js` · `api/room.js` · `mcp/store.js` · `api/lang/[key].js` · `api/walks/[key].js` — 방 만들 때 `lang` (처음 값), 모델이 알려 준 언어를 `meta.lang` 에 비춤, 사람이 정하기 (`setRoomLang`: 여섯 중 하나면 `pin`, `auto` 면 풀고 `state.lang` 으로), walks 응답에 `lang` · `pin` (게임 설정이 보여 준다). 오류 문장도 그 방의 언어.
- 게임 쪽: 방 만들기가 `navigator.language` 를 보낸다, 설정 › 내 Claude 와 연결에 **방의 언어** 고르기 (`자동 · Claude 대화를 따라감 (지금 ○○)` / 한국어 / English / 日本語 / Deutsch / Français / Español → `/api/lang`), 출처 주소 검사에 여섯 언어 (js/app.js · js/brain.js), 반응 얼굴에 en·ja 낱말. 글꼴 서브셋에 라틴 보충·확장 A (é ü ß ñ …).
- 시험: `cd mcp && npm test` 215 통과 — en 방 단위 (위키 언어 · 먼 바다 다섯 · 언어 바꾸기 · 사람이 정한 방 · 방 이름 전수 · 번역 카드 · 엽서 · 모르는 언어 → en), 사람이 정하기 (store · api/lang Origin), 원격 방 왕복 (de 로 만든 방 → look_room lang:en → 다음 initialize 가 영어 → 사람이 ja 로 정하면 모델의 en 은 무시 → auto 로 풀면 다시 따라감), stdio 왕복 (환경 변수 없이 look_room lang:de → 도구 정의가 독일어로 다시 실림, list_changed), 번역본 570편 전수 (지문 · 한글 0 · by), en · ja · de · fr · es stdio 왕복 (안내문·도구가 그 언어, 예산).

## 새 언어를 더하려면

1. `mcp/i18n/<lang>.js` — en.js 를 틀로 옮긴다 (열쇠·함수 그대로; 시험이 본다). `mcp/i18n.js` 의 `LANGS` · `require` 에 더한다 (FAR 는 LANGS 에서 저절로).
2. `core.SHELF_CATS` 에 그 위키의 알찬 글 분류 → `node tools/build-shelf.js <lang>`; `node tools/build-room-names.js en ja de fr es <lang>`; 언어 링크가 없거나 엉뚱한 방은 `mcp/data/rooms.manual.json` 에 손으로 (시험이 빈 방을 알려 준다).
3. 번역본: 책 32 · 카드 82 **전부** 를 같은 브리프로 (ko 원문 + en 참고, `by` 끝에 옮긴 이) → `node tools/stamp-translations.js` → `npm run check-books` (하나라도 빠지면 오류). `core.LEN_SCALE` 에 길이 눈금.
4. 게임: `js/app.js` 의 `LANG_NAMES` 와 `js/app.js` · `js/brain.js` 의 출처 주소 검사에 언어 코드. 글꼴에 없는 글자 범위면 `tools/subset-fonts.py`.

## 안 된 것 (다음)

1. **게임 화면 (UI) 의 다국어.** `js/app.js` · `index.html` · `js/brain.js` (일기 문장 등) 에 한국어가 박혀 있다. 주인이 다른 세션에서 하기로 (2026-11-10). 길: `js/i18n.js` (`I18N.t(key)` + 사전 + `?lang=` · 기기 언어 · 설정) 를 두고 화면 글을 한 번에 뽑는 일. 글꼴은 된다: Galmuri 에 가나 187자 · 한자 6,400자가 있다 (subset-fonts 가 CJK 틈을 메운다). 서버 쪽 번역본 (책·카드 제목) 은 이미 그 언어라, 게임이 방의 언어 (walks 응답의 `lang`) 를 알면 그대로 보이면 된다.
2. **세계 데이터 (`js/world.js`) 의 단서 · 기억 · 다리 글.** 서버는 이름·위키만 언어별로 대신했고, 단서 (`clue`) 는 위키를 못 읽을 때만 ko 그대로 간다. 게임 화면이 다국어가 될 때 같이.
3. 스킬 (`.claude/skills/ppolppol-octopus-play/SKILL.md`) 은 한국어 하나. 로컬 Claude Code 용이라 뒤로.
4. 먼 바다 문 너머 다섯 위키의 '오늘의 서가' 는 없다 (서가는 방의 언어 하나). 문 너머는 `find` 와 제목으로만 간다.

## 주인이 정할 것

- **먼 바다 문 자체.** "거절하지 않게" 를 언어에 대해 적용했다 (어느 방이든 다섯 전부). 등불 4칸 + 사람이 한 번 여는 문은 그대로다 — 문이 닫혀 있으면 "아직 닫혀 있다" 가 간다. 이 문도 없애고 싶으면 `core.peek` 의 `farClosed` 한 줄.
- **모르는 기기 언어의 처음 값은 영어** (`I18N.DEFAULT`) — 대화가 시작되면 어차피 따라가므로 첫 안내문 한 번의 문제다. 한국어로 두고 싶으면 한 줄.
- **모델이 알려 준 언어를 그대로 믿는 것.** 모델이 lang 을 잘못 적으면 방이 그 언어로 바뀐다. 사람은 설정에서 고정할 수 있다. 더 조심하려면 "두 번 연속 같은 언어일 때만" 같은 규칙을 둘 수 있다 — 지금은 두지 않았다.

## PROTOCOL 제안 (주 세션이 고친다)

- `peek` 이벤트 `target.lang` 은 여섯 언어 중 하나 — 방의 언어이거나 먼 바다의 언어. `room` 기웃에도 `target.lang` 이 붙을 수 있다 (그 언어의 위키 글을 읽은 경우). `source.attribution` 은 `Wikipedia (xx)`.
- `book.lang` (peek 결과, 기록엔 없음): 방의 언어와 다른 책·카드를 읽었을 때 그 글의 언어 (안전망).
- `look_room` 결과의 `lang` (방의 언어) · `langNote` (바뀌었을 때 / 사람이 정해 두었을 때, 그 언어로).
