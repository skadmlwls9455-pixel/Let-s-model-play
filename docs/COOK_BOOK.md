# 요리 수첩 · 새 요리 다섯 · 새 단계 여섯 (7차, 11-21)

> 주인 말 (11-21): 조리대를 누르면 **레시피 북**이 먼저, 단계는 **진짜 요리하듯 잘게**, 왼쪽 위 **단계 줄은 뺀다**, 끝은 '다시' 대신 **문어 부르기**, 스티커는 **전부 크게**.
> 이 문서는 7차에 바뀐 것만 적는다. 엔진 바탕 (시계 · 저장 · 배치 · 소리 층) 은 `docs/COOK_PROTO.md` 그대로다.

## 2. 요리 (수첩에 나오는 다섯)

| id | 이름 | 단계 (종류 @ 자리) | 하루 효과 |
|---|---|---|---|
| `jeon2` | 해초전 | 썰기 3줄 @도마 (해초 · 파) → 젓기 3바퀴 @조리대 → 붓기 @화구 → 뒤집기 @화구 (종이 울림) → 열십자 썰기 @도마 | 반짝이 |
| `gyeran` | 계란말이 | 달걀 깨기 (3개 x 두 번 톡) → 젓기 3 → 붓기 @화구 (네모 팬) → 말기 3번 (위로 쓸기) → 썰기 3줄 | 방울 |
| `jumeokbap2` | 주먹밥 (세모) | 밥 담기 (주걱 끌기 3번) → 깨 뿌리기 (문지르기) → 젓기 2 → 모양 잡기 (3곳 x 두 번 톡) → 김 붙이기 (끌기) | 별 |
| `kkochi2` | 과일 꼬치 (시럽) | 씻기 (문지르기) → 썰기 2줄 → 꼬치에 끼우기 (끌기 3, 차례로) → 시럽 입히기 (젓기 2 @화구) | 꽃잎 |
| `cake` | 딸기 케이크 | 달걀 깨기 → 젓기 3 → 붓기 (틀) → 굽기 (오븐) → 크림 바르기 (문지르기) → 딸기 올리기 (끌기 3) | 색종이 |

- 처음부터: `jeon2` · `gyeran` · `jumeokbap2`. `kkochi2` · `cake` 는 게임이 `ctx.unlocked` 로 열어 준다 (카페 선물 · 예전에 꼬치를 만든 사람). 따로 연 `cook.html` 은 전부 열려 있다.
- 실패 · 점수 · 시간 제한 없음: 진행은 내려가지 않고, 동사 단추 (키보드 Enter) 는 어느 단계든 세 번 안에 끝낸다. 굽기 정도 (보들 · 노릇 · 바삭) 는 고르는 것일 뿐 어느 쪽도 같은 대접이다.
- 냄비 해시는 요리마다 따로: `COOK.tuneOf(id)` = 단계 목록 + `NUM` 의 해시. 단계나 수치를 고치면 그 요리의 하다 만 냄비만 `potOld` 로 간다.
- 모양 (`look`): 새 요리는 **단계마다 하나** — `{ v: 2, s: [단계별], plate, band? }`. `band` (0~2) 는 뒤집기 · 굽기가 있는 요리에만 (해초전 접시 그림의 장을 고른다). 200 바이트 안쪽.

## 3. 새 단계 여섯 (`COOK_STEPS.NUM`)

| 종류 | 손짓 | 끝 | 단추 한 번 | 사건 (소리 act) |
|---|---|---|---|---|
| `stir` | 그릇 가운데를 돌며 끌기 (어느 쪽이든, 찌그러져도) | 누적 각도 = N 바퀴 | 한 바퀴 | `turn` 4분의 1바퀴마다 (`stir`) |
| `pour` | 아무 데나 누르고 있기. 떼면 멈출 뿐 | 누른 시간 합 2.4초 | 3분의 1 | `pour` 켜짐/꺼짐 (`pour`/`quiet`) · `fill` 3번 |
| `drag` | 재료를 자리로 끌기. 28px 안에 들면 붙는다. 딴 데 놓으면 제자리로 | 다 놓음 | 다음 것 하나 | `lift` · `place` (`place`) · `back` |
| `rub` | 음식 위를 문지르기 (8x6 칸, 손가락 둘레 14px) | 80 % 덮이면 나머지는 저절로 | 3분의 1 | `rub` (`scrub`) · `coat` 3번 |
| `swipe` | 위로 짧게 쓸기 N번 (뒤집기의 쓸기 판정) | N번 | 한 번 | `roll` (`flip`) |
| `bake` | 톡 = 불 켜기. 3초마다 보들 → 노릇 (종) → 바삭에서 기다림. 0.6초 뒤부터 톡 = 꺼내기 | 꺼냄 | 켜기 / 꺼내기 | `heat` (`clink`) · `band` · `out` (`lift`) |

- 붓기는 시간으로 센다: 채움 = 모은 ms + (지금 − 누른 때). 어느 프레임률에서도 끝나는 ms 가 같다.
- 진동은 주인이 정한 셋만: 4분의 1바퀴 · 놓기 = 톡 (`tap`), 말기 = 뒤집기 (`flip`), 썰기 (`cut`). 붓기 · 문지르기 · 종 · 접시 · 수첩에는 없다.
- 소리: 녹음된 `stir` · `place` · `lift` · `back` · `clink` 를 쓰고, `pour` · `scrub` 둘은 `js/audio.js` 가 파일 없이 만든다 (종소리처럼). `simmer` 는 보내지 않는다 (맛보기 스티커가 뜨므로).
- 처음 보는 손짓은 유령 손이 한 번 보여 준다 (돌리기 · 누르고 있기 · 옮기기 · 문지르기 · 위로 쓸기 · 톡). 5초 동안 진행이 없으면 한 번 더. `seen` 은 16개까지 (전엔 8).

## 4. 화면

- **수첩이 첫 화면.** 요리를 정해 주지 않았고 (`recipe` 없음) 끝낸 단계가 있는 냄비도 없으면 수첩이 펼쳐진다 (표지 → 펼침 3장면, 움직임 줄이기면 바로). 한 쪽에 요리 하나: 큰 완성 그림 · 재료 · 단계 그림문자 · 하루 효과 · 만든 적 있으면 도장. 글자 · 숫자는 없다 (이름은 `aria-label`, 대화상자는 '요리 수첩').
- 넘기기: 옆으로 끌기 · 아래 책갈피 다섯 · 좌우 화살표 키. **요리 그림을 누르면 시작.** 잠긴 요리는 그림자 + 커피잔이고 누르면 살짝 흔들릴 뿐이다. 마지막에 만든 요리 쪽이 먼저 펼쳐진다.
- 수첩은 캔버스에 그린다 (어느 배율에서도 또렷). 그 위에 보이지 않는 진짜 단추 여섯 (그림 하나 + 책갈피 다섯) 이 놓여 키보드와 화면 낭독기가 닿는다.
- 고르기 전에는 판도 냄비도 만들지 않는다. 끝낸 단계가 있는 냄비는 수첩을 건너뛰고 바로 이어진다 (옛 규칙 그대로).
- **단계 줄 없음.** 진행은 음식이 보여 준다 (손댈 때마다 달라지고, 자리가 옆으로 미끄러진다).
- **끝 단추 둘** (접시가 놓이고 0.45초 뒤, 0.9초부터 눌림): '문어 부르기' (80px, 320 폭에선 72) 와 '식탁에 두기' (60px). 게임이 부를 수 없다고 하면 (`ctx.canCall` 거짓) '식탁에 두기' 하나만 크게. 누르면 `serve` 를 알리고 부엌이 닫힌다. '다시' 는 없다 — 조리대가 수첩을 다시 연다.
- 스티커: 단계 줄이 빠진 맨 윗줄에서 시작하고 한 픽셀이 기기 픽셀 `floor(4 x 배율)` 개까지 (전엔 3). 360 폭에서 128px (전엔 96), 320x568 에서도 112px 로 보인다 (전엔 안 보였다). 오른쪽 것은 닫기 단추 왼쪽에서 멈추고, 음식 줄 (무대 44행) 위에서 끝난다.

## 5. 게임과 주고받는 말 (`{ ppolCook: ... }`)

| 방향 | 이름 | 내용 |
|---|---|---|
| 게임 → 부엌 | (주소) `&ctx=` | 첫 로드: `{ canCall, unlocked: [id...] }` 를 JSON 으로 |
| 게임 → 부엌 | `open` | `{ kbd, recipe?, ctx? }`. `recipe` 가 있으면 수첩 없이 그 요리 |
| 게임 → 부엌 | `ctx` | `{ canCall }` — 언제든 (결과를 받은 뒤 다시 보내면 끝 단추가 따라 바뀐다) |
| 부엌 → 게임 | `result` | 그대로 (요리마다 한 번, 일곱 칸) |
| 부엌 → 게임 | `serve` | `{ id, mode: 'call' \| 'table' }` — 끝 단추를 눌렀을 때, `close` 바로 앞. 닫기 단추로 닫으면 안 보낸다 |

게임 안인데 `ctx` 가 없으면 `{ canCall: false, unlocked: 처음 셋 }` 으로 본다. `COOK.open` 옵션: `ctx` · `host` · `onServe` · `book: false` (옛 방식으로 바로 열기, 주소 `?book=0`). 시험용: `COOK.pick(id)` · `COOK.setCtx({ canCall })` · `COOK.live().book / .end`.

- 새 요리의 요리별 스티커 대본은 없다 (공통 규칙만 쓴다).
