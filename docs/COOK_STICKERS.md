# 요리 반응 스티커 (COOK_STICKERS)

> 11-08. 요리 놀이(카드 7, 놀이방 부엌) 하는 동안 판 가장자리에 **요리사 모자 쓴 문어 스티커**가 톡 떴다 사라진다. 방송 이모트 세트처럼 따봉·감동·만세 같은 반응 19종.
> 요리 순간(재료 떨어뜨림·합쳐짐·가득·완성·차리기…)마다 **자동으로** 뜬다. 요리마다 '요리 스크립트'를 두어 그 요리의 특정 순간에 특정 스티커가 뜨게 할 수 있다.

## 움직이는 스티커

움직여야 뜻이 사는 것만 칸 몇 개짜리 스트립으로 만든다. 지금은 여섯: **짝짝** (맞닿음↔벌림) · **휘휘** (국자 오른쪽↔왼쪽) · **꾸벅** (졸기↔숙임, 느리게) · **퓻** (퍼짐→뿜음→퍼지는 중, 빠르게) · **만세** (번쩍↔내림) · **두근** (분홍이 차올랐다 빠짐). 나머지 13종은 멈춘 그림이 더 이모트답다.

- 그림: `tools/ui-art/cook-stickers.js` 의 `def(id, …, draw, frames)` — `frames` 배열의 칸 0 은 정지 그림과 **같아야** 한다 (검사가 픽셀까지 본다).
- 파일: `assets/stickers/cook/<id>_anim.png` (32×칸 수 · 32), manifest `sticker.cook.<id>.anim` `{ frames, cell: 32 }`. 정지 그림 `<id>.png` 도 그대로 있다.
- 런타임: `CATALOG[id].anim = 칸 수`, `fps` (없으면 4). 칸 단위로 톡톡 넘긴다 (CSS `steps`, 보간 없음). 1.4 초 머무는 동안 짝짝은 세 번쯤, 꾸벅은 한 번 반쯤.
- 모션 줄이기면 정지 그림(칸 0)을 띄운다. 스트립을 못 받으면 정지 그림으로, 그것도 없으면 지운다.

## 자동 발동

순간 이름은 **진짜 부엌 놀이** (`js/cook.js`, docs/COOK_PROTO.md §8) 가 소리 훅 `AUDIO.on('cook', { act, … })` 으로 보내는 act 그대로다.
(11-08 첫 판은 카드 7 의 옛 계획 '재료 떨어뜨려 합치기' 를 보고 `drop`·`merge`·`full` 과 가짜 요리 6개를 두었다. 진짜 놀이는 고르기 → 톡톡 → 굽기·뒤집기 → 썰기 → 접시라서 11-10 에 전부 바꿨다.)

잇는 법은 둘 중 하나:

```js
COOK_STICKERS.listenAudio();   // (가) cook.js 를 고치지 않는다 — 그 소리 훅을 한 겹 감싸 같은 act 를 듣는다. 원래 소리는 그대로
window.COOK_STICKERS && COOK_STICKERS.cue(act, detail);   // (나) cook.js 가 소리 훅 옆에서 직접 (그러면 (가) 는 쓰지 않는다 — 둘 다 하면 두 번 뜬다)
```

`css/cook-stickers.css` · `js/cook-stickers.js` 를 `js/cook.js` 뒤에 싣는다. 스티커는 부엌 무대 (`#cook-dlg .ck-stage`) 의 **위쪽 두 모서리**에 ×2 로 뜬다 (팬 · 손짓 안내 · 단계 이름을 가리지 않는다).
통합 브랜치의 진짜 `cook.html` 에 붙여 한 판을 돌린 캡처: `tests/evidence/cook-stickers/real-cook-1.png` · `real-cook-2.png`.

| act | 언제 | detail | 기본 스티커 |
|---|---|---|---|
| `pick` | 조리대에서 소품을 고름 (새 판) | `{ dish }` | 빼꼼 |
| `tap` | 톡톡 한 번 | `{ i }` 0~8 | 첫 톡 = 바빠 · 가운데(4) = 짝짝 |
| `sizzle` | 불 켬 · 굽기가 바뀜 | `{ band }` 0 · 1 · 2 | 불 켬 = 휘휘·솔솔 · 노릇 · 바삭 = 솔솔·빼꼼 (두 굽기가 같은 묶음) |
| `flip` | 뒤집음 | `{ band }` | 만세·깜짝·퓻·따봉 (어느 굽기든 같다) |
| `cut` | 썰기 한 줄 | `{ i }` 0~1 | 첫 줄 = 바빠 |
| `step` | 단계 하나 끝 | `{ kind }` | 따봉·짝짝 (가끔) |
| `quiet` | 소리 내리기 | — | 없음 |
| `done` | 접시 공개 | `{ dish }` | 한 접시·다 됐다·감동·두근 |
| `stir` · `simmer` · `place` | 조각 2 (cook.js 가 아직 안 보냄) | — | 휘휘 · 맛보기 · 솔솔 |
| `serve` · `eat` · `idle` | 본 게임 쪽: 식탁에 차리기 · 냠 · 한참 손 안 댐 | — | 한 접시 · 냠 · 꾸벅 |

고르는 순서:

1. **요리 스크립트** `RECIPES[요리].cues` — 위에서부터 보고 먼저 맞는 줄 하나.
2. 없으면 **공통 규칙** `RULES`.
3. 줄의 `pick` 이 배열이면 판 시드(FNV-1a + mulberry32)로 고른다. `chance` 도 같은 시드.

조건 키: `on`(act) · `is: { 키: 값 }` · `atLeast` · `atMost` · `nth` · `every` · `once` · `force`.
스티커 사이 쉬는 틈 0.9초, 화면에 최대 3장 (부엌은 자리가 둘). `pick` · `flip` · `done` · `serve` 는 틈과 상관없이 뜬다.
요리 스크립트는 `pick` · `done` 의 `dish` (요리 id) 로 정해진다.

### 요리 스크립트

```js
jeon: { name: '해초전', cues: [
  { on: 'tap', is: { i: 8 }, pick: 'clap', force: true },   // 반죽 다 폄
  { on: 'flip', pick: ['cheer', 'shock'] },                 // 휙 뒤집음
  { on: 'cut', is: { i: 1 }, pick: 'thumbs' },              // 열십자 다 썲
  { on: 'done', pick: ['heart_plate', 'star'] }             // 접시 공개
] }
```

지금 있는 요리는 해초전 하나다. 조각 2 가 미역국 · 톳 주먹밥을 더하면 그 요리 id 로 `RECIPES` 에 한 덩이씩 더한다 (검사가 act 이름·스티커 id 를 확인한다).

## 지키는 것

- **글자 없음.** 스티커는 그림뿐. 맛 평가·취향 말을 코드가 쓰지 않는다 (카드 7 금지 낱말 검사를 이 파일에도 건다). 대체 글은 그림 설명("엄지 척 하는 요리사 문어 스티커")이지 문어의 말이 아니다.
- **장식이지 문어의 반응 기록이 아니다.** 요리는 주로 문어가 산책 간 동안 하므로, 스티커를 '문어가 지금 이렇게 느꼈다'로 쓰지 않는다. 기록(`COOK_STICKERS.log()`)은 `by: 'demo-rules'` 이고 문어 기록(`trips`) · 두뇌 입력 · 모델 요청에 넣지 않는다 (CORE_LOOP_V2 약속 2).
- **벌 없음.** 굽기(부드럽게·노릇·바삭)는 고르는 것이지 맞고 틀림이 아니다 — 어느 굽기로 뒤집어도, 굽기가 바뀔 때도 같은 묶음에서 뜬다 (11-10 주인: 굽기가 바뀔 때는 노릇 · 바삭 모두 솔솔 · 빼꼼만. 뿅 · 맛보기 · 갸웃 · 진땀은 굽기를 평가하거나 문어가 좋아한다 · 맛봤다고 읽혀서 굽기에서는 저절로 뜨지 않는다). 우는 그림은 '감동'(반짝 눈물)뿐.
- **시드.** 같은 판 id + 같은 순간 순서 = 같은 스티커. 시드 없는 난수 0건 (검사).
- **모션.** 등장 250 ms (6px 아래 → 2px 넘침 → 제자리) · 머묾 1.4 s · 퇴장 180 ms. 픽셀 그림이라 배율 대신 이동. 모션 줄이기(`data-motion="reduce"` 또는 OS 설정)면 투명도만.
- 그림이 안 오면 그 스티커를 지운다 (이모지로 대신하지 않는다). 번들(`dist/`)은 `ASSETS_INLINE['sticker.cook.*']` 를 쓴다.
