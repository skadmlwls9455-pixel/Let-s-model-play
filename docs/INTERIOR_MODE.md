## 0. 한 줄 요약

장면 구석의 **[🪴 꾸미기]**를 누르면 꾸미기 모드가 열린다. 물건을 고르면 옆에 버튼 둘 **[⟳ 돌리기]**(90°씩) · **[✥ 옮기기]**가 뜬다. 그 물건의 **흐릿한 모습(고스트)**이 놓일 자리에 먼저 앉아서 "여기 두면 이렇겠구나"를 보여 주고, 한 번 더 누르면 놓인다. 못 놓는 곳이면 고스트가 **빨간 반투명**이 된다. 평소에는 물건을 **톡 = 쓰기·앉기**, **0.6초 꾸욱 = 바로 옮기기**. 한 손가락으로 **밀면 화면이 미끄러지듯 따라오고**, 줌은 손가락을 따라 부드럽게 움직인다.

## 1. 왜

**주인이 폰으로 해 본 뒤 한 말 (11-05)**

- "가구 꾸미기 버튼은 어디에 있어?"
- "실제로 놓기 전에 흐릿한 형상처럼 떠서, 여기 배치하면 이런 느낌이겠구나 하고 감 왔으면 좋겠어."
- "집꾸미기 버튼 누르면 본격적인 가구 배치 모드로 들어가는 것도 좋고, 아이템 꾸욱 몇 초간 누르면 간편 이동은 가능하게 해 줘."
- "자연스럽게 슥슥 슬라이딩할 때 화면이 안 움직여." (줌은 된다)
- "나갈 때 땅 아래로 슉 떨어지는 거 넘 깜짝 놀랐어." → §6 의 **0단계**로 먼저 고친다.

### 2.4 집에서 기다리기와 같이

- 문어가 산책 중이어도 꾸밀 수 있다. 꾸미기는 '집에서 기다리기' 쪽 놀이 가운데 하나다 (요리 미니게임과 같은 자리, CORE_LOOP_V2 C2).
- 산책 줄은 봉해 둔다 (CORE_LOOP_V2 §3.3).
- [끝내기] 에 숫자 배지를 달지 않는다. 재촉하지 않으려고.
- 문어가 돌아오면 쪽지: "뚜루가 돌아왔어." [보러 가기] 하나 (CORE_LOOP_V2 C4, 11-07). 문어는 문 앞에서 타이머 없이 기다린다. 꾸미는 동안엔 보드 앞까지 오지 않고, 꾸미기 반응도 하지 않는다 (고스트·자리와 엇갈리지 않게). [보러 가기] 를 안 누르고 꾸미기를 이어 하면 다시 만나기(포스터, 돌아온 뒤 대화 두 차례, 결정 18)는 끝내기 뒤에 이어서 나온다 (C5).
- 출발·귀가 의식과 포스터 걸기(`startHang`)가 도는 동안은 [🪴 꾸미기] 가 잠깐 흐려지고, 꾸욱 들기도 받지 않는다 (날아가는 포스터와 자리가 엇갈리지 않게).
- '같이 가기' 동안에는 [🪴 꾸미기] 가 없다. 헤엄 화면이 장면을 덮고, 꾸미기는 기다리기 쪽 놀이다 (CORE_LOOP_V2 §3.2·§3.3).

## 3. 규칙과 수치 — 고스트 미리보기 · 꾸욱 이동 · 카메라

px 는 따로 적지 않으면 CSS px 다. 기본 p=2 에서 **1 아트px = 2 CSS px**.

### 3.1 손가락 문법

| 동작 | 평소 화면 | 꾸미기 모드 | 사진 모드 (PHOTO_AND_FURNITURE §1.5) |
|---|---|---|---|
| 한 손가락 짧게 톡 | 물건 쓰기·앉기 (PHOTO §3.1·§3.6: 소파 = 내가 앉기, 양초 = 켜고 끄기 …), 포스터 열기, 기념품 일기, 문어 = 몸짓 + 기호(? ! ♪ …) | 물건 고르기 / 숨 쉬는 자리를 누르면 고스트가 그리로 | 아무 일 없음 |
| 한 손가락 밀기 (빈 곳에서 시작) | **화면 밀기 + 관성** (§3.4) | 화면 밀기 | 돌리기 (가로 = 옆, 세로 = 위아래) |
| 한 손가락 밀기 (물건·고스트 위에서 시작) | 화면 밀기 | 그 물건(고스트)을 끈다 | 돌리기 |
| 물건 꾸욱 | **0.6초 → 들어 올림** (§3.3) | 필요 없음 (바로 끌 수 있다) | 아무 일 없음 |
| 문어 꾸욱 | 0.35초 쓰다듬기 (그대로) | 그대로 | 아무 일 없음 |
| 두 손가락 벌리기·오므리기 | 줌 (§3.5) | 같다 | 줌 + 밀기. 멈춤 4개 더 (§3.5) |
| 두 손가락 비틀기 | 돌려 보기: 15° 넘게 비틀면 시작, 9° 계단, ±27° (지금 범위 그대로) | **잠김.** 0° 고정이라 자리가 늘 같은 곳에 보인다 | 옆으로 돌기 (같은 손짓이 통하게) |
| 관성으로 움직이는 중에 톡 | 멈추기만 한다. 탭으로 치지 않는다 (iOS 스크롤과 같음) | 같다 | 같다 |
| 마우스 | 왼쪽 끌기 = 밀기, 휠 = 줌, 오른쪽 끌기나 Shift+끌기 = 돌려 보기 | 돌려 보기 잠김 | 왼쪽 끌기 = 돌리기, 오른쪽·Shift 끌기 = 밀기, 휠 = 줌 |
| 키보드 (입력칸에 글을 쓰는 중엔 안 받음) | `+` `−` 줌, 화살표 밀기, `0` 가운데로 | 같다. 자리 칩·[⟳]·[✥] 는 Tab·Enter, Esc 는 고르기 취소 → 한 번 더 Esc 는 끝내기 | PHOTO §1.5 |

- 돌려 보기는 한 손가락에서 두 손가락 비틀기로 **옮긴다.** 주인이 "슥슥 밀면 화면이 움직이길" 원했기 때문이다.
- 비틀기와 핀치가 섞이면, 손가락 거리가 1.1배 바뀌기 전에 15°를 넘긴 쪽이 이긴다. 한 번 정해지면 그 손짓이 끝날 때까지 바뀌지 않는다.
- 캔버스에서 `contextmenu` 를 막는다 (지금은 안 막음). 안드로이드는 꾸욱 누르면 이 이벤트가 오고, 마우스 오른쪽 끌기도 이게 있어야 된다. iOS 는 `-webkit-touch-callout: none`.

| 자리에 붙으면 | 놓일 면에 접촉 그림자를 절반 진하기로 | "여기 놓이면 이렇게 앉는구나"가 가장 잘 읽힌다 |
| 못 놓는 곳이면 (자리 밖, 또는 그 자리에서 안 되는 방향) | 고스트 자체를 팔레트 빨강(#a53030)으로 물들인 체크 25%. 그림자 없음. [여기 놓기]는 흐려진다. X·거절 문구 없음. 손을 떼면 제자리로 | 주인 피드백: 고스트만 보고 "여기엔 안 되는구나"를 안다 |
| 양초 고스트 | 불꽃·빛 무리는 빼고 몸통만. 불빛 미리 보기는 v1 (아래 주의) | |

**고르는 판정**

| 항목 | 값 |
|---|---|
| 자리 톡 | 화면 거리 **32px 안**에서 가장 가까운 자리 (bubble cursor). 문어 몸·창유리는 판정에서 뺀다 |
| 끌기 자석 | **48px 안**의 자리에 붙는다 |
| 끄는 기준점 | 손가락보다 **40px 위**. 손가락이 고스트를 가리지 않게 (마우스는 0, 커서 바로 아래) |
| 끄는 면 | 물건 종류의 면(바닥, 창턱 높이, 보드 면)에 손가락 광선을 맞춘다. 물건이 공중에 뜨지 않는다 |
| 가장자리 자동 밀기 | 끄는 손가락이 장면 가장자리 **32px 안**에 들어가면 그쪽으로 0.1 → 0.4 px/ms 로 천천히 밀린다 |
| 작은 물건 (선반 13px 간격) | 기념품을 고르면 카메라가 선반으로 1.4×쯤 다가간다 (0.3초). 자리 칩과 띠의 ◀ ▶ (한 칸 옆으로 — 방을 오가는 단추가 아니라 자리 한 칸. 픽셀 그림, 글자 기호 아님) 도 같이 둔다 |

**자리 표시 (X 없이. 못 놓으면 빨간 고스트)**

- **고른 물건이 갈 수 있는 자리만 그린다.** 다른 물건의 자리는 아예 안 보인다. 못 놓는 때는 둘뿐이다: 끄는 고스트가 자리 밖에 있을 때, 그 자리에서 안 되는 방향일 때. 그때만 고스트가 빨갛다.
- 빈자리: 1px 모서리 괄호 4개, 픽셀 중심에 맞춤. 1.2초에 한 번 **4프레임으로 숨 쉰다** (결정 13: 2프레임 깜빡임 대신 4~6프레임 움직임). 모션 감소면 점선으로 멈춤.
- 찬 자리: 모서리를 실선으로, ⇄ 글리프 (7×5 px). 놓으면 맞바꾼다. "자리가 없어" 같은 거절 문구는 만들지 않는다.
- 지금 자리: 작은 점 하나.
- 꾸미기는 지금 있는 방만 (11-07). 다른 방의 자리는 꾸미기를 끝내고 문으로 가서 그 방의 화분 단추로 (◀ ▶ 는 없다).

**고른 물건 옆 버튼 둘 (놓기 표준)**

| 버튼 | 하는 일 |
|---|---|
| [⟳ 돌리기] | 고스트가 그 자리에서 시계 방향으로 90° (0 → 90 → 180 → 270 → 0). 4프레임 120ms. **자유 각도는 없다** |
| [✥ 옮기기] | 물건이 고스트가 되어 추천 자리에 먼저 앉는다 (§2.2-5). 그다음은 자리 톡·자리 칩·끌기 |
| 놓이는 곳 | 고른 물건(고스트) 위 오른쪽, 8px 띄움. 화면 가장자리면 왼쪽. 각 44px, 진짜 `<button>`. 고스트를 따라간다 |

- 꾸미기 모드와 꾹 옮기기(§3.3)에 같은 모양으로 뜬다. 꾹 0.6초는 [✥] 를 바로 누른 것과 같다.
- 포스터·기념품은 [⟳] 가 없다 (벽·선반에 붙는 것).
- 자리마다 되는 방향이 있다 (`rots`, §5.1). 안 되는 방향이면 빨간 고스트. 예: 소파는 등이 카메라 쪽이면 안 된다 (PHOTO §3.3).

**약속**

- **놓은 뒤에 문어든 규칙이든 몰래 손보지 않는다.** 미리 본 것과 놓인 것은 같다. (리서치의 "모양은 문어가 정한다" 안은 쓰지 않는다. 주인이 원한 것이 "미리 보고 감 잡기"라서.)
- 끝내기를 누르면 미리 보던 것은 **놓이지 않는다.** 놓기는 늘 한 번 더 누르는 일이다.

### 3.3 꾸욱 눌러 바로 옮기기 (꾸미기 밖)

**대상**: 옮길 수 있는 물건만. 벽·바닥·창·문·등불·상자·보드·선반·커튼(집의 뼈대)에는 링이 뜨지 않는다. 그래서 **링이 뜬다는 것 자체가 "옮길 수 있다"는 뜻**이 된다. 문어가 위에 있는 물건(자는 담요, 문어가 앉은 소파)도 링이 안 뜬다. 내가 앉아 있는 소파는 저절로 일어난 뒤 들린다 (PHOTO_AND_FURNITURE §3.1).

| 시간 | 보이는 것 |
|---|---|
| 0 ~ 0.15초 | 아무것도 없다. 여기서 떼면 톡 = 쓰기·앉기 (`on.propTap`) |
| 0.15초 | 손가락 둘레에 **점 8개 링** (문어 다리, 지름 48px) + 물건에 1px 테두리 |
| 0.15 ~ 0.6초 | 점이 하나씩 켜진다 (한 개에 약 56ms). 여기서 떼면 링이 그리다 말고 사라지고 **톡으로 친다** |
| **0.6초** | 물건이 들린다: 3 아트px 올라오고 (80ms) 세로로 1.06배 눌림. 링은 픽셀 4점으로 톡 터진다. 안드로이드 진동 10ms 는 설정에서 켠 경우에만. 그 물건의 자리만 숨 쉬고, 옆에 [⟳ 돌리기] [✥ 옮기기] (§3.2) |
| 0.6초 전에 10px 넘게 움직임 | 취소 → 그냥 화면 밀기 |

**왜 0.6초인가** (주인은 "몇 초"라고 했다. **정함: 모든 물건 0.6초**, §8 질문 1)

- 폰 기본 길게 누르기는 0.4~0.5초다. 물건 톡에는 이미 뜻이 있어서(쓰기·앉기, 포스터 열기) 실수로 들리지 않게 0.1초 더했다.
- 문어 쓰다듬기(0.35초)와 확실히 다르다.
- 1초가 넘도록 반응이 없으면 사람들은 "안 되나?" 하고 손을 뗀다. 손이 떨리는 사람은 오래 누를수록 10px 를 넘겨 실패한다.
- 길게 누르기가 답답한 건 시간 때문이 아니라 '되고 있는지 모르는 것' 때문이다. 그건 링으로 푼다.
- 나중에 설정: "꾹 누르기: 보통 0.6초 / 느리게 1.0초" 하나만. 값을 물건마다 다르게 하지 않는다 (PHOTO 플레이테스트의 0.7초 안도 쓰지 않는다).

**들린 다음**

- 손을 떼지 않고 끌면 고스트가 자리에 붙고, 손을 떼면 놓인다. 못 놓는 곳이면 빨간 고스트, 떼면 제자리로.
- 움직이지 않고 떼면 든 채로 남는다. 물건 옆에 [⟳] [✥], 아래에 띠: "놓을 자리를 눌러 줘 · 취소" (44px).
- 놓으면 쪽지 "옮겼어 · 되돌리기" 가 4초 뜬다.
- 서랍에 넣고 꺼내기, 맞바꿈 미리 보기의 25% 고스트는 꾸미기 모드와 같다. 다만 서랍은 꾸미기 모드에만 있다.
- 모션 감소여도 링은 남긴다 (진행 정보라서). 톡 터짐과 눌림만 뺀다.

### 3.4 카메라: 밀기와 관성

| 항목 | 값 |
|---|---|
| 따라가기 | 손가락에 **1:1**. 손가락이 간 만큼 장면도 정확히 간다 |
| 밀기 시작 | 8px 넘게 움직이면 (지금 탭 판정과 같은 값) |
| 손 뗄 때 속도 | 마지막 100ms 평균. 떼기 전 80ms 이상 멈춰 있었으면 0 |
| 튕김 최소 속도 | 0.25 px/ms 보다 느리면 그 자리에 멈춘다 (천천히 민 뒤 미끄러지지 않게) |
| 관성 | 매 프레임 `v ← v · e^(−dt / 0.25초)`. 약 '속도 × 0.25초' 만큼 더 간다 |
| 최고 속도 | 2 px/ms (최대 약 500px 미끄러짐. 작은 방이라 iOS 기본 0.5초짜리 감속보다 짧게) |
| 멈춤 | 0.03 px/ms 아래로 떨어지면 |
| 경계 | 방 상자를 화면 축에 투영한 범위 + 여백 12 아트px |
| 고무줄 | 경계 밖에서는 손가락 이동의 40%만, 최대 20 아트px (40px). 손을 떼면 0.25초 동안 ease-out 으로 돌아온다. 관성이 경계에 닿아도 같은 고무줄로 받는다 |
| 1× (방이 거의 다 보임) | 가로는 고무줄만 (손가락을 따라 조금 갔다 돌아온다). 세로로 쓸면 **페이지가 내려간다** |
| 1× 보다 크거나 꾸미기 중 | 가로·세로 모두 장면이 밀린다. 페이지 스크롤은 장면 밖에서 |
| 픽셀 | 위치는 소수로 들고, 그릴 때 지금의 `snapScreen` 이 1 아트px 격자에 맞춘다. 미끄러질 때도 1 아트px 계단으로 움직이고 정확히 픽셀 위에서 멈춘다 |
| 디더 | 움직이는 동안 꺼짐, 멈추고 0.3초 뒤 켜짐 (지금 규칙 그대로. 화면이 반짝거리지 않는다) |
| 프레임 | 밀기·관성 중에는 60fps, 멈추면 지금의 쉬는 속도로 |
| [⌖] 칩 | 가운데에서 화면 1/4 넘게 벗어나면 장면 오른쪽 위에 뜬다 (DIALOGUE_UI §3.2). 누르면 0.3초 만에 가운데로 |
| 의식·입장 연출 | 시작하면 밀린 것을 0.3초 동안 0 으로 되돌린다. 연출 중엔 밀기를 받지 않는다 (문어가 화면 밖으로 나가지 않게). 줌은 된다 |
| 장소가 바뀌면 | (다락 ↔ 바깥 ↔ 옆방) 밀린 것을 0 으로. 장소마다 경계 상자가 따로 있다. 옆 장소가 있는 쪽으로 고무줄 뒤 56px 더 끌고 놓으면 그 장소로 간다 (ROOM_EXPANSION §5.4) |

숫자 감: 360×326 장면, p=2 이면 렌더 타깃이 178×162 다. 줌 1 에서는 보이는 폭 6.6m, 방 대각선 7.1m 라서 수십 px 만 밀리고 고무줄이 걸린다. 줌 2 에서는 보이는 폭 3.3m 라 방 끝까지 밀 수 있다.

## 5. 만드는 방법

### 5.1 자리(슬롯) 모델

자유 배치가 아니라 **정해진 자리**와 **90° 방향**에만 놓는다. 겹침 검사, 문어 길 막힘이 생기지 않는다. 빨간 고스트는 자리 밖이거나 안 되는 방향일 때뿐이다.

| 물건 | 기본 자리 (지금 위치) | 다른 자리 | 생기는 때 |
|---|---|---|---|
| 이끼 화분 `moss` | `sill.3` (지금 화분 자리) | `sill.0` ~ `sill.2`, `crate.top` | 등불 1 |
| 양초 `candle` | `crate.top` | `sill.0` ~ `sill.3`, `shelf.end` (선반이 있을 때. 뒷줄 오른쪽이라 기념품 8칸과 안 겹친다) | 등불 3 |
| 담요 `blanket` | `floor.f` | `floor.c`, `floor.fr` (문어 길 테스트를 통과한 것만) | 등불 4 |
| 소파 `sofa` | `attic:floor.win` (창 아래) | `attic:floor.back` (뒷벽 선반 아래). 크기·방향은 PHOTO_AND_FURNITURE §3.3 | 첫 산책 (PHOTO §3.2) |
| 포스터 `poster:<tripId>` | `board.0` ~ `board.5`. 번호: 윗줄 0~2, 아랫줄 3~5 (첫 핀은 윗줄, TUTORIAL §3.4). **첫날부터 있다** — 보드 전엔 벽이 주인 (아래 예외). 2D 도 6칸(3×2) | (v1) 벽 `wall.0` ~ `wall.1` | 산책 |
| 기념품 `sv:<tripId>` | `shelf.0` ~ `shelf.7` (선반 전에는 `sill.0` ~ `sill.2` = 지금 창턱 기념품 3자리, scene3d 863행) | 순서만 | 산책 |
| 우리 둘 자리 | `attic:hook.door` (문가 벽걸이). 배지 기념 소품 1개 (예: 배웅 종, ACHIEVEMENTS §3.1) | 옆방 '네 선반' `side:shelf.0~2` | 배지 |
| 옆방 (ROOM_EXPANSION §5.2) | 포스터 `side:board.0~7` · 네 선반 `side:shelf.0~2` · 바닥 `side:floor.0~3` (산 가구는 여기만) | — | 방 넓히기 |
| 고정 (뼈대) | 벽·바닥·창·문·등불·상자·보드·선반·커튼·러그 | — | DESIGN §19 |

- 창턱 자리는 4개다: `sill.0`~`2` = 지금 기념품 자리 (z −0.15·0.11·0.37), `sill.3` = 지금 화분 자리 (z 0.9, scene3d 782행). 기본 자리끼리 겹치면 `normalize` 가 처음부터 물건을 밀어내므로 **기본 자리는 서로 달라야 한다** (테스트에 넣는다).
- 상자·러그는 v0 에서 고정이다. 상자를 옮기면 위 자리·양초 빛·문어 자리가 같이 움직여야 해서 v1 로 미룬다.
- 슬롯 하나: `{ id:'attic:sill.2', kind:'floor'|'sill'|'top'|'board'|'shelf'|'hook', label:'창턱 오른쪽', fits:[…], host?:'crate', surface:'wood'|'sill'|'cork'|'cloth', use:[dx,dz], rots:[0,90,180,270] }`.
  - `use` 는 문어가 그 물건을 쓸 때 서는 발치다. 물건을 돌리면 발치도 같이 돈다.
  - `rots` 는 그 자리에서 되는 방향이다. 테스트가 고른다: 돌린 물건이 벽·다른 자리·문어 길과 안 겹치고, 앉는 가구는 등이 카메라 쪽(카메라 ±40° 밖)이 아닐 것. 포스터·기념품·벽걸이 자리는 `[0]`.
  - id 앞에 장소 이름을 붙인다 (`attic:`·`side:`). 장소가 늘면 표만 더한다.
  - 자리는 **주인(host)이 있을 때만** 있다 (선반 자리는 선반이 생긴 뒤). **예외: 포스터 `attic:board.0~5`** 는 첫날부터 있다. 보드(등불 5)가 생기기 전엔 벽이 주인이다 (지금도 포스터는 보드 없이 같은 자리에 붙는다).
- **문어 자리가 물건을 따라간다.** `anchorPos('blanket')` = 담요 자리 + `use`. 지금 `ANCHORS` 는 기본값으로만 쓴다. 담요를 옮겼는데 문어가 옛 자리 맨바닥에 누우면 꾸미기가 문어에게 아무 의미 없다는 신호가 된다.
- 좌표는 장면마다 따로 둔다 (scene3d `SLOT_POS`, scene2d `SLOT_XY`). 빌드 때 `snapPos` 로 맞춘다. look-shots 로 화면을 보며 맞춘다.
- 테스트로 미리 막는다: 바닥 물건 × 바닥 자리 모든 조합에서 문어 자리와 자리를 잇는 직선이 물건 바닥 면적을 지나면 그 자리를 표에서 뺀다 (지금 `moveTo` 는 직선으로 걷는다).

### 5.2 저장

```js
S.room.layout = {              // 없거나 비면 = 전부 기본 자리. 옛 저장은 지금 화면 그대로 열린다
  place: {                     // 물건 → 자리 + 방향. 좌표는 저장하지 않는다
    candle:              { slot: 'attic:sill.2',    rot: 0,  by: 'user',       at: '…' },
    sofa:                { slot: 'attic:floor.win', rot: 0,  by: 'user',       at: '…' },
    blanket:             { slot: 'attic:floor.c',   rot: 90, by: 'user',       at: '…' },
    'poster:trip_k7x2':  { slot: 'attic:board.0',   rot: 0,  by: 'user',       at: '…' },
    'sv:trip_a':         { slot: 'attic:shelf.3',   rot: 0,  by: 'demo-rules', at: '…' },
    'poster:trip_old':   { slot: 'drawer',          rot: 0,  by: 'user',       at: '…' }
  }                            // rot: 0 | 90 | 180 | 270. 없으면 0 (옛 저장)
}
S.room.layoutLog = [           // 최근 50개만
  { id, item, from, to, rot: [이전, 이후] | undefined, swap: 'poster:…' | undefined,
    kind: 'move' | 'turn' | 'undo' | 'suggest' | 'own',  accepted: true | false | undefined,
    by: 'user' | 'demo-rules' | 'model' | 'fallback',  session: 'decor_…',  at }
]
```

- **`by` 이름은 MODEL_VOICE 를 따른다** (`user`, 리서치·설계 B 의 `human`/`oct` 는 쓰지 않는다).
- 이 기록은 데이터다. 화면에 쌓이는 로그는 없다 (DIALOGUE_UI). 사람에게 보이는 것은 집 줄과 다시 보기뿐이다.
- 기념품도 `place` 에 넣는다. 선반 순서는 자리 번호에서 나온다. 그래야 "사람이 놓은 기념품은 문어가 안 옮긴다"가 자리마다 지켜진다.
- 버전 `v` 는 2 그대로. `normalize()` 에 선택 칸으로 덧붙인다.
- **`normalizeLayout()` 규칙** (순수 함수, 두 번 돌려도 결과가 같다):
  1. 없어진 자리 id → 그 물건의 기본 자리.
  2. 한 자리에 물건이 둘 → 늦게 온 쪽을 기본 자리로. 기본 자리도 차 있으면 허용 자리 중 첫 빈 곳, 그것도 없으면 서랍.
  3. 아직 없는 물건 (등불 칸이 모자람) → 무시하되 지우지 않는다.
  4. 앨범에 없는 포스터·기념품 → 칸을 비운다.
  5. 물건 수는 줄지 않는다 (방 + 서랍 = 전부).
  6. 그 자리에서 안 되는 방향 (`rots` 밖) → 그 자리의 첫 방향.
- **되돌리기**: 기록의 마지막 한 줄을 거꾸로 실행한다. 이번 꾸미기 안에서 같은 물건을 여러 번 옮기면 한 줄로 합친다 (three.js editor 의 명령 합치기와 같은 생각).
- **새 포스터가 오면** (ROOM_EXPANSION §5.4 와 같은 순서):
  1. 빈 칸에 건다. `attic:board.0` … `.5` → 옆방이 있으면 `side:board.0` … `.7` 순서.
  2. 빈 칸이 없고 방 넓히기 **공사 중**이면 천에 기대 둔다 (`build.leaning`, 보이는 건 3장까지, 나머지는 서랍).
  3. 아니면 `by!=='user'` 인 포스터 가운데 가장 오래된 것을 **보이게** 바꿔 건다: 문어가 떼어 말아 서랍(앨범)에 넣고 그 칸에 새 것을 건다 (처음 3번만 다 보여 주고 그 뒤엔 빠르게). 다른 칸은 안 움직인다.
  4. 다 사람이 건 칸이면 새 포스터는 서랍에 들어가고 쪽지 "새 포스터는 서랍에 있어 · 걸기".
  5. 문어(모델)가 걸지 않기로 고른 포스터(`hang:false`)는 어느 경우에도 걸지 않는다.
  - 아무도 안 꾸민 저장에서는 지금과 똑같이 '마지막 6장'이 걸린다. `startHang` 은 `slotOfPoster(id)` 로 날아갈 칸을 받는다.
- **집에 있는 날 `rearrange` 활동** (`js/app.js` 923~924행, 지금은 `posterOrder` 를 바로 맞바꿈): `by:'demo-rules'`, `kind:'own'` 기록 한 줄로 바꾸고, `by:'user'` 자리는 건드리지 않는다. 활동은 출발 때 정해지므로, 두뇌에 '사람이 안 건 포스터 수'를 넘겨 2장 미만이면 `rearrange` 를 후보에서 뺀다 (지금 `requiresPoster` 와 같은 방식, world.js 1261행). 그래야 일기에 "자리를 바꿨어"가 적혔는데 실제로는 못 바꾸는 일이 없다. 그래도 귀가 전에 사람이 다 옮겨 버렸으면 그날은 `fallback` 으로 기록하고 '골랐다'고 연출하지 않는다.

### 5.3 엔진 (scene3d)

**손가락 상태기계 하나로 묶기.** 지금은 `press`, `pinch`, 한 손가락 `yawDrag` 세 갈래다. `GEST = { mode }` 하나로 묶는다 (`G` 는 이미 걸음새 상태로 쓰고 있다, scene3d 931행).

| 시작한 곳 | mode | 하는 일 |
|---|---|---|
| 문어 위 | 쓰다듬기 대기 | 350ms 또는 8px → 쓰다듬기 (지금 그대로) |
| 물건 위 (평소) | 들기 대기 | 0.15초 링, 0.6초 들기, 그 전에 10px → 밀기, 그 전에 떼면 톡 (`on.propTap`·포스터 열기 등) |
| 물건·고스트 위 (꾸미기) | 끌기 대기 | 8px → 끌기, 그냥 떼면 고르기 |
| 자리 근처 (꾸미기, 고른 뒤) | — | 32px 안 가장 가까운 자리로 고스트 이동 |
| 빈 곳 | 밀기 | 밀기 + 관성 |
| 두 번째 손가락 | 핀치 / 비틀기 | §3.1 |
| 관성 중 누름 (0.05 px/ms 넘음) | — | 멈추기만 |
| 어디든 (사진 모드) | `photo` | 한 손가락 = 돌리기, 톡·꾹 없음 (PHOTO §1.5) |

- **고를 수 있는 물건**: 소품 메시(moss, candle, blanket, sofa)는 `tapItems()` 에 넣지 말고 `pick()` 에서 **문어 판정 구 다음**에 따로 본다 (문어 몸·포스터·기념품 → 문어 판정 구 → 소품 → 창). 지금 `pick()` 은 `tapItems` 에 맞으면 포스터·기념품이 아닌 것을 전부 문어로 돌리고(scene3d 1868행), 담요 위 문어 근처 톡은 판정 구가 받는다. 소품을 판정 구보다 앞에 두면 그 톡이 문어에게 안 가서 T2 가 바뀐다. 소품 짧은 톡 = `on.propTap` (쓰기·앉기, PHOTO §3.1·§3.6). 꾸미기 중에는 판정 구를 빼므로(T9) 소품이 바로 잡힌다.
- **밀기**: `PAN = { off: Vector3, v:[vx,vy], samples:[] }`. `camTargetNow()` 의 기본 타깃에 `PAN.off` 를 더한다 (입장 연출 중, `focus:'oct'` 일 때는 0). 손가락 이동은 카메라 면 축으로 바꾼다 (`−dx/p·pw·_r + dy/p·pw·_u`). 경계는 방 상자 8꼭짓점을 `_r`, `_u` 축에 투영해서 구한다 (돌림이 바뀌면 다시 계산, 내적 8번).
- **줌**: `resize()` 를 둘로 나눈다. 크기가 바뀔 때(렌더 타깃 `setSize`)와 줌만 바뀔 때(`applyZoom`: 프러스텀, `S.N`, `S.pw`, `placeCamera`, 비·커튼·먼지·바깥 다시 스냅). 핀치 중 매 프레임 `renderer.setSize` 를 부르면 캔버스 버퍼를 다시 잡아서 끊긴다.
  - 호환: `setLook({zoom:i})` 는 옛 단계를 N 으로 받는다 (0→27, 1→34, 2→41, 3→54). look-shots 는 그대로 돈다. `stats().zoom` 은 N ÷ 기본 N.
- **`touch-action` 바꾸기**: 캔버스를 감싼 `#scene3d` 를 평소 1× 에서는 `pan-y`, 확대했거나 꾸미기·사진 모드 중이면 `none`.
  - 주의: `pan-y` 이면 세로 움직임을 브라우저가 가져가서 `pointercancel` 이 온다. 그러면 1× 에서 **핀치가 끊기고, 꾸욱 들어 세로로 끌면 물건 대신 페이지가 내려간다.** `touch-action` 은 손짓 도중에 못 바꾸므로, 캔버스에 `touchmove` (passive:false) 를 달고 손가락이 둘이거나 물건이 들린 동안만 `preventDefault()` 한다. T6·T7 을 1× 에서도 돌린다.
- **고스트 재질** `ghostMat(src)`: 원래 재질을 복제하고 `onBeforeCompile` 로 프래그먼트 맨 앞에 `if (bayer(gl_FragCoord.xy) >= uDensity) discard;` 를 넣는다.
  - Bayer 표는 후처리의 `uBayer` 4×4 를 같이 쓴다. `gl_FragCoord` 는 저해상 렌더 타깃 좌표(= 아트 픽셀)라서 체크가 한 픽셀 단위로 정확하다. 카메라가 정수 px 로만 움직이니 무늬가 기어가지 않는다.
  - `customProgramCacheKey` 로 프로그램을 나누고 원래 재질마다 하나씩 캐시한다. **시작할 때 미리 컴파일 목록에 넣는다** (첫 고스트에서 끊기지 않게. 밤샘 때 만든 미리 컴파일과 같은 자리).
  - `transparent:true`, `opacity:1`, `depthWrite:false`, `depthTest:true`, renderOrder 높게. 깊이를 안 쓰니 외곽선 패스가 체크마다 선을 긋지 않는다.
  - **노멀 패스에서는 숨긴다** (`draw()` 에서 `shade` 처럼 `visible=false`). 안 숨기면 `overrideMaterial = normalMat` 때문에 꽉 찬 노멀이 들어가 하이라이트가 생긴다.
  - **빨간 고스트**: `uTint` (평소 0). 못 놓는 곳이면 빛 받은 색을 #a53030 쪽으로 섞는다. 팔레트 스냅 뒤에도 빨강 램프에 남는지 T8 에서 본다. 재질을 바꿔 끼우지 않고 값만 바꾼다.
  - 그림자를 던지지 않고 레이어 0 에만 (발광 패스 제외). 디더 게이트(`ramp()`)는 밝기 차이 부호가 번갈아 바뀌면 0 을 내서 체크 위에 디더가 더 붙지 않는다.
  - 양초 불빛 미리 보기를 넣을 때(v1)는 **빛을 새로 더하지 말고** 기존 `candleLight` 를 미리 보기 자리로 40% 세기로 옮긴다. 빛 개수가 바뀌면 모든 재질이 다시 컴파일돼 끊긴다.
- **자리 괄호**: LineSegments 한 번 (드로우콜 +1). 점은 `snapC` 로 픽셀 중심에. 고스트처럼 노멀 패스에서는 숨긴다 (`normalMat` 으로 그려지면 괄호 둘레에 하이라이트가 생긴다). ⇄, 꾸욱 링, [⟳][✥] 는 HTML 오버레이 (픽셀 파이프라인 비용 0).
- **드로우콜**: 고스트 1~2 + 괄호 1 → 지금 약 85 에서 약 89. 예산 150.

## 8. 주인이 정할 것 (남은 것 2)

1. **꾸욱 누르는 시간.** 정함 (주인 피드백): 0.6초 + 점 8개 링. 모든 물건 같은 값. 나중 설정 '느리게 1.0초'만.
2. **놓을 때 문어가 매번 들고 옮길까?** (가) 바로 놓이고, 끝낸 뒤 문어가 옮긴 물건에 가서 써 본다 — **추천**, 빠르고 미리 본 대로 놓여. (나) 문어가 매번 걸어가서 들고 옮긴다 — §19 처음 안이고 귀엽지만 느려. 큰 물건은 미는 동작이 되고, 문어가 네 일을 대신하는 일꾼처럼 보일 수 있어.
3. **처음 화면(1×)에서 밀기.** 1×에서는 방이 거의 다 보여서, 밀면 손가락을 따라 조금 갔다가 돌아와(고무줄). 확대하면 끝까지 밀려. (가) 이대로 — **추천**, 처음 화면에서 방이 다 보여. 다른 방은 문으로 가 (11-07). (나) 처음 줌을 1.26×로 올려서 처음부터 늘 밀 수 있게 — 대신 방 가장자리가 조금 잘려 보여.

(정해 둔 것: 돌려 보기는 두 손가락 비틀기로 옮겼고, 1×에서 세로로 쓸면 페이지가 내려가. 놓기는 [⟳ 돌리기] [✥ 옮기기] 두 버튼, 못 놓는 곳은 빨간 고스트. 다르게 하고 싶으면 말해 줘.)
